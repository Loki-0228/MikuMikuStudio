# 实现记录

Windows x64 构建产物为 `MMSCurveRepair.dll` 与 `MMSCurveRepairLauncher.exe`。

曲线恢复核心保留先前完成的回归结果：3,174 项断言通过。用户提供的 `carp cam 2.vmd` 包含 5 个镜头关键帧；旧端点计算可在 3 处重现小数误差。带工程原始曲线的 PMM 样本可将第 44 帧的 `-5.58748070034e-08` 恢复为 `0`。原值不明确时，核心会跳过。

为避免占用 `dsound.dll` 名称，加载方式现已改为启动器启动挂起的原 MMS 进程，再加载唯一命名的插件 DLL。最终启动器已编译。此加载方式的桌面运行尚未重新验证，旧版代理 DLL 的加载记录不能作为其运行证明。

启用前请关闭正在运行的 MMS，并用本包的启动器选择当前 `MikuMikuDance.exe`。启动器不会写入或替换 EXE。具体步骤见 `README.md`。
