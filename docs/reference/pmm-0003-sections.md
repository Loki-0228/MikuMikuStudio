## 当前保存格式

main 的 `0003` 继续使用 v2 主体和 `MMSXPMM2` 尾部扩展，读取兼容旧 `MDSXPMM2`。它用于实际内容超出旧格式容量或帧号等能力的工程；名称扩展与负数关键帧本身不强制切换版本。原版 MMD 和最小包不能读取 `0003`。

## 未接入的容器

`PMM3END` 末尾块目录和 `PMM3SECT` 分节布局均未接入当前工程保存、加载。它们不能作为当前文件的解析依据，也不能用这些标记识别正常生成的 MMS 工程。

当前字节布局、名称、路径、未知记录保留及版本选择统一见 [PMM 扩展参考](pmm-extensions.md)。旧设计可通过 Git 历史查阅。
