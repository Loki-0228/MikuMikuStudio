# 骨骼与表情曲线共同历史

日期：2026-10-18。基准为 `3c963b4`，分支为 `codex/plugin-abi`，工作目录为 `D:/MMD-Next/MMS-abi-dev`。本轮受控迁移已完成本机验收；独立复核见[审查记录](abi-model-curve-history-review-2026-10-18.md)。

## 窗口与事务

表情窗口和骨骼原生／自由曲线窗口共用已有 `Session.history`。写入以一次 `ExplicitCommit` 提交，窗口撤销与重做直接遍历宿主共同队列。两种历史记录模式下，曲线操作均为显式提交。普通未绑定宿主继续使用原有局部历史。

表情只传递实际变化的 `NamedTrack`。读取窗口、切换比较模式和重新选择已有关键点不会把其他轨道注册为作者曲线。

受控窗口在筛选变化之前验证完整通道集合、顺序 ID 和连续／离散类型；表情不能夹带隐藏系统轨道，未修改的其他骨骼也不能携带错误的通道类型。任一来源无效时整次拒绝。

骨骼窗口先收集全部变化，再提交一次私有计划。受控路径可以同时修改多根骨骼。原生模式继续只编辑五组插值控制，保持原来的关键帧位置、骨骼数值，以及旋转和缩放各轴共享控制的规则。自由模式提交位置、Euler 角度和缩放的九条轨道。显示与 IK 状态保持原有帧号，值为 0 或 1。

仅修改显示或 IK 时，不生成骨骼自由曲线。原生、自由和显示数据全部准备成功后，才统一发布。

`BindModelHistorySource` 检查模型稳定 ID、历史绑定代次、模型表及键池身份。旧窗口不能在绑定变化或模型替换后继续写入。正常扩容和共同历史恢复同一对象保留稳定身份。换选模型后，该模型窗口暂为只读；主窗口共同历史仍按原顺序操作。

## 内部接口

本批没有新增公共 C ABI，以下接口仅供原生宿主组合。

| 接口 | 输入与职责 |
| --- | --- |
| `PlanMorphCurveWrite` | 模型槽及变化的 `NamedTrack`，返回私有 `HistoryChange`。无变化时返回空记录。 |
| `PlanBoneCurveWrite` | 模型槽、多条 `BoneCurveEdit` 及可选完整 `DisplayCurveRows`，返回同一次私有计划。 |
| `WriteBoundMorphCurves` | 检查宿主准入，提交表情计划，发布后同步当前读数。 |
| `WriteBoundBoneCurves` | 采用相同准入、事务及刷新规则提交骨骼计划。 |
| `ReadManyDetached` | 在私有表情层副本中派生窗口数据，保留当前原始作者层及缓存。 |
| `bone_curve::ReadDetached` | 只复制目标骨骼的作者条目并协调原生键，保留当前作者数据及旧撤销环，避免逐骨骼复制整模型作者表。 |

`BoneCurveEdit.freeCurves` 为真时提供九条 `tracks`。为假时提供完整原帧序的 `nativeControls`，每条记录包含帧号及位置 X、Y、Z、旋转、缩放五组原生控制。帧零控制保持原值。

`DisplayCurveRows` 提供原显示链的全部帧，每帧包含显示字节及全部 IK 状态。空指针表示本次不修改显示数据。计划保留外亲载荷及未涉及的原生字段。

## 准备与恢复

表情计划分别保留原始作者层和私有原生镜像。恢复本次涉及的表情时，合并其他表情当前的作者数据，避免旧整表快照覆盖其他编辑。采样针对目标原生键派生，撤销和重做不依赖原始文件。

骨骼计划保留原生键、缩放作者数据、自由曲线作者数据、游标和登记范围。多根骨骼共用同一私有目标键池、缩放及作者快照，避免多个参与者分别覆盖同一侧表。显示与 IK 值和该计划一起准备及发布。

当前帧求值沿用已有共同历史规则。干净骨骼在私有目标上求值；存在未登记姿态标记的骨骼保持当前位移、旋转和缩放，包括本次涉及的骨骼。之后切换播放帧时应用新曲线。物理模式变化和模式 3 的 IK 启动继续遵守现有局部求值的拒绝边界。

表情采样只更新本次涉及的权重。其他表情、其他模型及其他轨道的未登记姿态保持。

准备阶段完成分配、对象保留、扩容、身份及数值校验。短期候选冻结完整原生来源和相关当前姿态。发布阶段不分配、不调用窗口、GPU、插件或文件。失败或取消不留下部分修改，不截断重做分支。

表情权重保留负数和超一数值。新计划检查曲线端点、Bezier 控制点及原生线性镜像的 float 表示范围，避免当前帧可用、后续帧溢出的曲线进入受控记录。此准入不修改既有 VMD 读写器。

共享窗口的写前读取捕获来源异常，并阻止读取回调递归触发历史操作。失败时转为只读并重试读取，不调用写入或历史遍历。该恢复与提交后的只读刷新使用相同的队列边界。

只读重读中的选区同步不提前刷新控件。先按帧更新窗口选区，待数据及历史修订确认后再统一发布界面，避免表情镜像的全选标记使文本框短暂禁用、丢失焦点。

后续选区按骨骼／表情身份及帧号识别，不能按被复用的槽位转移。首次发布保持原镜像的导出标记；短期候选仍拒绝准备之后的选区变化。

## 兼容与剩余范围

VMD 标准字段、骨骼缩放及自由曲线扩展、`MMSMCRV1` 和 PMM 记录布局保持原格式。窗口写入迁移不代表受控模型 VMD 导入已经接受所有自由曲线尾段，该导入仍是后续迁移项。

专项将首次原生镜像、槽序、导出选择标记与旧纯 `Write` 函数逐字节比较；表情还比较实际 `CaptureVmd` 尾块。既有 VMD1／VMD2 原生加载、求值、保存和曲线传输测试全部保留。PMD 基础表情 0 的原生登记限制没有放宽。

显示／IK 的当前 `loadComplete` 和 `IkChain.enabled` 随事务发布，并在往返时按当前帧采样。IK 派生矩阵继续由正常绘制流程处理，不因离散值编辑重采作者姿态。隐藏窗口模型不含 CCD 链接或渲染器，本批不将状态发布测试记为完整 CCD 视口验收。

公共 `mms.edit` 继续关闭，直到其余原生写入完成受控迁移。Win7 SP1 x64、CPU 基础路径和 AMD 兼容约束保持。高级图形能力没有成为本批基础依赖。
