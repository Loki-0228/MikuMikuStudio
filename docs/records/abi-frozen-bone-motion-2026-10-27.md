# 冻结骨骼动作采样

## 当前能力

新增内部 `BoneMotionSnapshot`，为独立场景求值保存完全自有的骨骼动作数据。它复制每根骨骼的可达原生关键帧、尺度矩阵与控制柄，并组合新的 `bone_curve::SamplingState` 保存已在私有存储中协调的自由曲线。源模型只需在捕获期间存活；之后修改或删除模型不影响旧快照。捕获需在 UI 安全点与模型编辑串行执行。

`SampleChannels` 接受显式非负时间，返回位移、四元数、3×3 尺度矩阵和原生物理开关通道。它不分配内存，不读取活体模型或侧表，可由多个线程并发调用。失败保留调用方输出。旧快照维持捕获时的数据，更新内容需要重新捕获。

原生控制字节解释及四元数直接跳帧运算移入 `bone_key_sampling.hpp`，供原历史编辑求值和冻结采样共同使用。运算顺序保持不变。自由曲线数学同样由原作者采样和新冻结采样共享；没有维护另一套自由曲线算法。

捕获校验帧零、帧顺序、前后链接、可达槽归属、浮点值和尺度。不可达池槽中的旧数据不被复制。源存在未完成范围编辑时拒绝捕获；空或失效自由曲线来源保持为空，不删除源侧表。默认保留数据上限为 64 MiB，按实际向量容量及保守节点开销核算；它不是捕获临时分配峰值或全场景总预算。

## 支持边界

这是约束、骨骼层级、IK、表情、动作层及物理模拟之前的已注册动作通道，不是世界矩阵或最终模型姿态。当前未注册编辑姿态不作为采样后备。负帧、非有限值及超出宿主帧范围的时间明确拒绝。

外部父级窗口随显示关键帧变化，不能固定使用捕获时的窗口。本阶段对带外部父级 selector 的骨骼返回 `ExternalParent`；未支持的派生类型返回 `UnsupportedBone`。物理开关值是原生关键帧数据，不代表已经执行物理模拟。

本批没有公开新的 C ABI，也没有改变 `mms.scene` 的可用求值阶段。尚需场景身份/修订绑定、资源预算与租约、表情及显示轨道冻结、层级和约束求值、物理能力及图像输出，才可供完整洋葱皮或多视口使用。现有 `physics_bake::ModelCopy` 不因此获得跨模型寿命保障。
