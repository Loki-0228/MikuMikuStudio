# 临时布局公共服务与 SDK

本批将已有内部会话开放为 `mms.ui.layout.session` 1.0，并增加复用该表的 C++17 包装。没有另建控件身份、排版状态或历史实现。目标范围未修改；main 已提交 HEAD 仍为 `d551f1f`，阴影同步暂缓，未复制 main 未提交内容或覆盖稳定程序。

## 实现

公共 C 表提供能力与目标查询、开始、应用、状态及原始索引查询、回退、正式提交和释放。注册表继续负责全部业务校验。输入数组限制为精确记录布局、版本 1、最多 64 个目标；保留字段及未声明的值须为零。所有入口保留线程、回调和停止限制，失败不写输出。

状态增加累计撤回原因。字段被部分接管后，原始声明索引保持不变；插件查询剩余字段，再按原顺序提交完整剩余值。终态的查询仍保留元素身份，但字段为零。正式布局修改、目标变化、用户接管和停止分别记录原因。修订不会回绕，最后一个修订保留给终态操作。

`LayoutSessionServices` 和 `LayoutSession` 只包装原 C 表与 handle。便捷的单目标开始函数与多目标数组使用相同会话；成功修改后需要再次显式查询修订，不隐式重试旧编辑。活动对象不能被另一句柄覆盖；释放失败保留原句柄；析构不跨线程调用宿主。

开发环境、字段权限、错误处理、停止清理及示例见[插件开发参考](../../sdk/mms/layout-session.md)。本批尚不提供跨父节点、DOCK、跨插件、本体任意控件、绘制层或动画调度；这些仍属于完整需求。
