# Morph 文本共同历史验证（2026-10-17）

本批基于 `codex/plugin-abi` 的 `e41b8d4`，仅修改 `D:/MMD-Next/MMS-abi-dev`。四类 Morph 权重文本 `506/511/516/521` 接入受控共同历史，普通 `mms.edit` 仍关闭。

## 行为与接口

`CommitBoundMorphNumber` 在旧写入前消费修改标志，验证完整输入，再按原七字符窗口读取 double 并保存 float。保留原始权重精度，允许负数及大于 1 的值，滑杆自身限位不限制作者数据。未修改的舍入文本不写回，重复失焦和 Enter 不重复追加历史；同值、非法／超长输入、float 溢出、无目标、忙碌或准备失败不截断 redo，不写 dirty、选择、旧环或部分权重，不回落旧写入。

初次文本滑杆按旧 double 输入乘 100 后截断，例如 `0.53` 显示 53。该值转 float 后再计算可能得到 52，恢复读数仍按原 `SyncMorphRow` 的 float 权重转 double 百分比规则显示。两条换算明确区分，不用舍入后的文本覆盖权重。同值重输沿用初次滑杆规则，不产生新历史。大数转换为整数前先限制可表示范围，避免旧代码的超范围强转；权重仍保存实际 float。

新内部模块 `native_morph_commands` 提供 `ApplyBoundMorphValue(MMDApp&, modelSlot, morphIndex, value, changed)`，参数为作者权重，不是百分比。这是 C++ 内部接口，不是公共 C ABI。它检查 UI 线程编辑门禁、运行状态、模型、目标索引、键池及有限值，准备和提交成功后才发布 dirty 与读数。相机模式拒绝新的隐藏 Morph 文本提交，已提交记录可在相机模式下撤销和重做。

`RefreshBoundMorphReadout` 按当前模型及四行选择显示 `%5.4f`，并同步滑杆。它只读作者值，不求值关键帧；保留有 EDIT 修改标志的行，避免其他操作刷新时丢失未提交文本。提交成功后刷新，插件撤销和原生撤销分别使用既有安全通知位置；不在原子发布中操作控件。可选通知失败不把已完成的编辑报告为失败。

## 身份、寿命与复核

`MorphValueChange` 保存单个目标权重的 before/after、原模型槽和指针、稳定模型 ID、Morph 表及数量、目标 20 字节名称／panel／type、自有 Morph 键池身份。历史往返先检查对象在场，再解引用；模型或表替换、数量变化、目标身份变化、新模型复用原地址、键池替换均使旧记录过期。正常键池扩容保留身份，记录可以继续往返。

长期记录不依赖后来选择的模型或 Morph，不依赖当前编辑模式和播放头。每个短期候选另外检查对象代次、当前帧和目标权重，发布只写一个 float 及记录状态，不分配、不调用窗口、插件、GPU 或文件，不重采关键帧、不改变骨骼姿态与物理。

标量记录不额外保留模型或备用键池，采用附件标量相同的寿命规则。受控导入／删除节点持有资源，按历史顺序先恢复删除模型，再撤销更早的权重；更早标量节点先于后续删除节点淘汰。恢复更新对象代次时仍使用原稳定 ID、表与键池。未迁移代码绕过历史释放、重排或替换模型数据不属于支持范围。
