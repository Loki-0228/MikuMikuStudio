# 独立持有骨架定义

## 已实现范围

内部 `BoneDefinitionSnapshot` 为后续独立姿态求值保存完整的已加载骨架定义，不生成姿态。它与已有骨骼动作、表情权重、显示轨道快照分开持有数据；当前没有新增公共 C ABI，也没有将该模块接入 `mms.scene.evaluate` 的姿态结果。头文件为 `include/mikumikustudio/bone_definition_snapshot.hpp`，实现为 `src/animation/bone_definition_snapshot.cpp`。

快照保存以下静态内容。

| 数据 | 冻结内容 |
| --- | --- |
| 模型定义 | `physicsMode`、`maxBoneLayer`，保留原字节和有符号层号 |
| 骨骼 | 固定 20 字节中英文名称、父索引、基准位置、类型、标志、层、调度标志、刚体参与标志 |
| 继承与约束 | 尾骨或尾端偏移、继承来源和比例、固定轴、局部轴、外亲键、selector 索引及扭转限制 |
| PMX 原始 IK 定义 | 原目标、迭代数、角度，以及逐骨骼深拷贝的链接和限制 |
| 运行 IK 定义 | 独立深拷贝驱动骨骼、目标、迭代数、角度和运行链接，保留重复项及顺序 |
| selector | 原顺序的骨骼映射，索引 0 为模型全局项，骨骼值为 `-1` |

PMX 原链与运行链分别保留，数量和参数无需相等。加载器会转换运行链的链接数和迭代数，并调整角度。`CoRotate` 的 `tailIdx` 是有符号百分比，来源为 `tailBone`；其他继承类型按各自启用规则解释 `tailIdx`。`extParent` 保留为外亲键，不作为模型槽号校验。

不复制名称指针、当前变换矩阵、编辑姿态、IK 当前开关、选择状态、显示窗口或外部目标引用，也不访问作者或尺度 side table。PMD 膝盖判定所需的固定日文名字节保留。所有读取接口返回独立记录，源模型修改或销毁后仍能并发读取，无需分配。非法序号返回 `false`，输出保持原值。

## 校验与内存

捕获必须在 UI 安全点与模型编辑串行执行，调用方保证输入表的实际内存范围有效。非零计数要求对应指针；索引、启用约束和必要浮点值在发布前验证。父子层级用非递归线性遍历检测环，允许父索引大于子索引。继承关系与 IK 反馈不参与父链环检测，重复链接和零链接、零迭代保留。

骨骼非负 `slotIndex` 必须在 selector 范围内，且该 selector 指向本骨骼。额外 selector 只要求合法骨骼并保留顺序，不要求映射为双射。启用的固定轴不要求归一化、正交或非零。PMX 链限制只在原始 `hasLimits == 1` 时检查；未启用数据原样保存。PMD 不使用的 `tailOffset` 不因 NaN 而拒绝。

默认保留额度 64 MiB。顶层和嵌套最低容量在分配载荷前预检，最终按所有自有 vector 的实际容量计费。保留量包含快照、实现对象及嵌套容器，不等于捕获期间的峰值内存。无效定义抛 `invalid_argument`，额度不足抛 `length_error`，分配失败抛 `bad_alloc`；失败销毁私有候选，不修改源。
