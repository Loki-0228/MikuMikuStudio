# 补齐 main 的启动器修复与保存验收

2026-10-20 更新：独立镜头数值修复工具及启动器已按用户要求从 ABI 分支移除。下文保留当时的验证记录，当前范围见[移除说明](abi-main-marker-sync-2026-10-20.md#移除独立修复工具)。

ABI 起点为 `2f2bcb7`，本次核对的 main 为 `6af0514`。`main` 后续提交中的相机构图修复已由 `dcfe98c` 适配，图片、粘贴和 PMM 生产修复已由 `2f2bcb7` 纳入。本批补齐此前遗漏的 `b41fb80ee9c513a080771acc35ebc0410c44a171`，并补充源线程后来完成的正常保存错误提示测试。发布说明不覆盖 ABI 分支的实现记录。

核对期间 main 将上一批修复正式提交为 `9de615e`。对应生产代码已存在于 ABI，本批没有用 main 覆盖共同历史、调度器、原子侧车发布和单图取消等 ABI 适配。

## 曲线修复启动器

启动器先恢复目标 MMS 进程，等待 Windows 模块列表初始化后再加载插件，修复对挂起进程查询模块时的失败。英文界面按系统 DPI 计算客户区和控件位置，「Start MMS」与「Close」保留独立空间。MMS 内的修复菜单与报告继续跟随宿主语言。

验证脚本显式填写传入的宿主路径，覆盖中文改名 EXE。源码仍使用本分支既有的 `plugins/curve_repair` 跟踪路径，没有新增大小写不同的第二套工具目录。原有曲线识别和修复计算继续保留。

## ABI 工程配对

本批审查发现，修复工具原样复制 `.pmm.mms-plugins.json`，但修复后的 PMM 字节已经变化。ABI 宿主按 `mainSha256` 校验配对，因此原实现会生成无法重开的副本。

工具现在复用宿主的侧车解析与校验代码。在创建输出之前校验原 PMM、侧车格式及插件载荷；遇到未恢复的保存日志时拒绝操作，不改写源工程。副本保留项目身份、插件数据和全部未知 JSON 字段，仅更新 PMM 哈希及保存标识。未知数字保留原始拼写，避免大整数或指数精度损失。没有侧车的工程不会新增侧车。原工程及其配套文件保持原字节。

## 正常保存错误提示

上批已验证静默备份拒绝非法数据，本批增加真实 `SaveSceneFile` 的日文、英文和中文错误提示检查。用合法保存作为插件序列化捕获的正对照，再核对非法保存不触发捕获、不改原 PMM 和插件侧车，并保留未保存状态。测试关闭实际错误对话框，设置限时失败，不能用模拟返回值替代界面验证。

源测试的固定 SHA256 为 `636E921D60A671AEB81DA1F904DF4C08ECBAE7D6D7B9C213433BD02D41D85FC6`。本批保留 ABI 已有的名称边界、侧车保护和序列化检查。非法引用由测试人为构造，用于验证保存保护；这些用例没有查明真实工程中损坏引用的产生过程。
