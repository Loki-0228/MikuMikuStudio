# 同源拓扑与跨模型网格验证（2026-10-27）

内部 `MeshSceneSource::MeshAt` 提供同一安全点捕获的绑定网格、索引、三角形和材质分段。返回值属于来源的借用只读对象；来源必须保持存活，不允许将它作为独立帧的生命周期保证。独立网格帧仍不持有拓扑；公开 C ABI 前须设计与帧关联的拓扑租约或等价所有权，并计入公共额度。

三个实际加载的 PMX 2.0 模型构成外亲链。测试将两个依赖模型各一个顶点的 BDEF1 骨骼索引在运行时绑定到实际受目标动作影响的骨骼；这使夹具能检测顶点变化，而不是仅检测骨架变化。使用测试拥有的内存 COM 缓冲调用生产 CPU 蒙皮路径，逐位比较独立网格帧的位置、法线和已启用 UV，骨架与原生两阶段调度结果对照。目标动作变化后，消费者和传递依赖者的网格均变化；旧来源保留原结果。删除所有来源模型后旧、新来源仍能求值，销毁来源与数学上下文后帧仍能读取。

第一次运行发现原夹具的权重没有保证绑定到受影响骨骼，未通过顶点变化断言；修改测试夹具并重新冻结、构建后通过。该验证不代表源文件自身含有这两个特定权重，也不覆盖真实 PMD 多模型、物理模拟或 PMX 2.1/QDEF。

网格专项 596 项通过；实际 PMX、PMD 单模型拓扑和删除后的来源读取通过；三模型原生 CPU 对照通过。完整和原始兼容配置产品构建通过。源文件冻结哈希、构建日志和独立宿主结果位于 `build/verification/abi-mesh-scene-topology-20261027/`，最终冻结后重新构建宿主。稳定版 release 未覆盖，SHA256 为 `180db2580c99a3578f30b2539451ff82605aebdec337daebce8b77edf86cf65a`。
