# main 未提交功能向 ABI 的行为迁移

## 本轮范围

本轮纳入 main 尚未提交的多骨骼和阴影改动，范围从已提交内容扩展到上述两项。改动涵盖骨骼与共同历史、阴影、其他数据与登记修复，以及 HUD；整合后进行代码审查和验收。

来源是 main `6facf91330530c917dba70e20ea1c30268829bd2` 上固定的一份工作树快照：清单及 SHA-256（本地证据，未随本文发布）。`base/` 保存提交基线，`current/` 保存本轮授权的未提交文件。main 仍可能由另一任务继续修改；本记录不声称同步了快照之后的变化。没有修改 main 工作区或覆盖稳定版程序。

## 已迁移的行为

| 内容 | ABI 中的处理 |
| --- | --- |
| 多选骨骼旋转 | 普通旋转骨骼围绕自己的关节、按自己的坐标轴旋转，选中的父子关节可共同弯曲。Move/IK 保留原有围绕主骨骼移动及选中根过滤。固定轴、本地轴、视图轴使用统一计算。 |
| 独立旋转 HUD | 每个参与关节显示独立圆环与扇形，主骨骼最后绘制。父级带来的继承运动不会算作子骨骼自己旋转；切换轴、选择、场景、时间或释放模型时清理临时状态。 |
| 共同历史 | 先验证全部实际旋转目标，在私有草稿计算后统一接受；整组一次撤销、重做及取消，保留两种历史模式、外部修改保护与失败原子性。 |
| 固定与动态阴影 | 固定精度以原滑条的世界采样密度拟合范围，为模型提供独立接收图；动态精度使用近、中与桥接层，在视距变化时过渡密度。 |
| 阴影滤波与曲面 | 共享深度预滤，保留原始深度采样；调整曲面接收者的平面校正，兼顾平面条纹及曲面误暗。集中设置、SM2 回退、设备重置与资源释放保留。 |
| Unicode 名称 | PMX 无法用 CP932 表示的名称生成非空内部绑定；PMM 仅在表大小相同且来源索引一致时识别旧绑定，完整名称仍由 MMS 元数据保存。 |
| 保存判断与报告 | 详细报告具体模型、字段与原因；未经编辑的默认碰撞轨道不误报；反向播放范围按相对末尾解释。 |
| 表情及显示登记 | 四栏表情、全部表情、显示/IK 登记补原生撤销；修复关键帧池扩容后撤销/重做及最大帧、搜索位置恢复。保留 ABI 已有的共同历史拦截和私有重放。 |
| 备份设置界面 | 修复 `.pmm1` 选项与相邻复选框重叠；增量保存选项和命名占位按钮在 Tab 顺序中先于确认／取消。仅替换与来源基线完全一致的两个资源块。 |

## 接入时额外修正

HUD 在手势开始、首个输入样本之前捕获姿态基线，避免首次绘制把已经旋转后的姿态当零点；共同历史及原生入口均接入。父坐标轴直接取实际编辑计算结果，避免用非正交父矩阵的转置反推轴向。绘制批次使用有界存储，选择准备失败不能带着半成品状态退出绘制。

真实 PMM 往返测试发现原始配置的读写上限不一致：骨骼／表情映射写入宽度为 20 字节，读取却误用了 VMD 的 15；模型中英文标题写入允许 255 字节，读取却限定 20。已按各自实际字段容量修正正常读取及非法槽位的标题跳过路径，加入缓冲区容量断言。测试同时验证 21／255 字节标题完整往返、后续关键帧不串位、源 PMX 不变，以及超限／非 CP932 标题拒写时原文件不变。这些修改不改变 VMD 字段宽度。

旧版兼容副本继续执行 ABI 的严格 CP932 路径、规范绑定及原版加载器身份检查。一个新绑定即使字节碰巧能按 CP932 往返，也不能据此声称原 MMD 能正确按名加载。完整 MMS PMM 保存与这些旧版副本限制分开。VMD 15 字节名称、PMD 严格导出及标准 VMD 写入规则没有放宽，MDS 标记读取没有恢复。

## 明确保留的边界

- 全部表情登记和 `ResetModelSelection` 原有入口仍缺少共同历史专用适配。本轮迁入其原生历史能力，不能据此关闭跨模型共同历史的全部要求。
- 扇形当前仍由相邻绘制姿态的四元数差取得最短弧；两次绘制之间超过半圈的真实累计绕圈不能从最终姿态唯一恢复。编辑结果与历史正确性不依赖这个视觉累计值，后续若支持连续多圈反馈，应在接受输入样本时记录有向角度。
- 固定精度的独立模型接收图仍沿用来源硬件尺寸上限，最高可达 8192²；单个颜色和深度图合计约 512 MiB，多模型可能增加显存与绘制开销。分配失败保留回退，但不能将此视作总显存预算或性能验收。
- 本轮阴影运行时使用 `--mme 0`，没有新增真实 MME 插件验收结论。
- 本轮不新增 Win7 SP1 x64、AMD 真机或真实鼠标通过结论；CPU 基础路径及可选图形接口边界继续保留。
