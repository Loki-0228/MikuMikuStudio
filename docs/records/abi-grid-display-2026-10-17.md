# 坐标显示共同历史验证（2026-10-17）

本批基于 `codex/plugin-abi` 的 `4fe3a0b`，仅修改 `D:/MMD-Next/MMS-abi-dev`。坐标轴／地面网格显示菜单 `215`、主面板按钮 `557` 和浮动分派 `557` 接入受控共同历史。该字段由 PMM 保存，属于工程状态；相邻 Morph 前后按钮只切换编辑目标，本批没有为它们添加编辑历史。普通 `mms.edit` 仍关闭。

## 行为与接口

三条原生写入由 `TryToggleBoundGridDisplay(MMDApp*)` 接管，保持零变 1、非零变 0，以作者值决定切换方向，不依赖复选框外观。内部 `ApplyBoundGridDisplay(MMDApp&, enabled, changed)` 提供显式布尔目标，写入 0 或 1。记录保存原始字节，撤销可以恢复 7 等非标准非零值。该入口是 C++ 内部接口，不是新增公共 C ABI。

一次实际变化形成一条共同历史；已有相同目标字节时不添加历史，不改变 dirty、选择或 redo。播放或事务忙碌、准备失败等拒绝不回落旧切换逻辑。复选框可能在命令到达前改变外观，拒绝时从作者数据恢复菜单和控件。原生点击每次都切换，未设置独立取消对话框；插件待提交事务取消后可以重试，已提交切换通过共同撤销恢复。

提交后同步主菜单和主／浮动面板的坐标显示复选框，不因浮动面板打开而遗漏隐藏的主控件。显示标志是唯一数据来源；切换不激活轨道、不改变当前模型或附件选择，不修改姿态、关键帧、投影或播放头。字段更新后仍由原有绘制流程显示坐标轴／网格，不增加场景求值。

## 记录与复核

`GridDisplayChange` 保存原始字节和目标字节，以相机键池身份作为现有工程来源标记，与其他工程级标量记录保持一致。正常池扩容保留身份，替换工程来源拒绝旧记录且保持历史游标。长期往返不依赖当前模型、编辑模式或播放头；短期候选另外校验当前帧、字段值和记录代次。

发布只写一个字节及记录状态，不分配、不调用窗口、插件、GPU 或文件，不持有场景资源或设备对象。提交完成后才调用 `RefreshGridReadout` 同步菜单与控件，可选通知失败不把已完成编辑报告成失败。共同历史的安全刷新通过 `RefreshBoundGlobalReadout` 更新该字段，插件回调不提前刷新控件。该记录及其专用读数不重建投影或求值关键帧；普通未绑定路径和原始兼容 profile 保持旧逻辑。
