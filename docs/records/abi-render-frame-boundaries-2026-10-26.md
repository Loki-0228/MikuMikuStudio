# 渲染阶段与回调重入边界

日期：2026-10-26。工作区 `D:/MMD-Next/MMS-abi-dev`，分支 `codex/plugin-abi`。

## 行为

DX9 `FrameDriver` 在成功 `Present` 后发送普通帧通知和 END，正常绘制与局部重绘共用此入口。没有呈现或呈现失败时不发送 END。BEGIN 移至设备恢复检查与场景修改检查之后，避免这些提前退出路径通知插件。BEGIN 表示开始一次绘制尝试，不保证随后有 END。

`PluginFrameBegin/End/Presented` 检查 `Manager::InCallback`。普通插件回调再次进入这些入口时，不嵌套调用渲染回调，也不推进服务的帧序号。回调返回后，后续正常通知仍有效。

`render.h` 的租约说明改为现有契约：设备丢失调用释放函数；显式释放和插件退休只取消登记，正常关闭资源由插件负责。此修改与现有 SDK 指南一致，不改变 ABI 表布局或释放行为。
