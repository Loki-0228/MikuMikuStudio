# 设备租约取消安全性

日期：2026-10-26。工作区 `D:/MMD-Next/MMS-abi-dev`，分支 `codex/plugin-abi`。

## 修复行为

设备丢失时，RenderService 从原登记表逐个提取租约，再执行释放函数。释放函数可以取消同一插件尚未执行的其他租约，取消成功后不会再调用已取消的释放函数。这避免了旧实现将整张表移走后，取消失败却继续访问已销毁上下文的问题。

当前执行的租约已从表中移除，取消自身返回 `MMS_E_NOT_FOUND`。其他插件的租约不能被取消。插件退休会移除其未执行租约，释放函数抛出异常后仍清理其他租约。

设备丢失或释放进行中，申请租约返回 `MMS_E_NOT_READY`，不修改输出句柄。释放函数内的重复设备丢失或恢复通知被忽略，不递归派发、不改写当前设备代次，也不提前开放申请。正常恢复通知后允许重新申请。显式释放和插件退休仍只取消登记，不调用资源释放函数。公共 C ABI 表布局不变。

SDK 参考同步说明以上行为，并纠正帧信息永远为零、C++17 包装尚未提供等过时描述。设备 Reset 与普通插件回调的反向设备丢失问题仍单独列为未完成。
