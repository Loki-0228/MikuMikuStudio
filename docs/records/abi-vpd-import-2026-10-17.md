## 接管范围与原子性

`LoadVpdFile` 的直接调用、菜单 `202` 和模型模式 `.vpd` 拖放在显式绑定时由 `native_vpd_import.cpp` 接管，拒绝时不回落旧加载器。相机模式菜单仍不弹出文件选择器。原始兼容 profile 和未绑定路径保留旧逻辑。

`VpdImportSession::Begin(app, history)` 捕获来源，不持有历史预留或模型资源。`Apply(path, changed, resetPhysics)` 消费会话，检查线程及共同历史门禁、绑定、对象存在身份与代次、槽位、帧号、历史修订、键池身份、骨骼结构、固定轴来源、姿势、缩放及脏标记。选文件期间插件可以合法编辑；关闭后旧输入返回 STALE。另有未结束插件事务时返回 BUSY。

标准段完整解析后才开始作者修改。非法计数、截断、错误字段、非有限数值整体拒绝。有效文件保持旧名称匹配、重复名称的逐个修正、重复记录后写覆盖及 PMD／PMX 固定轴行为。实际旧 `LoadVpdFile` 作为有效文件的数值比较依据，不用新实现复制一份充当预期值。

标准文件句柄禁止其他写入，并保持到缩放尾部读取完成。尾部沿用既有 CRC、边界及名称映射规则；缺失或损坏的可选扩展采用单位缩放，文件 I/O 失败则停止整次导入。`LoadTail` 新增可选 `strictRead` 参数，默认值保留既有策略，并补上 C++ 分配异常时的 fd 自动关闭。它是内部 C++ 接口，不新增公共 C ABI。

实际姿势或缩放有变化才创建 `NativePoseScope`，统一提交命中骨骼的位置、四元数、缩放及脏标记。失败回滚后释放预留；提交成功后才更新选择、dirty、历史按钮和读数。相同姿势及无匹配骨骼保留 redo、选择及物理重置标记。直接加载和拖放不新增主动物理重置，菜单成功产生修改后请求重置。菜单旧输入消费标记保留，不随撤销恢复。

历史持有作者值和模型保留资源，不依赖原 VPD 路径。缩放读数会安装临时 `matInit` 变换，该显示缓存不属于姿势历史；跨帧往返比较位置、四元数、缩放、脏标记及旧环，避免把显示缓存误报为作者数据损坏。

## 文件选择与路径

菜单使用绝对初始目录和 `OFN_FILEMUSTEXIST | OFN_NOCHANGEDIR`，返回后主动恢复 cwd。默认目录以 EXE 目录为基准，记忆的相对目录也按该基准解析。递归入口不打开第二个选择器。取消、坏路径、过期输入及 BUSY 不改记忆目录和共享路径工作区；只有成功且产生修改才更新记忆目录。文件读取、模态消息及 UI 通知均在姿势预留之外。
