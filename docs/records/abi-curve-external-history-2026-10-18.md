# 曲线编辑器接入宿主共同历史

日期：2026-10-18。基准为 `3db6bfd`，分支为 `codex/plugin-abi`，工作目录为 `D:/MMD-Next/MMS-abi-dev`。

本批只扩展共享曲线编辑器的模块内 C++ 接口，不新增公共 C ABI。共享编辑器继续只依赖 CPU 曲线核心和 Win32 UI，不依赖 MMS 的事务、场景或插件实现。宿主负责绑定实际共同历史。

## 五类全局曲线写入

显式绑定共同历史时，相机、灯光、自阴影、重力及附件的 `curve_host::Write` 统一进入 `WriteBoundGlobalCurves`。曲线窗口修改和该窗口读取 VMD 使用同一入口。`PlanGlobalCurveWrite` 返回独立 `HistoryChange`，无变化时返回空记录；调用方以 `ExplicitCommit` 准备并发布，两种历史记录模式下均为一次显式提交。

`AuthoredReplacement` 在私有副本中验证全部通道、生成原生镜像，并保留原始作者数据与经过协调的显示数据。受控 `Read` 只协调副本，不修改当前作者基线、修订或待登记集合。撤销恢复原始作者数据，不能用显示副本代替。原生读取失败时明确拒绝，即使已有作者数据也不返回过期曲线。

记录保存原生键补丁、原始字节、作者数据、游标、最大登记帧及实际涉及的姿态分量。提交和历史遍历按当时播放头采样这些分量，保留其他未登记姿态；严格等价的原生相机片段包装不取得未变化通道的姿态所有权。相机距离、视角或投影实际变化时请求投影刷新。重力原生回退保留右键模式完整四字节及原 float 插值规则。

撤销发布原始作者节点，但准备时另在私有副本中与目标原生键协调后采样，避免原生键已恢复而姿态仍来自旧作者值。原生插值会产生 float 差值溢出或重力噪声整数溢出的来源在首次准备前拒绝，防止提交后换帧才发现无法撤销。

分组及 `collections` 的 ID、标签属于保留的作者组织数据，参与修改比较和来源校验，但不会取得姿态分量所有权。通道显隐、显示标签及单位仍不创建作者历史。

原生关键点选区与曲线数据分别处理。首次提交保持旧镜像字节；后续未改选区时可以精确恢复原始标记。用户改变选区后，历史按有效键链中的帧号投影当前标记，槽位压紧不会把选区移到其他帧。当前不存在、撤销后重新出现的帧默认不选中。短期候选仍冻结全部字节，准备后再改变选区会拒绝该候选。

准备阶段完成分配、键链验证、父对象保留、扩容和当前帧采样。发布只交换已准备的作者节点和原生数据，不分配，不调用窗口、GPU、插件或文件。稳定键池身份允许正常扩容；对象或池替换、准备后来源变化以及无效父绑定均拒绝。历史按保留容量计费。

发布完成后，宿主同步当前读数并通知曲线窗口。同步读数期间的 `ScopedUiInputGate` 拒绝原生输入重入，不禁用窗口或改变焦点。该刷新不移动播放头、不重新求值整个场景，也不另加历史。

本批不开放普通宿主的 `mms.edit`。模型骨骼与表情的独立曲线写入尚未迁移，显式绑定下暂为只读；未绑定宿主和 MMV 保留原路径。骨骼及表情迁移仍是未完成需求。

## 同一编辑器可接入宿主历史

`Source.externalHistory` 默认关闭。未启用的源保留原有局部撤销栈，MMV 和未绑定共同历史的 MMS 无需修改既有调用。

启用的源共用 `Session.history`，接口如下：

```cpp
struct HistoryState {
    std::uint64_t revision = 0;
    bool canUndo = false, canRedo = false;
};
struct ExternalHistory {
    std::function<bool(HistoryState&, std::wstring&)> query;
    std::function<bool(bool redo, std::wstring&)> traverse;
};
```

`query` 只读取共同历史状态。临时编辑锁不代表历史丢失，宿主可继续返回历史版本和撤销、重做可用状态；绑定已失效时返回失败。`traverse` 执行一次撤销或重做，宿主在此检查完整写入门禁。返回成功表示一次历史操作已经提交；返回失败或抛异常必须保持历史不变。

启用外部历史后，`CommitChannels` 仍只通过该源的 `apply` 写入数据，但不再建立局部撤销副本。内容未变化时不调用 `apply`，保留宿主重做分支。拖动、插入、删除和应用仍以既有单次命令为提交边界。读取动作调用宿主的单次导入回调，然后只读取结果。

撤销、重做按钮及 `Ctrl+Z`、`Ctrl+Y`、`Ctrl+Shift+Z` 直接调用 `traverse`。编辑器读取宿主的最终数据，不把旧局部快照再次传给 `apply`。切换源不清理宿主历史；在一个源中撤销可以撤回另一个源或插件的上一项操作。

## 刷新失败不重复撤销

共同历史已经提交后，编辑器立即把当前视图标为待重新读取。读取失败时禁用写入、撤销和重做，保留宿主事务结果。可见窗口的定时刷新或手动刷新重试读取；它们不再次调用 `apply` 或 `traverse`。

读取前后分别查询历史版本。若读取期间历史变化，编辑器继续保持只读并重试，避免把旧数据记成最新版本。临时查询失败只影响界面可用性，不清空宿主历史。

成功读取时先采用数据，待第二次版本查询通过后再统一发布控件状态。输入框不会在成功提交中短暂禁用，因此原焦点保持。读取失败仍禁用编辑；恢复读取不把焦点从导航控件抢回。

定时刷新同时比较 `revision`、`canUndo` 和 `canRedo`。历史设置裁剪步骤而未增加版本时，按钮仍更新。未提供播放头回调的编辑器也可以刷新外部历史；隐藏窗口不轮询。

## 拖动结束后再发布

画布在鼠标松开时先结束拖动身份并释放自身捕获，再提交保存的预览、基线和增量。`WM_CAPTURECHANGED` 不再取消这份待提交预览。宿主仍可拒绝任何外部鼠标捕获，无需给曲线窗口特殊豁免。按 Escape 取消的拖动不提交。

## 验证入口

新增 `animation_curve_editor_tests --external-history`，覆盖跨源共同历史、键盘与按钮一致性、局部栈为空、其他原生或插件编辑的版本轮询、仅可用状态变化、读取及查询失败后的恢复、读取版本竞争、写入与查询回调重入、完整拖动与取消、保形插帧、删除、无变化提交、动作读取，以及未启用源的局部历史兼容。

真实 Win32 文本框回归检查成功提交及外部历史刷新期间无临时禁用或失焦事件，读取失败进入只读，恢复后不抢走导航控件焦点。

`native_edit_history_tests --curve-write-only` 覆盖五类原生镜像对照、两种历史模式、原始作者状态、私有求值、父对象与附件寿命、扩容、来源过期、元数据、选区、无分配发布、逐分配失败和数值边界。

`curve_sync_tests --bound-history` 打开真实 MMS 曲线窗口，用实际控件和快捷键操作五类来源及 `EditStore` 插件事务。相机 X 曲线修改、原生相机登记、Y 曲线修改按顺序形成三条历史，在不同播放帧逐次撤销和重做。检查原生插值字节、稀疏作者数据、分数帧采样、未登记姿态及 PMM 作者扩展字节。该 PMM 检查是扩展捕获与加载，不是完整工程文件往返。
