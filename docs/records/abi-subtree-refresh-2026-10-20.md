# 注册子树刷新实现与验证

日期：2026-10-20。分支：`codex/plugin-abi`。接口用法见 [刷新服务](../../sdk/mms/refresh.md) 和 [C++ 包装](../../sdk/mms/cpp-refresh.md)。

## 实现范围

`mms.ui.refresh` 1.0 增加 `MMS_UI_REFRESH_SUBTREE` 能力，沿用原 64 字节服务表、112 字节请求结构和元素身份。SDK 的子树便利方法组合同一个请求，不创建第二套队列或控件。插件查询能力时按位判断所需范围，不能假定能力集合只含 SELF。

范围来自宿主注册树，不遍历插件任意 HWND。GROUP 仅作为容器身份，实际阶段选择已注册且支持该阶段的成员；PANEL 可包含自身。任一后代归属其他插件则拒绝整次请求，任一请求阶段没有适用成员则返回 UNSUPPORTED。每次最多捕获 256 个注册节点，并计入现有队列预算。

注册表在结构变化时发布拓扑快照。后台提交只读已发布拓扑和呈现信息，不访问注册表或原生窗口。新增、删除、换父级或所有者变化使旧子树票据失效；本实现使用全局拓扑代次，即无关树的结构变化也可能保守地使票据 STALE。命令或文本变化不会单独改变拓扑代次。

DATA 在同一绑定锁内取得整树已绑定成员的不可变数据与版本集合。无绑定成员跳过；任一已绑定来源未就绪则整次拒绝。SUBTREE 请求的 binding 和 sourceRevision 为 0，票据 sourceRevision 为 0 代表版本集合，成功须检查 completedKinds。入队后发布新版本不替换旧快照，解绑、重绑或新增绑定使旧请求失效。无绑定、折叠为零尺寸的成员不会阻止 DATA-only 请求。

处理顺序是整树 DATA、整树 STATE、一次保留树 LAYOUT、整树 REPAINT。只有一个阶段的全部适用成员完成才标记完成位。失败停止后续阶段，不回滚已经更新的显示数据。取消、合并、停止保活、只读回调与因果任务限制复用原规则。刷新不求值场景、不移动播放头、不写入工程，也不增加撤销记录。

SUBTREE 暂不接受局部矩形；DEPENDENTS、自动来源订阅、插件量测提供者和更多控件的完整 STATE 仍待实现。Win7 基础路径继续使用 GDI 和已有 DPI 回退，没有新增厂商专用依赖。

## 回归中修正的问题

- 旧 SELF 请求必须先报告不支持的阶段，再检查几何和就绪状态。保留原有断言并恢复此顺序，避免 PANEL 的无效 STATE 请求从 UNSUPPORTED 变成 STALE。
- 独立生命周期测试插件原先要求能力集合严格等于 SELF，拒绝了正常追加的 SUBTREE。改为检查所需能力位，并保留 Manager 必须成功启动的断言，失败时打印实际阶段、错误码和日志。
- 旧 Manager 刷新夹具按窗口类选择首个 Button，误选宿主新增的隐藏“更多”按钮。改为使用真实插件命令 ID 范围，并严格要求恰有一个可见插件按钮；真实键盘激活、命令次数和票据状态断言保留。
- 新测试的数据发布需携带来源的实际 expectedRevision；换父级测试的文本参数需保持有效生命周期。这两处仅修正测试夹具，没有放宽产品校验。

## 验证

新增 `--subtree-refresh-only` 专项覆盖嵌套 GROUP／PANEL、同对象 SDK、阶段顺序、来源版本集合、后台提交、只读重入、跨所有者拒绝、拓扑及绑定失效、配额、合并、取消与卸载保活，共 615 项检查通过。

完整配置与 `mmd932` 基础配置均已重新构建。每种配置选定的 10 组整合回归通过，覆盖刷新、数据绑定、保留布局、ABI 契约、模型容量与可选图形导入；完整配置另含物理烘焙与工程身份，基础配置另含原版文件读写和状态。

最终 `--refresh-only <lifecycle.dll>` 在两种配置分别完成 10,155 与 10,175 次检查，包括真实独立 DLL 的请求、状态更新、键盘激活及停止保活。检查总数包含泵消息期间的状态检查，不是独立用例数量。更新夹具后另行重跑两种配置的 `plugin_abi_contract`，均通过。完整配置实际产品在原名及中文改名下的启动、菜单、工具栏和正常关闭均通过。

主要日志为 `test-full-self-compat.log`、`test-original-final.log`、`test-refresh-all-button-final.log`、`test-refresh-all-original-final.log`、`test-abi-final-full.log`、`test-abi-final-original.log` 和 `test-product-smoke-final.log`。早期失败日志保留，未以新结果覆盖。

证据目录：`build/verification/abi-subtree-model-order-20261020/`。没有运行完整共同历史套件，也没有 Win7 或 AMD 真机结果。
