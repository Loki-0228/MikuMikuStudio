# 全局删键与相机 HUD 共同历史

日期：2026-10-19。分支 `codex/plugin-abi`。本批迁移受控宿主的五类全局关键帧删除，以及相机 HUD 的六个平移／旋转轴。普通公共 `mms.edit` 继续关闭。

## 全局关键帧删除

相机模式的实际删除命令 `423` 通过 `TryDeleteBoundKeys` 准备相机、灯光、自阴影、重力和全部已选附件的私有候选，一次显式提交。两种历史记录模式下，删除均是一条记录。插件编辑可以在前后独立提交、撤销和重做；当前模型、播放头或后续选区不决定历史次序。

原生链、池身份、附件及父模型身份、作者数据、预算和当前源均先校验，所有族准备完成才发布。分配或预算失败不留下半批删除；正常池扩容保留身份，池被替换或目标失效拒绝恢复。撤销不依赖重新读取原模型、X 或动作文件。

非零帧删除修复双向链并保留未删除键和后续选择。零帧按各族原生规则重置，其中相机原生删除保留 FOV、透视和保留字节，并重置原生 24 个插值控制字节。作者层只重置对应字段；小数 FOV、未受影响自由柄和精确片段继续保留。删除引起区间合并时，只释放实际受影响的保形片段，普通重定时仍保留原严格规则。

当前未登记姿态仅在仍对应删除前采样结果时更新，外部或用户后来修改的姿态不被历史刷新覆盖。无实际变化不增加记录、不清除已有 redo。当前行回退只在没有显式关键帧标记时采用。

## 相机 HUD 手势

相机模式 HUD 操作 `15..20` 在按下前预留共同事务，沿用原平移和旋转数学，拖动时显示临时预览，释放时按一次 Adjustment 收尾。“全部操作”模式记录整次手势，“仅显式提交”保留原先姿态调整不自动登记的语义；不修改关键帧、FOV、距离或父骨骼。

预览期间持续校验相机池、工程绑定、当前帧、父对象与骨骼表、坐标和输入状态。ESC、焦点丢失、捕获接管、模式变化、解绑和关闭都取消未完成手势。在原数据域内，取消逐字段回滚仍由 HUD 持有的值，保留其他作者修改；进入另一帧或失效数据域时不把旧姿态写进去。

原生 HUD 按下会将真实光标移到视口中心。因此释放时读取实时 OS 光标并换算到所属主窗口／分离窗口客户区，防止排队的旧 `lParam` 把快速点击误算为大幅移动。有效最终位置仍计入本次手势；光标读取失败则保留最后有效预览。

分离窗口鼠标释放另补所有权检查：旧窗口排队的抬起消息不能释放其他窗口新取得的捕获。

模型模式 HUD、附件坐标目标、同模型跟随的特殊拖拽及其他尚未迁移写入仍不借此开放。

真实 PMX 与中文改名 PMD 隔离宿主同时验证实际菜单、插件交错、两个真实 X 附件、源文件离线及保存重开。HUD 走真实 Main/Mic 窗口过程，覆盖按下与释放预先排队、中心 warp、最终位置、字段冲突和捕获移交后的旧抬起消息；测试结束恢复光标和宿主状态。

审查中的失败均保留在本地日志：零帧测试原先错误要求原生 root 控制字节不重置；另一个无窗口 CPU 夹具过早绑定，使生产 Write 被正确门禁拒绝。两项修正测试后，精确比较又实际发现删除误改未受影响 FOV 根几何，现已修复生产代码，未放宽其余作者层断言。

额外将增强版插件启动探针用于原始兼容产品时，因等待 GUI_REGISTERED 超时而失败，见 `product-smoke-original.log`。核对 `integration.cpp::InitializeRuntime` 确认原始 profile 按既有设计直接返回，不加载 ABI 插件；本批保持此边界，没有将该探针计为通过。原始配置的 16 组结果是对应测试程序与组件验证，不表示原始产品开放新插件。

本批不改变 VMD 或 PMM 格式，不宣称 Win7／AMD 真机、混合 DPI 或参数滑杆视觉闪动已经验收。
