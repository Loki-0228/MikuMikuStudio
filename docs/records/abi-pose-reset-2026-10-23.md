# 绑定骨骼整体重置的局部零位与草稿

日期：2026-10-23。基线：`f43c76f`。本批开始核对 main 为 `fed9768f9fe726c4b5e068849808803f1713ad42`。只读取 main 已提交的 `command_control_450.cpp`，没有修改 main 或稳定版。

## 同步行为

main 的命令 495 将所有选中骨骼的局部位移归零、旋转设为单位四元数、缩放设为单位矩阵。ABI 原绑定入口仍保留根骨骼 X/Z，并对其他无父骨骼烘焙偏移。本批将绑定入口统一为 main 的局部零位目标，根骨骼、有父骨骼和其他无父骨骼使用同一规则，不再需要 D3DX 构造目标。

`ApplyBoundPoseReset` 从粘贴入口单独分出。它先检查编辑及历史门禁，再扫描选中骨骼；只有真实姿态或缩放变化才建立 `NativePoseScope`，以 `ExplicitCommit` 记录一次共同历史。两种历史模式均保留该显式提交语义。空选择不改变任何数据，已为目标的骨骼不额外置 dirty，无变化重置不增加历史或清除 redo。准备和提交失败沿用原事务回滚。

成功或合法无变化重置后，只有当前显示骨骼属于本次选择集合，才取消其位置、旋转和缩放九个输入草稿。位置显示保留父绑定偏移，旋转缓存归零，缩放显示为 1。其余骨骼、输入、选择、关键帧、播放头、物理重置请求和旧撤销环保持。

固定大小的 `PoseResetReadout` 记录已注册对象身份、绑定代次、历史版本、骨表和选择表、父绑定位置、姿态及窗口身份。每次文本消息返回后重新验证上下文，发现变化即停止后续写入。找不到已注册对象身份时跳过局部 UI 发布，不为无变化重置创建身份或分配历史；合法数据重置仍可完成。正常绑定宿主需要先登记场景对象，本批没有开放普通公共编辑服务。

数据提交后仅发布 `ProjectData | Viewport`，保留工程脏标志、撤销／重做按钮更新及协调器视口请求。九框单独更新，不调用完整 `PostViewRefresh`，避免覆盖未选显示骨骼的待提交缩放文本。文本写入失败也撤销旧草稿提交资格，失焦不会重新写回旧值。497／498 普通和镜像粘贴路径保持。
