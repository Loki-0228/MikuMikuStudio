# 模型 VMD 自由曲线尾段与共同历史

日期：2026-10-18。基准 `25381ce`，工作目录 `D:/MMD-Next/MMS-abi-dev`，分支 `codex/plugin-abi`。本轮完成受控模型 VMD 的骨骼、表情曲线尾段导入及本机验收。独立复核见[审查记录](abi-model-vmd-curves-review-2026-10-18.md)。

## 导入和兼容规则

标准键、缩放及自由曲线共用同一份私有目标池，形成一次显式历史提交。准备、取消和失败不改变场景；撤销和重做使用历史保留的数据，不重新读取 VMD 文件。普通未绑定宿主及原始兼容配置继续使用原加载路径。

VMD1、VMD2 标准记录、Unicode 字典、缩放前缀 CRC 和两类自由曲线编码保持原格式。没有重新编码标准体来计算校验值。解码依次消费 Unicode、有效 CRC 的表情块、有效长度的骨骼块，再读取缩放；坏表情 CRC 不跨过该块，合法长度但非法骨骼载荷仍占用原有边界。应用顺序保留为表情、缩放、骨骼。

表情按旧规则逐轨匹配：每个尾段关键点必须对应本次标准导入产生的标记键，值按原生 `float` 精度比较。原始 20 字节名称有歧义时跳过；Unicode 使用显式所有者映射，空映射不回退名称匹配。合并保留目标未覆盖帧和精确作者数据，缺失帧零锚点取目标原帧零值。安装作者层时不再次改写标准镜像。

骨骼要求完整九通道。偏移后缺少帧零时复制首值，以 Step 连接首区间。私有镜像保留旧槽序、标记、四元数及缩放基底；目标有不属于尾段帧集合的原生键时，整个骨骼作者块跳过，仍保留标准、表情及缩放结果。宿主仅在成功后提示该兼容跳过；内存或历史预算不足则拒绝整次导入。

模型最大帧可由尾段扩大，最后登记帧仍按尾段应用之前的标准导入结果计算。实际应用骨骼尾段后恢复旧分配游标及相关骨骼游标行为。无标准记录的骨骼尾段、只有表情作者数据变化的导入均可形成历史；目标键、作者及元数据完全不变时不新增节点。文件相同不必等于结果无变化：旧缩放非线性求值可改变偏移导入的原帧零基底，不能为消除这种变化而修改旧算法。

## 内部组合接口

本批增加内部 C++ 组合能力，没有开放新的公共 C ABI，普通宿主 `mms.edit` 继续关闭。

| 接口或字段 | 职责 |
| --- | --- |
| `ModelPasteSource.boneCurveBlock / morphCurveBlock` | 保存原始可识别封装，供各族在标准键的私有目标上处理。 |
| `curveTargetsResolved / boneCurveTargets / morphCurveTargets` | 表达 Unicode 所有者到目标索引的映射，区分未解析与已解析但无匹配。 |
| `bone_curve::DecodeVmdTracks` | 纯解码、名称匹配、偏移、九通道及帧零补齐；不写实时模型或名称映射 TLS。 |
| `bone_curve::ValidateFreeTracks` | 与现有骨骼 `Write` 共用同一组验证规则。 |
| `morph_curve::AuthoredImport` | 从未来 `NativeKeyView` 派生并合并原始表情作者层，复用预分配恢复候选。 |
| `ModelPasteReport.boneCurvesSkipped` | 只报告成功规划后的骨骼兼容跳过，不把失败包装为成功。 |
| `registrationMaxFrame / overridesSearchCursor` | 汇总层区分标准登记范围和尾段最终元数据。 |

准备期完成扩容、作者层复制、采样及预算计算。发布不分配内存，不访问文件、窗口、GPU 或插件。短期候选核对所有参与族和其他模型的存储范围，拒绝准备后出现的交叉引用；长期历史重新准备候选，允许正常的池扩容。骨骼游标与键索引、权重、IK 链及嵌套显示载荷之间的重叠也在检查范围内。

只求值本次拥有的姿态，保留未登记骨骼、其他表情和其他模型的临时值。播放头、剪贴板和名称映射 TLS 不变。成功提交并解锁后才刷新读数、历史按钮和曲线窗口；刷新失败不重复导入。

## 复核和验收

本轮先保留全部原回归，再新增骨骼、表情及模型组合专项。组合用例调用真实未绑定 `LoadVmdMotion` 作对照，覆盖 VMD1/VMD2、原始名称/Unicode、零/非零偏移、消费边界、缩放、作者数据、选择和元数据。不是以新解析器模拟旧加载器。

首轮发现的测试问题及生产修正均保留日志：

- 集成测试先有固定名称数组 15/20 字节赋值错误，修正为按缩放字段的真实宽度复制。
- 表情偏移测试把精确作者帧零误当成原生浮点镜像；现同时验证作者原值和原生原值。
- 混合历史夹具只改变会被旧合并规则清零的首键切线，实际为无变化；现改变真实保留的末键入切线，继续要求三步撤销。
- 独立审查发现表情导入额外套用了窗口写入的浮点控制点限制，会跳过旧版可正常采样的大切线曲线。本轮恢复导入原有准入，并补旧导出/加载对照。
- 审查补齐准备后跨模型别名，以及独立骨骼计划的索引表、游标存储保护。
- 完整宿主回归中的帧线、小键盘视图及稀疏登记夹具仍把曲线初始化当作不记历史的操作。现在绑定下的曲线写入已正确记入共同历史，因此夹具显式清理初始化节点，再检查空历史边界；全部原命令、数据及撤销断言保留。首次和第二次宿主失败日志保留。
- 新宿主缩放期望最初直接使用文件中的矩阵。旧 `CurveTime` 的非线性十二步求值在区间起点也有微小偏移，故镜像必须与真实旧采样及写入结果逐位比较；不修改旧求值器或改用误差容忍来掩盖差异。
