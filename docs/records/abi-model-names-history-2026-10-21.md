# 模型英文名称与备注共同历史

菜单 259 的受控共同历史路径已改为私有编辑会话。模型英文名、英文备注、骨骼、表情和显示组英文名在一次确认中提交。普通启动和原始兼容配置保持原路径；这项迁移没有开放普通公共 `mms.edit`。

## 编辑与撤销

打开窗口前固定模型身份、场景代次、历史修订、表地址、数量、显示行目标及完整原始文本。窗口中的切换和 Enter 只保存私有草稿；取消、关闭、来源失效及准备失败不写正式模型，也不创建历史节点。两种记录模式均把一次确认作为一次显式提交，无变化保留 redo。

正式窗口使用 Unicode 对话框入口和原生 Unicode EDIT、COMBOBOX。中文和补充平面字符不经过系统 ANSI 代码页。故障测试证明仅检查文本包装 API 的 BOOL 不够；正式路径现在核对原始 WM_SETTEXT 返回及 Unicode 实际读回。初始化或切换条目的拒绝、截断会取消整个草稿，避免将上一条文本保存到下一条。IME 组合中不把 Enter 当作提交；本轮真实控件字符输入不能代替微软拼音组合态真机验收。

准备阶段分配全部 Unicode 缓冲、显示组 sidecar 节点及历史资源。最终发布只移交所有权和复制已准备字节，不分配内存、不重新读取文件、不求值场景或移动播放头。撤销与重做保持未登记姿态、当前选择及其他模型状态，并刷新原列表。实际变化沿用模型文件的 sticky 保存提醒；撤销不清除可能由其他模型修改设置的提醒。

原始宽文本按已登记的完整分配容量保存，包括早期 NUL 后的字节。恢复使用原有分配／释放家族。会被替换的原始宽指针必须由一个模型字段独占，拒绝会产生悬空别名的来源。

## 标准字段与工程扩展

能精确编码为 CP932、且能留出终止符的新文本会同步更新原始短字段及显示行镜像。其他文本保存在 Unicode 数据中，旧短字段保持原字节；没有扩大 PMM、PMD、VMD 或 VPD 的标准字段。

PMM 继续使用既有 `org.mikumikustudio.model.<slot>.unicode.v1` 名称记录，编码体不变。双语言备注使用独立的 `org.mikumikustudio.model.<slot>.comments.v1`：小端 u32 版本 1、u32 语言存在掩码，再按本地语言、英语的顺序保存存在的 UTF-8 字符串。仅允许掩码的低两位；字符串沿用 u32 字节长度。新记录使用 MMS trailer，不增加 MDS 读取别名。

每种语言独立保存，有 Unicode 时保留显式空串。没有 Unicode 且原始 CP932 已被旧读取器截断时，该语言不生成覆盖值，重新打开沿用源模型备注；另一语言仍可保存。已登记的 Unicode 分配若首个 NUL 后还有非零字节，同样省略该语言，保留源模型的完整原始分配；全零 padding 不妨碍显式空串。这避免新增扩展令旧模型无法保存工程，也不把替换字或字符串前缀冒充原文。缺记录保留源备注，未知版本不解释；已知版本的损坏记录拒绝加载。所有目标模型的解析、缓冲和 sidecar 准备均成功后才一起发布，后面模型的错误不留下前面模型的部分修改。

标准 PMD 保存前逐语言比较实际写出的字段与规范 Unicode 内容。允许原有完整 20 字节名称、50 字节分组和 256 字节备注；新 Unicode 内容无法编码或与实际短字段不同则拒绝，避免静默写出旧文本。显示用跨语言回退不参与这项比较。VMD 的名称判断、标准读写及 motion 扩展没有改动。
