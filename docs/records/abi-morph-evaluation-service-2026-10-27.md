# 表情通道的公开求值服务

## 本批能力

`mms.scene.evaluate` 1.1 在同一个服务中追加通道选择、扩展源描述、表情枚举和表情权重采样。掩码 `1`、`2`、`3` 分别捕获骨骼、表情或两者。1.0 的 72 字节函数表和骨骼创建语义不变，1.1 保留相同前缀，追加四个入口，表大小为 104 字节。完整字段、错误码及 C11 示例见 [SDK 参考](../../sdk/mms/evaluation.md)。

生产工厂只检查并冻结选中的通道。损坏的表情动作不影响骨骼单选请求，损坏的骨骼动作也不影响表情单选请求。组合请求在所有准备及校验完成后才发布源，任一通道失败都保留调用方输出，不发布部分源。

表情 ID 与 `mms.scene` 的绑定快照一致，描述携带原类型、面板及基础表情标志。权重来自已注册原生关键帧和私有协调的自由曲线，保留负数及超过 1 的有限值。后台按有理数秒读取，无需移动主播放头，不修改当前编辑姿态、作者数据或工程历史。旧源不受后续动作编辑、模型删除和工程重载影响。

骨骼与表情共用源身份、`captureId`、保留字节额度、句柄及停止保护。每份源 64 MiB、每插件 128 MiB、服务总计 256 MiB，包含两类记录与两套索引的计费。`retain` 共享数据，不重复计费。最后一个句柄释放后，执行中的骨骼或表情采样仍保活数据和插件上下文，采样结束才归还额度。

## 支持边界

表情输出仅为轨道的直接权重，不执行组或翻转展开，也不计算顶点、骨骼、UV、材质的最终形变。当前未注册权重不参与采样。类型枚举通过不等于形变渲染已经支持该类型。

模型显示、IK 开关、随时间变化的外部父级、层级与约束、负帧、动作层、独立物理、完整场景帧及多视口仍待实现。局部通道不等于 `ANIMATED` 世界矩阵。原始兼容产品仍未开放生产求值工厂，该配置的专项使用注入捕获器验证公共运行时。

本批只使用 CPU，不新增图形或系统依赖，不改变 VMD 格式、插值及标记规则。Win7 SP1 x64、CPU、AMD 要求不变，Win7 与 AMD 真机仍未验收。真实生产宿主本批使用 PMX；PMD 基础表情标志有公共存储测试，未增加真实 PMD 宿主验收。
