# main 近景阴影细节层与分层采样同步

日期：2026-10-23 至 2026-10-24。工作区为 `D:/MMD-Next/MMS-abi-dev`，分支 `codex/plugin-abi`，起始提交为 `d9b931c`。本批按行为同步 main 已提交的 `0fa22b9`，不读取或覆盖 main 工作区文件。ABI 侧重新实现，未机械合并提交。

## 来源与行为

`0fa22b9` 改动的是近景细节阴影与远景覆盖阴影的分层关系：

- 细节层的覆盖区从当前摄像机画面推出。焦点深度取帧焦点经最终 `world * view` 变换后的视图深度；深度区间以焦点为中心，厚度等于焦点平面上画面的世界对角线；正交视图用可见对角线。区间不越出投影近平面与裁剪远平面。相机拉近或视场收窄时覆盖的世界范围按比例缩小；相机只绕焦点旋转时包围球半径不变。半径下限从 5 个世界单位降到 0.0001。
- 远景覆盖层的投影、深度和方向光基不随精度滑条或相机拟合变化；模式 2 的相机相关 Y 增益固定，避免旋转或精度变化改变偏差与深浅。
- 细节层和覆盖层共用一个像素按视图深度混合的采样规则；细节层贴图尺寸只由精度滑条决定，各档共享同一网格与深度映射。
- 独立「动态精度」复选框退役，精度滑条只改变采样密度，不再改变工程阴影范围。

## 实现

纯函数与着色器部分直接采用上一轮核对过的 main 实现，再按 ABI 架构接入：

- [native_shadow_projection.hpp](../../include/mikumikustudio/native_shadow_projection.hpp)：新增 `VisibleShadowReceivers`、稳定接收范围的聚焦拟合路径、`DetailShadowProjection`、`CameraShadowRegion`、`CameraDepthShadowRegion` 与 `CameraDetailShadowProjection`。ABI 上一批为实现 `fed9768` 行为自行加入的 `VisibleShadowReceiverBounds`、`FiniteNativeShadowBounds` 随旧拟合方案一并移除，对应的 `native_shadow_receiver_tests` 删除；其真实设备接线测试被重写为下述 wiring 测试。
- [adaptive_shadow.cpp](../../src/render/adaptive_shadow.cpp)：`UpdateAdaptiveShadowMap` 改为覆盖投影固定、细节区域跟随相机、精度决定尺寸的结构。ABI 的中央设置约定保留：阴影偏好仍存 `data/settings.json` 的 `shadow` 段，旧 `Data/adaptive_shadow.ini` 只作为迁移来源；动态精度加载后恒为关闭。
- [shadow_filter.hpp](../../include/mikumikustudio/shadow_filter.hpp)、[shadow_filter.cpp](../../src/render/shadow_filter.cpp)：新增 `PlanDetail`、`PrepareDetail`、`MarkDetailRendered`、`ConfigureDetailReceiver` 与 `ReadDetailInfo`。细节图独立于已有的平滑滤波，滤波关闭时细节层仍可工作；设备丢失与渲染目标切换路径沿用既有 `FineDepthTarget`。
- [skin_effect_sm3.fx](../../res/assets/skin_effect_sm3.fx)：加入 `MdsShadowToNative`、`MdsStableShadowGrid`、`MdsDetailTexelSize`、`MdsDetailEnabled`、`MdsCoverageToDetail`、`MdsDetailDepthBlend` 与细节采样器；原生材质斜坡改为先还原覆盖投影再比较深度，细节层按边缘与深度权重混合。
- [model_renderers.cpp](../../src/render/model_renderers.cpp)：覆盖图渲染完成后额外渲染细节图，保留附件 caster、恢复投影与渲染目标状态；[accessory.cpp](../../src/render/accessory.cpp) 在附件效果路径显式关闭细节接收者，避免附件本地变换误用模型矩阵。
- UI：`ui_init` 不再创建动态精度复选框；`wm_paint`、`ui_windowsize`、`ui_translation` 更新精度标签与布局；`ui_frame_refresh` 在时间轴换帧导致滑杆位置变化时立即重绘滑轨；`command_control_500` 将退役 ID 固定为关闭状态；`native_ui_catalog` 不再登记该控件。

ABI 与 main 的差异：没有移植 main 的 `model_vertex_cache::ShadowBounds` 帧内包围盒缓存，阴影包围盒仍每次锁定顶点缓冲读取，包围盒数值不变，属性能差异；其余差异见文末。
