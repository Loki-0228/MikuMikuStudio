# 灯光与 Morph 滑杆共同历史迁移

本批在 `D:/MMD-Next/MMS-abi-dev` 的 `codex/plugin-abi` 同时迁移灯光六滑杆 `455..460` 和四类 Morph 权重滑杆 `505/510/515/520`。分工为灯光、Morph 和剩余写入审计三个子任务；子任务遇到调用额度限制后，主 agent 接手补齐实际宿主测试、边界修正、整合与验证。

## 灯光滑杆

内部入口 `TryCommitBoundLightSlider` 校验主窗口实际 HWND 和控件 ID。RGB 保留整数刻度除以 256 的换算，方向保留除以 100 的 double 运算及最终 float 存储。复用既有 `LightPoseChange`，每个有效位置立即提交一条共同历史；CPU 灯光镜像与作者字段共同发布，窗口及 GPU 更新在发布完成后执行。

RGB 整数刻度可精确往返。方向的 `-.53f` 乘以 100 后可能向零截断成 `-52`；刷新优先保留与作者值对应的当前刻度。恢复、撤销或失败回读时，如果最近整数刻度能精确映射回作者 float，则用该整数，否则保留原截断规则。该处理只调整控件显示，不量化作者值。

## Morph 滑杆

内部入口 `TryCommitBoundMorphSlider` 将实际主窗口滑杆映射到对应 lane，再按当前模型、选中 Morph 和键池身份复用 `MorphValueChange`。保留刻度除以 100 的 double 运算、原索引零及 physicsMode 门禁，不采样关键帧或改写旧撤销环。历史仍绑定原模型和原 Morph，切换当前模型、选择器、编辑模式或播放头后可以按共同历史顺序恢复。

成功时保留原始刻度，并按旧显示精度回显。失败时滑块恢复当前作者值，未提交的文本继续保留。通用安全刷新同样保留可精确映射回作者 float 的整数刻度，避免 `.53f` 从 53 降为 52，再由 ENDTRACK 生成意外修改。对应旧文本测试原先预期下降为 52，本轮改为检查保持 53；非整百分比权重仍按既有截断规则显示。

## 共同约束

两种入口仅在绑定共同历史时消费通知，成功、无操作和拒绝均不回落旧写入。普通未绑定宿主和原始兼容 profile 保留旧路径。每个有效位置独立撤销，当前不将一次完整拖动合并为一个节点。

重复位置、结束通知和相同值不增加历史、不清除 redo。只有正在编辑的滑杆可以使用自身鼠标捕获例外；其他滑杆、普通灯光或 Morph API 不能借用此例外。播放、录制、模态编辑、未完成插件事务及历史忙碌等门禁继续生效。准备失败不留下部分作者值、CPU 镜像、dirty 或选择修改，滑块恢复不追加补偿历史。

## 剩余写入

本轮已消除上述十个滑杆在受控绑定下的旧写入路径，普通宿主仍不提供 `mms.edit`。只读审计与主 agent 核对确认还存在以下候选：

- `src/window/frame_line_edit.cpp` 中的帧线插删及其旧撤销准备。
- `src/window/command_control_400.cpp` 的关键帧粘贴 `421`、镜像粘贴 `422`。
- VMD 动作导入 `209` 及拖放入口。
- `src/app/frame_modes.cpp` 的视口姿态操作，仍有直接 `PushBoneEditUndo` 调用。

这些项目不构成全部剩余入口清单，后续逐项确认迁移范围与失败原子性。本批没有新增公共 C ABI、修改 main 或配置路径、覆盖稳定版程序、关闭用户实例。Win7 SP1 x64、CPU 基础路径和 AMD 兼容要求保持；真实设备及原始兼容 profile 独立重建未在本批验收。
