# 独立骨架工作区装配方案

本文为待实现方案。已有定义、动作、显示、表情、姿态准备、五阶段求解和独立尺度模块，不等于完整场景帧已经实现。

## 来源与所有权

在同一个 UI 安全点捕获骨架定义、骨骼动作、显示轨道、表情定义及表情权重，归入一个不可变来源包。每个来源持有同一捕获身份，后台只读。单独快照的数量相等不能证明它们属于同次捕获。

每次求值创建自己的骨表、运行 IK 链、嵌套链接、selector、骨骼表情偏移、尺度和矩阵输出。数学上下文以共享只读租约保留。结果帧独立拥有数据，来源与工作区释放后仍可读取。

骨骼从 `BoneDefinition` 逐字段恢复，保留名称、类型、flags、hasFlag、layer、parent、tailBone、tailIdx、inheritRatio、静止位置、轴、IK 限制、slotIndex 和 hasRigidBody。PMD 膝盖逻辑读取名称；CoRotate 的 tailIdx 是百分率。PMX 原链接和运行链分别拥有，不以原参数重新生成加载器已经调整过的运行链。

## 确定起点与求值顺序

工作区不复制当前编辑姿态或旧矩阵。PMX 加载器清零后将两组局部四元数 w 和 matWorld 对角设为 1；PMD 的初始 matWorld 只有索引 10、15 为 1。应逐字段复现确定起点，并用同样初始化的原生对照验证。不能未经验证统一设为四张单位矩阵，也不能宣称复现依赖上一帧残留状态的任意模型。

每个目标时间按以下顺序执行：

1. `PrepareKinematicChannels` 填充 trans、rotQuat、physicsDisabled，并保存完整尺度。
2. 显示快照填充每条运行 IK 链的原始 enabled 字节及父级选择，检查其映射与定义一致。
3. 表情权重经 `MorphEvaluationFrame` 得到自有骨骼偏移；不再次乘权重，也不把偏移当作最终旋转。
4. `BonePreparePosePrivate(model, 0, context)` 后执行物理前各层。
5. 再次准备姿态，保留前阶段矩阵，执行物理后各层。
6. 复制最终 matInit 作为刚性 baseline，再用 `BuildTransformsPrivate` 生成尺度结果。

形参 0 表示不模拟物理。`model.physicsMode` 保留格式语义，PMX 仍为 2，否则骨骼表情及 IK 分支都会改变。physicsDisabled 是动作元数据，IK enabled 来自显示轨道，二者独立。

保留原骨骼索引和层内遍历，不拓扑重排。按实际出现且处于 `[0, maxBoneLayer]` 的层号升序执行，跳过空层，避免遍历巨大上界。负层及越过上界的骨骼保持原跳过行为及确定初值，并分别验证。定义捕获已拒绝非零骨数而无 selector 0 的情况。

## 外部父级输入

`ResolveBoneWorld` 实际读取外部目标的静止位置 `position[3]` 和未加显示尺度的 `matExtra[16]`。内部工作区可以用自有代理表承载这些显式依赖，重映射工作 selector 的模型槽与骨骼索引。原显示快照的 raw pair 和时间窗口保持不变，继续参与局部插值。

依赖必须绑定目标身份、捕获来源、时间和物理前后阶段。原宿主先执行全场物理前阶段，再执行全场物理后阶段，目标矩阵可能在两阶段间变化。只给一份最终矩阵只能表达固定附着输入，不能算作跨模型原生顺序验收。尺度后的 matInit 不能替代 matExtra。

没有提供活动外亲所需输入时应明确失败，不允许清成无父级再返回成功。最终场景层仍须完成目标动作冻结、身份解析、分阶段调度和循环处理；单模型内部入口不替代这些需求。

## 发布与验收

预算覆盖来源、工作数组、嵌套链接、依赖代理及输出容量，乘加先做溢出检查。失败只销毁候选，不发布半帧。输出矩阵与关节位置检查非有限值；关节位置是静止位置乘变换矩阵，不能直接取平移列。

验收须包含真实 PMX 和 PMD、非零 IK 控制运动、骨骼表情、非单位尺度、不同层、前后物理路由，以及编辑、删除、槽位复用和工程切换后的旧来源读取。使用禁用 IK 对照证明求解路径生效，逐阶段比较刚性矩阵，再验证尺度结果与关节位置。跨模型需有目标随时间变化和两阶段变化的对照，不能只用静态附件证明。

公开帧租约、蒙皮、渲染器和多视口要在上述结果基础上继续实现。历史物理须独立声明缓存、烘焙或模拟支持范围，不能用无物理结果冒充物理阶段。
