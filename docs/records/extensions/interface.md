<a id="record-mmv-ui-implementation-外置描述与算法源码"></a>
### 外置描述与算法源码

作者文件为 FX 语法，不使用先前试验的 `ui { ... }` 文本格式。内部 `ParseLayout` 保留用于数据路径测试；公开帮助、示例和文件加载均使用 FX 变量声明与注解。

`parameter_metadata.inl` 在相同预处理流程中读取描述文件，核对原变量的名称、类型与可写性，再生成 `Schema`。原 DX9 FX 源文本保持不变。原生 DX12 参数仅在内存编译副本中改为自动 b1 常量块，写盘测试验证原文件未变化。

外置描述的默认扩展名由 `.mmvui` 改为 `.uifx`，改动在 `parameter_metadata.inl` 的 `layout.replace_extension` 一处。默认查找只做 `Face.fx` → `Face.uifx`，`.uifx` 缺失时不会回退到同名 `.mmvui`，也不把该文件计入热重载来源；随包 6 个描述文件已改名为 `.uifx`，三个透视样例的 `#include` 同步指向 `perspective_controls.uifx`。`MMVConfig` 的 `string MMVUI="..."` 显式路径仍按写下的后缀读取，加载器不附加也不校验后缀，旧文件可以由显式路径继续指到，因此旧同名文件需要改名，而不是靠回退兼容。`MMVUI`、`MMVUIGroup_*` 注解名，以及 `.vmm/.vem` 参数轨道、稳定 ID、关键帧、多语言、面板布局与热重载语义均未改变。

<a id="record-mmv-ui-scope-acceptance-本轮行为"></a>
### 本轮行为

- MMV 菜单位于右侧 MME 菜单左侧，随宿主切换日、英、中三语。
- 参数窗静态标签填充系统对话框底色；输入框和只读诊断区保留原生输入区背景。
- 模型、骨骼、表情使用宿主名称选择逻辑。PMX 材质加载时保留原名和英文名，优先使用操作语言对应字段，缺失则回退。中文界面沿用 MMS 的原名规则，不自动翻译模型文本。
- 显示名称与存档身份分离。两个固定页签各自保存分配和展开状态，固定展开类型不可修改。FX 扩展页支持 `MMVExpand` 声明和右键操作。
- 骨骼分配先于材质分配执行；骨骼行按该骨骼的归一化权重混合网格效果。刚体和 joint 保持为整个对象的只读查询数据，不增加独立分配组。
- 选中效果行后嵌入真实参数面板；切换页签切换对应实例，支持 `.uifx` 描述、三语、K 帧与配置热重载。保存格式升级至版本 2，并继续读取版本 1。

骨骼分配当前修改的是渲染网格，不是骨骼位姿输出。本轮没有实现 VMD 烧录接口；后续接口只允许烧录骨骼位置与旋转，不能把任意网格变形自动反推为骨骼。

<a id="record-mmv-curve-ui-validation-修复内容"></a>
### 修复内容

- 参数浮窗在 `WM_NCCREATE` 时保存真实窗口句柄，使非客户区计算调用正确的 `DefWindowProc`。窗口恢复标题栏、缩放边框，并居中于所属窗口、限制在显示器工作区内。
- 相同语言不重复填充下拉列表；枚举列表展开时跳过逐帧数值同步。
- 分配表与参数区随窗口高度分配空间，窄窗口工具栏换行，说明文字预留两行，空关键帧列表不再占用固定的大块高度。
- 「烘焙」位于「帮助」左侧。语言切换、模型载入、播放和重置通过 About 命令 201 定位帮助菜单，不依赖旧序号 7。
- 附件、摄像机、灯光、自阴影、重力，以及 MMV 参数共用曲线浮窗。支持增删帧、切线、贝塞尔手柄、所选通道烘焙及 VMD 尾部扩展。模型表情入口未纳入本次交付。

## MMV 骨骼与材质分配

原始记录：`MMV_ASSIGNMENT_SCOPE_DESIGN.md`。其中的版本、日期和验证范围沿用原记录。

Bullet3 先从刚体求解骨骼姿态，再通过蒙皮输出顶点。因此，骨骼分配是合理的物理入口。网格是插件交给渲染器的数据格式，不决定用户必须从材质入口操作。

本次设计按用户确认的分层规则替换早期的两个固定分配页。MMV 自带层固定为 0，只有一个内置分配页，可按骨骼或材质展开。MME 固定为 -1，负责最终绘制，不占 MMV 层数。正层属于 MMV 附件和效果处理，层号只记录在工程配置中，不写入 `.x`。

<a id="record-mmv-assignment-scope-design-作用范围与输出"></a>
### 作用范围与输出

同一个分配页的模型整行表示整个模型，骨骼子行和材质子行分别指定作用范围。展开方式只是选择范围的操作，不把已有骨骼分配改写成材质分配。

| 效果与范围 | 实际处理 |
| --- | --- |
| Bullet3，模型整行 | 为模型刚体提供默认物理规则 |
| Bullet3，骨骼子行 | 选择绑定到该骨骼的刚体，覆盖模型默认规则 |
| 普通网格 FX，骨骼子行 | 按该骨骼的顶点权重混合网格结果 |
| 普通网格 FX，材质子行 | 修改该材质引用的几何，可拆分共享顶点 |

Bullet3 骨骼分组在同一个世界求解，保留碰撞和跨组关节。模型中没有选中的刚体作为动画碰撞体。物理求解和蒙皮完成后，不再对物理输出追加一次骨骼权重混合。不同组可分别设置重力、地面碰撞和编辑模拟；共享世界采用各组中最大的模拟频率和约束迭代次数。

物理解算产生的完整结构供 MMV 下游层读取，包含骨骼、绑定权重、刚体、joint 和碰撞形状。
第 0 层到 MME -1 仍通过 `MmvObjectOutput.mesh` 交接，不写回 MMS 原生骨骼或刚体。
显式烘焙由独立事务处理。完整循环接口见 [MMV 总接口](effects.md#record-mmv-fx-原生结构与状态循环)。

<a id="record-mmv-assignment-scope-design-层间数据"></a>
### 层间数据

MMV 按正层编号从大到小执行，再执行 0 层，最后交给 -1 层 MME。每层保存一份上游输入。该层的效果都读取这份输入，无法读取同层其他附件尚未合并的结果。全部完成后合并输出，供下一层读取。

同层保存独立的绘制顺序，靠后的效果覆盖靠前的效果。运行时倒序处理，已被后置效果覆盖的范围不再重复计算或写入；返回原样输入也会占用对应范围。这个顺序不建立同层读取依赖，需要依次变形时应使用不同层。同一物理世界的 Bullet3 分组位于同一层；物理应位于其他几何变形之前。

骨骼与材质范围交叉时，合并保留后置效果的范围。若拓扑变化删除或重排了用于保留后置骨骼输出的顶点，运行时拒绝该层输出并说明原因；将这种拓扑变化移到上游层后，下游范围按新的输入表展开。

分配列表按所选层的输入快照展开。本层新增骨骼和材质只能在下一层分配，不能提前出现在本层输入列表。
新骨骼分配使用稳定键；旧索引/名称形式必须同时匹配，不因名称相似而重定向。
加载对象预设时，缺失附件、效果目标、骨骼或材质会拒绝整套配置并报告原因。

<a id="record-mmv-assignment-scope-design-展开操作"></a>
### 展开操作

默认按骨骼展开，但默认不允许展开。右键菜单提供「是否展开」和「切换展开方式」。未允许展开时，箭头为灰色，点击、双击和键盘均不会打开子行。开启许可后，箭头控制实际开合。

展开许可、开合状态和骨骼／材质模式按层保存到 VMM 与对象 VEM 文件。切换层后只显示该层的对象、目标页和参数。文件合同见[存档参考](usage.md#record-mmv-storage)。

<a id="record-mmv-assignment-scope-design-初始错误的来源"></a>
### 初始错误的来源

2026-09-27 的用户截图中，`獣音ロウ` 的 Bullet3 分配在旧「骨骼分配」页。引擎已选 Bullet3，编辑模拟已勾选，底部仍显示：

```text
Bullet3 FX must be assigned to a model's main output
```

旧 `PrepareBullet3` 只接受没有骨骼和材质范围的 `Target=Main`。骨骼页整行的目标是 `Bones`，因此在执行前被拒绝。把 MMS 原生物理设为「不计算」不会解除这项限制，也不会自动启动 MMV 解算。

截图中的效果行仍显示「就绪」，是因为旧回退路径把错误归到了另一个主输出绑定。本次运行时将错误记录到实际参与的绑定，避免加载成功掩盖执行失败。该截图只证明旧版分配限制，不能代替修复后 Rou 模型的运行验收。

## MMV 分配窗口撤销计划

原始记录：`MMV_EDITOR_UNDO_PLAN.md`。其中的版本、日期和验证范围沿用原记录。

状态：待实现。当前曲线编辑器的局部撤销不等于 MMV 整个分配窗口的撤销。

全局「应用」负责确认整个窗口的编辑；关闭窗口回退上次应用后的改动。这是编辑事务要求，也不能代替多步撤销。实现由 MMV 分层界面主会话统一安排。

计划覆盖分层配置、对象及骨骼／材质分配、FX 启停、参数和关键帧。一次连续拖动合并为一条撤销记录，撤销后发生新编辑时清空重做记录。不同页签的操作共用历史，不只记录当前 FX。

撤销历史只保存编辑数据；GPU 资源和物理运行状态按恢复后的配置重建。场景替换、对象删除、效果热重载、工程读取及帧率修正需要明确历史失效规则，防止恢复到已不存在的对象或层。

验收须包含跨页签连续撤销／重做、拖动参数、增删关键帧、效果移除、全局应用后再编辑并关闭，以及三语按钮状态。VMM 自动保存读取已确认配置，不写入待应用的预览或撤销历史。

<a id="record-mmv-curve-motion-plan-浮窗视野导航"></a>
### 浮窗视野导航

本节规则作用于浮窗上方曲线编辑区的画布，以及画布的时间范围条和数值范围条。范围条中央拖动平移、两端拖动缩放是用户本轮要求。滚轮平移、修饰键缩放及中键拖动的按键参照 Adobe After Effects 官方说明，具体对应见下表。

<a id="record-mmv-curve-motion-plan-视野导航与当前帧滑块的区别"></a>
#### 视野导航与当前帧滑块的区别

当前帧滑块定位播放时间。视野导航只改变画布显示的时间范围和数值范围，两者是两套独立操作：

- 不改变任何关键帧的时间与数值，不写关键帧数据。
- 不进入撤销栈，不触发烘焙，不产生需要撤销的事务。
- 不移动当前帧，不改变播放状态和播放头所在时间。
- 画布上的缩放和平移不得落到关键帧拖动上，拖动关键帧也不得改变视野。

<a id="record-mmv-curve-motion-plan-时间范围条与数值范围条"></a>
#### 时间范围条与数值范围条

画布在横向上带一条时间范围条，数值视图和速度视图在右侧各带一条纵向数值范围条。

| 拖动位置 | 行为 |
| --- | --- |
| 时间范围条中部 | 平移时间范围，保持当前时间跨度不变 |
| 时间范围条左端 | 缩放时间范围，固定右端时间 |
| 时间范围条右端 | 缩放时间范围，固定左端时间 |
| 数值范围条中部 | 平移数值范围，保持当前数值跨度不变 |
| 数值范围条上端 | 缩放数值范围，固定下端数值 |
| 数值范围条下端 | 缩放数值范围，固定上端数值 |

两端不能交叉。预览最小时间跨度为 1 帧，最小数值跨度为 0.00001；正式实现须按通道单位确定合理的精度下限。拖动到最小跨度后停止收缩，避免跨度为零造成除零。视野很小时，范围条的两端手柄和中部拖拽区仍保留最小可点击尺寸；其视觉宽度可能不再与范围严格成比例，精确范围由读数表示。触摸模式三段各至少 44 逻辑像素。

范围条的中部与两端都可以用键盘操作。手柄取得焦点后，方向键执行与鼠标拖动相同的平移或缩放：时间每次调整 1 帧，数值每次调整当前跨度的 2%，Shift 加方向键按十倍步长调整。

浮窗左侧的通道树列出全部可编辑通道：

<a id="record-mmv-curve-motion-plan-速度视图"></a>
### 速度视图

速度是数值视图所画同一条曲线的导数，单位是数值单位每秒。标量通道的速度带正负号，负值表示数值随时间下降。

位置这类向量通道按分量分别计算和显示速度。合速度模长只能作为派生预览显示，不能当作一条可编辑的速度轨道，也不能和分量速度放在同一行。

数值视图和速度视图编辑的是同一批关键帧和同一条切线。两个视图不能各自保存一条互相矛盾的速度轨道。在任一视图修改关键帧或切线后，另一个视图按同一曲线立即重算。

<a id="record-mmv-curve-motion-plan-mmd-局部手柄与完整曲线"></a>
### MMD 局部手柄与完整曲线

原版 MMD 的 0–127 局部区间手柄是兼容视图，只能表达手柄允许范围内的入段与出段形状。完整 F-curve 还能表达等值端点之间的起伏和过冲，因此编辑器显示或写回完整曲线时，不能无提示地把数值钳到 0–127 手柄能表达的范围内。等值端点无法通过除以端点差来归一化。超出局部手柄表达能力的曲线须用完整曲线编辑，并提示该区间无法由原版手柄表示。

<a id="record-mmv-curve-motion-plan-切线模式与显示"></a>
### 切线模式与显示

切线提供四种模式：

- 自由：入切线与出切线分别设置。
- 对齐：两侧手柄共线，入段与出段端点速率相同，影响长度可以不同。
- 水平：切线水平，在关键帧处形成平坦极值。
- 线性：目标区间两端都采用连接端点的割线斜率，使该区间速度恒定。只改变一个端点手柄不算线性区间。修改涉及相邻关键帧时一并纳入撤销事务。

自动切线带防过冲规则：自动切线若会在相邻关键帧之间产生超出这两个关键帧数值范围的过冲，编辑器降低切线速率以消除过冲。该调整必须可见，并且能被手动切线覆盖。

每个关键帧显示入切线和出切线的速率与影响长度。速率决定曲线在关键帧处的斜率，影响长度决定两侧控制点沿时间轴的延伸距离。两项都可以分别编辑。

<a id="record-mmv-curve-motion-plan-求值与边界情况"></a>
### 求值与边界情况

- 零分母：同一通道不得提交重复时刻。导入按明确的冲突规则处理，不构造零长度曲线。遇到无效时间切线时拒绝修改或回退，并报告原因，不输出非有限值。
- 离散键跳变：布尔、枚举、父绑定等离散通道按阶跃求值，跳变处的速度是脉冲，不能平滑成连续曲线。离散通道默认不显示速度视图。
- 向量单位不同：位置用长度单位，旋转用角度，透明度和参数用无量纲值或百分比。不同量纲的通道不能共用一条速度纵轴，适配范围按通道计算。
- 帧率：速度按每秒计算，等于每帧导数乘以动作时间基准的帧率。同样的帧号和值在更高帧率下播放，速度会变大。仅切换帧与秒的显示单位不改变动作；导出渲染帧率也不能暗中改写动作的时间基准。
- 显示与锁定：通道的隐藏和锁定只影响编辑与显示，不改变渲染启停，也不改变求值和烘焙结果。

<a id="record-mmv-curve-motion-plan-曲线与关键帧语义"></a>
### 曲线与关键帧语义

连续浮点通道支持阶跃、线性、现有平滑插值和自定义三次贝塞尔。布尔、枚举和父绑定采用阶跃。当前 MMV 整数参数也按阶跃求值，不能在扩展中无提示地改变既有行为。

贝塞尔求值先由时间求曲线参数，再取得数值进度。不得把时间直接当作曲线参数。手柄时间坐标保持可求逆，重复帧、零长度区间和非有限输入需要验证。原版 0–127 控制点模式与未来更广的切线模式须带独立版本或模式字段，不能改变旧数据含义。

新曲线段拟归属于结束关键帧的入段，与原版骨骼曲线的操作习惯对齐。当前 MMV 的 `parameters::Evaluate` 使用起始键 `before.interpolation`。实现必须版本化迁移旧段属性，不能仅新增字段后改变旧工程动画。

`.x` 的位置和旋转在本次审计的播放代码中按离散状态应用，缩放和透明度使用线性插值。扩展加入后，旧工程保持旧行为，只有显式设置曲线的通道采用新求值。

<a id="record-mmv-curve-motion-plan-vmd-必须保留原版可读取的标准数据"></a>
### VMD 必须保留原版可读取的标准数据

VMD 扩展只能追加在完整标准数据区之后。标准头、各段计数、记录布局和标准编码保持兼容。标准数据能表达的骨骼、表情、相机、灯光、自阴影、显示与 IK 数据仍写入对应标准段，不能全部迁入扩展。

本仓库标准写出器依次写完各段，并在显示与 IK 段结束后追加扩展。这里没有独立的通用“结束符”字节。本文中的“标准结束位置”指标准记录解析完毕的边界，不是额外插入的标记。

动作分为标准投影和完整扩展两部分：

- 真实模型的骨骼和表情按原有标准记录写出。新增表情曲线不改动标准表情记录大小。
- 附件位姿按骨骼式记录处理，其精确附件身份、欧拉角表达和绑定关系保存在扩展。标准骨骼记录采用四元数，单独使用该记录不能保留多圈欧拉角编辑信息。
- FX 数值采用表情式标量轨道。向量按分量保存，扩展保留参数稳定标识、类型、分量和所属绑定。
- 若把附件或 FX 数据投影为标准代理骨骼、代理表情，名称需要合法短名和冲突检测，扩展保存完整映射。原版仅能把这些记录应用到匹配的骨骼或表情，不会因此获得附件或 FX 控制能力。超出原版可表达范围的参数以扩展数据为准，导出界面说明损失。
- 新增曲线写入扩展。需要原版按帧呈现新增表情曲线时，标准表情部分写入烘焙样本，扩展另存原始稀疏关键帧与手柄。整数帧采样不等于任意子帧完全相同，采样步长须明确。

```text
[完整标准 VMD 数据][版本化扩展数据][长度与尾部标识]
```

现有骨骼缩放使用 `MMSXVMDX` 尾部标识和 `MMSXMMSX` 版本 1 载荷（读取兼容旧 `MDSXVMDX`/`MDSXMDSX`）。它是骨骼缩放专用布局，不能直接混入附件或 FX 字段。实现须演进为可容纳多个类型的版本化容器，兼容读取已有版本 1，并保留骨骼缩放数据。不能把两个独立扩展尾部简单串联，使其中一个读写器吞掉另一段。

扩展记录标准区长度与校验值。加载器先校验标准边界，再校验扩展长度、版本、校验值和条目边界。扩展无效时提示原因，并保留标准动作的加载结果。未知类型按长度跳过；可安全保留的未知条目随文件重存，不能误解释为已知类型。扩展应用作为独立事务，不提交部分参数或部分曲线。

通用动作读取器须按记录数量完整解析或跳过每个标准段，再确认追加边界。现有模型专用加载路径仅读取相机、灯光与自阴影的计数，不能直接作为任意混合轨道文件的通用解析器。

原版程序读取标准数据是验收要求。原版重存是否保留尾部扩展不能作为保证；扩展被丢弃后，标准动作仍须有效。原版 MMD 的运行时兼容性必须实测，不能只根据仓库头文件中的静态分析说明判定通过。

### 烘焙与动作范围选择

选择树包含模型骨骼、模型表情、`.x` 附件、MMV 材质主挂载页、MMV 骨骼主挂载页。对象之下列出子通道，支持父项全选和子项选择，父项显示半选状态。范围包含起止帧、采样步长和动作导入偏移。

附件连续通道包括位置 XYZ、旋转 XYZ、统一缩放与透明度。显示、投影开关、父模型和父骨骼属于离散通道。全部表情可批量选择。MMV 只列出作者允许 K 帧的参数，向量分量保留所属参数身份。

烘焙只替换选定通道和帧范围。当前附件键是整条记录，不能把未选分量写成当前帧值或默认值。已有目标帧键作为合并基底；无键帧先求值原动画，再合并所选样本。还需保留未选通道的原曲线区间与求值语义，不能因插入合并记录改变原动画。

计算结果先暂存，全部验证成功后一次性提交，支持撤销和取消。取样不能污染播放状态、物理状态或 MMV 的下一帧输入。原生附件与模型表情的结果进入 PMM，MMV 参数的结果进入 VMM。VEM 仍为静态预设。

此处烘焙的是通道数值。逐顶点变形、增删拓扑和材质生成不能仅靠位置、旋转或参数键保留，属于独立的网格缓存功能。
