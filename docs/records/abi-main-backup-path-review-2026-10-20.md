# main 默认备份目录核对

main 在 `ff7616e` 后新增 `c147454`，将默认备份及相应错误日志位置从 `data/backups` 改为程序同级 `backups`。该提交没有独立的备份算法、崩溃恢复、并发或日志错误处理修复。

本会话要求程序自己的数据集中在程序目录的 `data`，ABI 因此保留默认 `data/backups`，不采用该默认目录变更。安装隔离、随程序搬迁、相对程序解析、不依赖当前工作目录、不回退 AppData、保留旧文件及显式自定义目录已由现有 JSON 和 INI 设置路径提供。此次核对没有修改 main 或稳定版程序。

ABI 的错误日志在默认模式下跟随 `data/backups`，用户显式选择自定义备份目录时可跟随该目录。这是既有行为，不应描述为错误日志无条件固定到默认路径。`runtime_log.cpp` 仍保留 `data` 父目录的创建，保证首次启动错误日志能够落盘。
