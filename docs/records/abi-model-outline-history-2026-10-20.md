# 模型轮廓粗细共同历史

日期：2026-10-20。分支：`codex/plugin-abi`。菜单 253 在共同历史绑定宿主中采用事务路径，普通启动的 `mms.edit` 仍未开放。

## 编辑行为

646 文本框以 Enter 提交，失焦不重复提交。647 原生滑杆在拖动期间预览，松开后提交一次；键盘连续导航以对应按键全部松开为结束，独立滚轮操作也形成一次调整。修饰键松开和拖动中的滚轮不会拆分当前历史。

「记录全部编辑操作」将每次有效调整记录为一步。「仅记录显式提交」应用粗细调整但不新增历史。取消、按下后不移动、返回原值及准备失败均保留 redo。文本保留有限负值和大于 2 的原有语义，滑杆显示范围仍为 0 至 200。

控制器保留精确原值、原始刻度和鼠标起点。拖回原滑块起点会恢复原始浮点字节，不把 `0.625` 改成 `0.62`；夹紧显示的负值和大数同样处理。像素起点只用于命中滑块的拖动，点击轨道仍执行原生翻页。全部 201 个百分比刻度可往返，避免 `1.39f` 回显成 138 而吞掉下一次键盘移动。

## 对象和生命周期

`NativeModelOutlinePlan` 只写目标模型的 `edgeScale`，不修改播放头、其他模型、动画键或物理状态。候选保留模型资源和稳定 ID，按实际保留开销检查历史预算。撤销删除恢复同一 ID 后，粗细撤销和重做允许使用新的对象 generation，不依赖重新读取模型文件。

连续调整在第一次写入前预留完整候选。首次移动前若同一字段已由其他事务修改，旧拖动取消；活动预览继续核对绑定、修订、目标及当前拥有的字段值。取消只回滚仍属于该预览的修改，不覆盖外来写入。

登记且闲置的轮廓窗口允许共同撤销、重做和对象删除。未登记窗口、其他窗口、失效绑定、正在处理回调或活动手势仍保持拒绝。永久窗口标记防止初始化失败或解绑后回退旧版直接写入；失败时禁用控件，重新绑定后可安全连接。切换模型不把旧模型草稿或旧滑动通知应用到新模型。

回显期间重入关闭会延后到消息边界。关闭按钮、取消及父窗口销毁均回收控制器，按准确 HWND 清除引用。绑定退出时先取消预览，再释放历史依赖。

## 保留边界

本批不修改标准 PMM、VMD 或 VPD 格式，也不开放普通公共编辑服务。模型轮廓颜色、增强模型、其他资源编辑及可写属性 INPUT 仍需继续迁移。Win7 SP1 x64、CPU 基础路径和 AMD 兼容要求保持，本机结果不代替 Win7 和 AMD 真机验收。main 工作区和稳定程序未修改。
