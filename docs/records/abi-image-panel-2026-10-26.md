# CPU 图像面板 SDK 验收

## 实现范围

新增 [`CpuImageCanvas` 和 `ImagePanel`](../../sdk/mms/image-panel.md)。前者将只读 RGBA/BGRA 图像映射合成为不透明 BGRA 画布；后者提供原 `mms.ui.surface` 的单视图工厂，通过 `mms.render.image` 保留读取映射，在原 PANEL 元素中显示并适应尺寸变化。没有增加另一套底层 C ABI、注册身份或宿主存储。

支持 Contain 等比例居中和 Stretch 拉伸、最近邻采样、三种 alpha 模式与可选背景色。输入映射与完整输出候选准备成功后才替换当前显示。图像句柄可在设置后释放，独立映射持续保留数据；临时销毁/重建视图不丢失图像。面板及窗口类在显式 `Close` 中清理，存在活动视图时拒绝绕过注册表关闭。

换图和选项修改限制在 UI 线程，只使本面板失效，不触发场景求值、播放头、工程写入或历史记录。后台任务通过已有图像服务与 `enqueueUi` 组合。画布每张最大 64 MiB，候选与旧画布可能同时存在，插件仍须管理总量与频率。初次创建复用 WM_SIZE 已准备的画布，避免重复整幅合成。

新增原创 [image_panel 示例](../../sdk/mms/examples/image_panel/plugin.cpp)、清单及构建目标。它在工作区扩展页签显示四色透明度图，演示原注册束、图像句柄释放与停止顺序。不会自动部署到稳定版。
