# 分隔线实时拖动与测试面板修复（2026-10-17）

用户对独立 ABI 测试副本的真实鼠标反馈为：侧栏和底部区域分隔线不跟手。截图另显示原创生命周期测试插件面板的 STATIC 标题与 EDIT 输入框重叠。本批在 `D:/MMD-Next/MMS-abi-dev` 的 `codex/plugin-abi` 中修复这些问题，不修改 main、配置路径或公共 C ABI。

## 侧栏实时布局

原实现只记录拖动位置，松开鼠标后才提交侧栏宽度。本批让 `HandleMouseMove` 在侧栏捕获期间优先调用 `UpdateSidebarResize`，不再进入自动隐藏、时间线和视口工具的其他鼠标分支。

`ApplySidebarGeometry` 更新宽度和比例，再统一调整子控件与视口。子控件移动期间保留拖动标记，抑制中间绘制；布局一致后统一重绘。相同或限制后未变化的位置不重复布局。这是代码中的重绘安排，新版本是否跟手且无残影仍需用户实测。

拖动开始保存原宽度和比例。正常松开先更新最后位置，再清除拖动会话，避免 `ReleaseCapture` 同步发出的 `WM_CAPTURECHANGED` 把已提交宽度恢复。Esc、取消和异常捕获丢失通过 `CancelSidebarResize` 恢复起始布局。取消与正常完成使用不同路径。

## 底部区域实时布局

`HandleBottomPanelResize` 在鼠标移动期间更新区域附加宽度。计算可用空间时按拖动开始时的宽度预留兄弟区域，避免向左收缩后无法拖回右侧。窗口限制导致实际宽度小于请求宽度时，拖动起点按实际宽度调整，防止首次移动跳变。

有效宽度变化后进入临时批绘范围，暂停布局就绪标记，统一移动底部、视口及表情控件并抑制中间重绘。退出批绘后恢复标记，再重绘底部区域。批绘期间保持侧栏精确像素宽度，不重新用比例截断，也不调用无关插件布局。重复位置及相同位置的释放消息不重复布局。正常释放保留最终值；Esc、取消或捕获丢失恢复原请求宽度。鼠标捕获失败时不保留活动拖动状态。

## 生命周期测试面板

`tests/plugins/lifecycle_plugin.cpp` 将承载 EDIT 的 STATIC 父窗口标题清空，避免父窗口文字与输入内容重叠。`LayoutPanel` 按父窗口当前客户区安排输入框，四周通常保留 8 个客户区单位，输入框高度最多 24。窄小区域按可用尺寸收缩，避免原固定宽度超出区域。

创建与 `ResizePanel` 均调用该布局函数。坐标沿用宿主 DPI 上下文，不对 DPI-unaware 窗口再次乘屏幕缩放。此处修改是原创样例插件，不代表任意第三方原生控件自动获得相同布局行为。
