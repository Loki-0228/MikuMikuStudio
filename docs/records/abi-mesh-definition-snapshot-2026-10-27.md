# 独立网格定义快照（2026-10-27）

本批基于 `codex/plugin-abi` 的 `85b8cac`，新增内部 `MeshDefinitionSnapshot`。它在调用方串行的安全点深拷贝已加载模型的基础网格与活动蒙皮输入，为后续独立 CPU 蒙皮和场景帧提供不借用活体模型的数据。本批不计算蒙皮，也不开放新的插件 ABI。

## 捕获范围

快照保留 PMD/PMX 格式、骨骼数、顶点位置、法线、基础 UV、0–4 组附加 UV、活动骨骼索引与权重、边缘参数、三角顶点索引和原材质分段。PMX 额外 UV 从宿主按分量排列转换为按组排列；PMD 索引按宿主实际四字节步长读取。

PMX 支持 BDEF1、BDEF2、BDEF4 和 SDEF 的活动字段。BDEF1 权重为 1，BDEF2 与 SDEF 保留原第一权重并计算 `1 - w`，BDEF4 保留四个原始权重及顺序；不做归一化。SDEF 的中心及加载器已经重基的 R0/R1 偏移原样复制，不再变换。PMD 保留有符号权重百分比及边缘字节，并按原生常量计算两个权重。

活动骨骼索引原样保留，不解引用越界索引。原 CPU 路径对缺骨使用零矩阵及对应辅助值，未来独立蒙皮必须延续该行为。QDEF 和未知权重类型抛出单独的 `MeshDefinitionUnsupported`，不得当作 BDEF4。当前本体 PMX 加载器只接受 2.0，本批不表示支持 PMX 2.1 文件。

工作顶点可能已叠加表情。捕获先复制，再依照原顺序将位置和 UV 恢复表应用于私有副本；重复项保持后写覆盖。基础 UV 仅读取两个有效分量，未启用的附加 UV、权重及 SDEF 字段不读取。结果不保存材质颜色、纹理路径、表情定义、骨骼定义、当前姿态或设备资源；这些数据需由其他快照在同一安全点组合。

## 所有权和预算

快照完成后不持有源指针。顶点、三角形、材质分段和索引可以并发、无分配读取；无效索引不改变输出。默认保留上限为 64 MiB，计算包含对象和实际容器容量，不表示捕获期进程峰值内存。计数、表指针、有效几何索引、材质范围、活动有限浮点和整数溢出均在发布前校验；失败不发布部分结果。

真实夹具的活动骨骼索引均有效，附加 UV 的第 2–4 组仅由专项内存夹具覆盖。QDEF 和未知类型通过修改已加载测试模型的类型字段验证拒绝；不是 PMX 2.1 文件验收。独立只读审查核对了布局、SDEF 偏移、缺骨规则、恢复顺序、计费及无设备访问，未发现阻断问题。
