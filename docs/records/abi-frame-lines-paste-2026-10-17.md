# 帧线插删与骨骼关键帧粘贴

本批继续迁移受控绑定下的原生编辑入口。普通运行仍未绑定完整共同历史，`mms.edit` 仍未开放。本记录不表示普通运行的所有编辑已支持统一撤销。

## 实现范围

帧线命令 `255`、`256`、`257`、`258` 在私有目标键池中准备插入和删除。它们处理骨骼、表情、相机和灯光轨道，保留键池身份、帧零合并、缩放曲线及插值平滑规则。提交、撤销和重做只重新求值受影响的轨道；尚未登记的编辑姿态保留。

骨骼前向操作沿用现有原生编辑策略，使受影响的自由曲线失效并使用原生关键帧；撤销恢复原自由曲线作者数据。相机和灯光保留 `TrackAuthoring`，表情沿原图层采样规则处理。本批尚未实现所有自由曲线作者关键点随帧线同步移动。

关键帧粘贴命令 `421`、`422` 本批处理骨骼普通及镜像粘贴。历史记录持有键值、缩放和曲线数据，撤销和重做不再读取剪贴板。普通粘贴中含表情或显示键，或目标为相机及其他全局轨道时，受控入口整批拒绝，不执行部分粘贴。镜像粘贴沿用旧入口只处理骨骼的规则。

这些操作属于显式提交，两种历史模式都记录。所有准备均在发布前完成，取消、内存不足及预算拒绝不修改场景。无可粘贴的匹配骨骼不改变选择、游标、历史或重做。

VMD 导入仍未迁移。受控绑定在打开文件前拒绝旧加载入口，防止导入绕过共同历史；普通未绑定运行保留原导入功能。后续接口和验收范围见 [VMD 导入方案](abi-vmd-import-plan-2026-10-17.md)。

## 验证

| 检查 | 结果 | 本地证据 |
| --- | --- | --- |
| 四类帧线专项 | 2,639 项通过，含旧生产逻辑对照、帧零合并、插值平滑、未登记姿态、分配失败、预算和身份不变的扩容 | `build/abi-frame-lines-native-2.log` |
| 骨骼粘贴专项 | 761 项通过，含普通及镜像、PMX 固定轴及 PMD 尾轴、垂直轴零点积、空闲槽残留链接、无名称匹配和剪贴板独立重做 | `build/abi-key-paste-native-2.log` |
| VMD 入口保护 | 105 项通过，两种模式、模型及相机、ANSI 及 Unicode 实际入口均在文件读取前拒绝，场景和历史不变 | `build/abi-frame-paste-vmd-3.log` |
| 整合回归 | 原生历史累计 114,659 项、ABI 契约 1,717 项、统一设置 70 项通过 | `build/abi-frame-paste-regressions.log` |

| 普通旧路径 | VMD 加载安全、骨骼注册及显示粘贴回归、缩放 PMM／VMD／VPD 往返三组通过 | `build/abi-frame-paste-legacy-regressions.log` |

独立审查发现并修复了镜像固定轴零点积边界和全部名称不匹配仍产生历史的问题。旧路径的六段轨道循环提取后与原实现逐 token 一致，原有返回值、帧上限拒绝和界面刷新尾部保留。隐藏宿主测试不代替人工界面验收。

## 剩余边界

表情、显示、全局轨道及附件的关键帧粘贴，VMD 批量导入、视口拖动等入口仍需迁移。完整生产绑定必须等待所有写入入口完成审查。

本批不增加系统或特定显卡依赖。Win7 SP1 x64 和 AMD 真机验收仍未完成。
