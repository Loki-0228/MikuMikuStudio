# 受控模型 VMD 自由曲线尾段迁移方案

日期：2026-10-18。此文保留实施前设计依据；本轮已按此方案实现并完成本机验收，状态以[实施记录](abi-model-vmd-curves-2026-10-18.md)为准。约束是保留既有 VMD 兼容指标，不放宽旧测试来接受新实现。

## 接入位置

`src/plugins/native_model_vmd_source.cpp::DecodeModelVmdSource` 在 Unicode 名称字典之后检测到表情或骨骼曲线尾段时，仍返回 `MMS_E_NOT_READY`。现有 `ModelVmdSource` 未承载这些作者数据，`PlanModelVmdImport` 只把标准记录送入 `PlanModelKeyPaste`。

尾段应进入现有模型导入的私有 family 计划，在同一目标关键帧池上生成最终原生记录和作者数据，然后一次发布。不能把标准导入计划和独立 `PlanBoneCurveWrite`／`PlanMorphCurveWrite` 并列聚合：两者都从旧实时池准备，无法看到对方尚未发布的键，分配槽位和来源校验也会冲突。

骨骼可复用 `bone_curve::AuthoringState::Replace`、`AuthoringRestore`、缩放作者状态和私有扩容。表情需要增加面向未来 `NativeKeyView` 的私有尾段安装能力，复用既有合并及 `SetInstalled` 规则；不能直接用会重建全部镜像的 `AuthoredReplacement` 替代原表情导入行为。最大帧、游标及选择元数据仍由汇总计划统一发布。

## 必须保留的旧行为

1. 原始标准字节、VMD1／VMD2 记录布局、Unicode 字典及缩放前缀 CRC 保持。CRC 直接针对输入字节计算，不能通过重新编码标准体重建前缀。
2. 旧加载器先读取表情块，再读取骨骼块，按消费后的边界验证缩放尾部；标准键先导入，作者安装顺序为表情、缩放、骨骼。
3. 表情尾段保留目标未覆盖的帧。每个尾段键必须匹配本次已导入且有导出标记的原生键，权重按 `float` 比较。偏移后补出的帧零锚点使用目标原帧零值。尾段只安装作者层，不再次改写标准镜像。
4. 骨骼必须完整匹配九通道。偏移后缺少帧零时复制导入首值，以 Step 连接首区间；不得删除原生目标中不属于尾段 union 的帧。旧骨骼尾段会调用写入重新生成镜像，其标记、槽序和 `searchCursor` 差异也要保留。
5. 无 Unicode 字典时，骨骼按通道及原始 20 字节名称匹配，可作用于多个同名目标；表情同名歧义则跳过。Unicode 使用显式目标索引，缺失或歧义按旧规则跳过。不能把两者统一成新的匹配策略。
6. 坏表情 CRC 的旧路径不会推进尾部位置，其后的骨骼与缩放块也不会应用。有效封装、无效载荷和未知尾段的行为以真实旧加载器为准，不能根据注释自行改变容错规则。

导入、取消及往返均不改当前播放头、剪贴板或名称映射 TLS。跨帧历史只求值拥有的姿态和作者数据，保留其他对象的 dirty 与未登记姿态。撤销和重做不能重读源文件。

## 验收范围

保留现有 `native_model_vmd_checks`、模型 VMD 宿主探针、`bone_curve_tests`、`morph_curve_tests`、`animation_curve_motion_tests` 与 `vmd_load_safety` 的全部原断言，再新增以下覆盖：

- VMD1／VMD2，标准体、单类及两类曲线尾段，缩放与 Unicode 字典的有无组合。
- 用真实旧 `LoadVmdMotion` 比对标准记录、原生插值字节、作者 `CaptureVmd`／PMM 字节、偏移后采样、元数据及选择标记。
- 截断、CRC 损坏、合法长度但非法载荷、缺通道、表情值不匹配、未标记键、旧帧冲突、同名／Unicode 歧义与偏移溢出。
- 全流程逐分配失败、预算拒绝、取消、来源过期、首次扩容及源文件离线，均不得部分发布或截断 redo。
- 插件、原生登记、曲线窗口与带尾段 VMD 导入交错，在两个模型、两个历史模式和不同当前帧下逐步撤销／重做。

本项的实际准入以实施记录为准，公共 `mms.edit` 不因本项单独完成而开放。Win7 SP1 x64、CPU 基础路径和 AMD 兼容约束保持。
