# 曲线文件选择期间的会话保护

日期：2026-10-20。分支：`codex/plugin-abi`。修复前，文件选择器处理消息期间可能销毁曲线窗口，返回后 `RunReadMotion` 仍恢复旧对象中的布尔字段并读取旧来源；导出回调也可能持有已销毁来源的通道引用。

## 实现

读取和导出在调用前复制回调；导出同时复制当前通道快照。准备分配失败时保持原数据并显示错误。操作期间继续使用原编辑器的重入保护。

每次打开或替换编辑器会话创建独立身份。`CaptureWindowSession` 仅返回身份 token，`IsWindowSessionCurrent` 在注册表中核对窗口及当前控制块。持有旧 token 的强引用不会延长窗口或会话有效期。模态回调返回后，旧会话不再恢复字段、刷新来源或覆盖替代窗口的状态。

实际 VMD 文件选择返回后还核对工程代次、工程修订、共同历史绑定及修订、附件身份和编辑门禁。已关闭或被替换的窗口不读写文件，新的工程或模态期间产生的编辑不接收旧操作的结果。正常读取、导出、标准 VMD 与 MMS 作者尾段格式保持原样。

## 验证

证据目录：`build/verification/abi-history-region-lifetime-20261020/`。

- 最终完整编辑器回归 2,538 项通过，日志 `test-editor-final.log`。包含普通和外部历史来源、读取和导出、关闭、同窗口替换、关闭后重建、回调异常，以及持有强 token 的反例。旧导出快照在回调销毁来源后仍可读取，新会话保持可编辑。
- 真实 PMX 原名、PMD 中文改名宿主均通过文件选择期间关闭、重建、替换会话、改变工程代次及修订的检查，并复验 VMD1／2 原始控制、MMS 作者尾段、两种历史模式和撤销重做。日志 `test-real-curve.log` 及 `real-curve/report.json`，两个子进程退出码均为 0。
- 子任务只读交叉审查发现并促成修正了“强引用旧 token 使 expired 不再可靠”的问题，最终按注册表身份核对。

本记录限于文件选择与 motion 回调的返回过程。2026-10-21 已另行完成 [`Source.read`、`history.query` 和 `localizedLabel` 的会话保护](abi-curve-source-lifetime-2026-10-21.md)，随后完成 [`apply` 和 `traverse` 的写入及失败恢复保护](abi-curve-write-lifetime-2026-10-21.md)，以及[比较模式与相邻控制开关保护](abi-curve-comparison-lifetime-2026-10-21.md)。这些保护包含闭包复制、调用和最终释放中的重入。帧与播放控制、`subdivide`、`Channel.sample` 尚未统一，不能认定全部来源回调均可任意重入或销毁窗口。

实现没有引入新系统或显卡依赖。基础配置提供对应空实现，继续保留 Win7 SP1 x64、CPU 基础路径和 AMD 兼容要求。

统一构建还暴露两处旧测试把 `SceneModified()` 代理与字节字段放在同一 `auto` 声明中的编译错误。夹具现显式捕获字节值，保留原来的数据比较断言。最终宿主构建通过，日志 `build-host-final.log`。完整与原始兼容产品均构建成功；原始兼容构建的五组刷新、插件合同及可选图形导入通过，日志 `test-original.log`。这些本机结果不代替目标硬件验收。
