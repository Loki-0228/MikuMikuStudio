# 烘焙运行文件的安装目录隔离

日期：2026-10-23。基线：`25c9d7a`。工作区：`D:/MMD-Next/MMS-abi-dev`。本记录核对实际生产存储入口，不将其视为整个磁盘缓存管理服务已经完成。

## 问题与变更

`mesh_bake_cache::Install` 原先把私有 ABC 副本写入系统临时目录，读取临时目录失败时还会退回当前工作目录。仅烘焙而不导出 ABC 时，`alembic_export::Export` 的 `.partial` 中间文件也位于系统临时目录。两者都违反本分支运行数据位于程序根目录 `data` 的要求。

私有副本现使用 `data/mesh_bake_cache/mesh-cache-<进程号>-<随机串>`。仅烘焙的中间文件使用 `data/mesh_bake_work`。两个路径均通过已有 `local_data::File` 从实际 EXE 目录生成，与 EXE 文件名、当前工作目录及 TEMP/TMP 无关。目录解析、创建或写入失败时返回错误，不回退到其他位置。

用户明确选择的 ABC 导出位置保持不变，其 `.partial` 仍在目标目录以便原子发布。PMM 旁车继续跟随用户选择的工程路径。私有副本保持每实例独占，清理只删除自身文件及空目录；保存快照和重定时计划继续持有原 Archive。此类副本可能是已删除源 ABC 的唯一烘焙数据，不能交给可再生缓存管理器按预算淘汰。
