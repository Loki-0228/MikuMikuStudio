## 建议实施顺序

先处理 [main 审查对照](abi-main-review-comparison-2026-10-18.md) 中确认的 P1 及数据正确性问题，完成新增手势的捕获移交整合，继续补齐其他原生写入，形成可向普通插件开放的边界。随后在已有 SELF DATA 和保留布局的 SELF LAYOUT 上补完整 STATE 与依赖，完成本体控件登记及更多挂载点。再以只读独立求值和图像租约推进多视口与洋葱皮，以公共数据候选和共同事务推进格式编辑；这些服务稳定后扩展对应 SDK 包装。旧插件适配按独立工作包实施，目标硬件验收按设备可用情况补齐，不阻塞无硬件依赖的开发。
