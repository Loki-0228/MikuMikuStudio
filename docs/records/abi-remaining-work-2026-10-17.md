## 尚未实现的服务与工具

| 工作 | 具体缺项 |
| --- | --- |
| 复杂 UI 呈现 | 样式、绘制层、逐帧呈现、临时视觉变换、插件输入区域和辅助覆盖层；由后台事件驱动任意已授权目标的完整交互组合。桌宠、跨控件动画与换肤需要这些服务。 |
| 多视口和渲染 | 场景来源、独立求值实例、播放时钟、相机、渲染器与显示区域的独立对象；渲染器提供者、图像资源租约和设备代次协议。已有多 surface 或本体浮动窗口不等于多个独立 3D 视口。 |
| 洋葱皮 | 无副作用的过去／未来采样、样本缓存、辅助叠加和历史物理策略。不能通过暂时移动主播放头代替。 |
| 动画编辑服务 | 轨道、关键帧、动作层、片段、变速、烘焙和动画选择的公共 ABI。已有内部关键帧计划器不等于插件可用的 animation 服务。 |
| 求值与计算 | compute 两阶段求值、状态域、CPU 能力协商，以及 binding、cache、bake 的完整服务与 MMV 等价能力清单。 |
| 格式与专用编辑器 | 格式版本及读写能力声明、读取／写入回调、转换及损失诊断；公共 schema 和插件私有结构的查询与编辑；选择模式、操纵器及工具注册。PE 类工作区、UV、权重、材质节点、重定向工具仍依赖这些接口。 |
| 旧插件适配 | 原创 MMSAdapter、MMHack 兼容导出及 legacy_mme 的 EXE 改名与子目录适配。当前原生 ABI 插件改名可用，不能推定旧 MMD 插件可用；没有实际样本的旧插件仍限理论方案。 |
| 部署组合 | 固定并验证 Win7 的 CRT、UCRT、VCOMP、DirectX 部署依赖组合。当前工具链和 PE 导入检查不等于部署完成。 |

以上复杂能力继续由同一底层 C ABI 扩展，便利 SDK 组合相同句柄和规则。基础 UI 与刷新包装已落地，复杂呈现、格式、视口和工具包装尚未实现。

## 缺少验收或测量，不等于功能未实现

- Win7 SP1 x64、Win10、AMD CPU 和 GPU 的目标设备验收；现有本机编译和运行不能替代。
- Media Foundation 兼容回退在 Win7 上的媒体结果，以及旧 Win7 加载器分支的设备验收。
- 混合 DPI 跨屏、运行中缩放变化的独立记录、辅助功能、冲突快捷键与输入法组合态。已反馈的单屏 100%、175%、200% 不重复记为失败。
- 两个独立 SDK 示例的真实输入与视觉验收，以及 R3 批量布局和 GDI 缓冲失败路径的故障注入。
- 真实旧 MME 内部状态保持及相关遮挡恢复；MME 内部阶段计数与有效 ABBA 性能基线尚缺，不能宣称性能提升。

## 建议实施顺序

先处理 [main 审查对照](abi-main-review-comparison-2026-10-18.md) 中确认的 P1 及数据正确性问题，再补齐完整跟随开关及其他原生写入，形成可向普通插件开放的边界。随后补 DATA、完整 STATE 和 LAYOUT，完成本体控件登记及更多挂载点。再以只读独立求值和图像租约推进多视口与洋葱皮，以公共数据候选和共同事务推进格式编辑；这些服务稳定后扩展对应 SDK 包装。旧插件适配按独立工作包实施，目标硬件验收按设备可用情况补齐，不阻塞无硬件依赖的开发。
