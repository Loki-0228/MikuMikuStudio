# 普通骨骼整体重置与草稿取消

日期：2026-10-23。实现基线为 `576c291`，本轮核对 main 为 `fed9768f9fe726c4b5e068849808803f1713ad42`。本批接续[绑定整体重置](abi-pose-reset-2026-10-23.md)，处理增强版普通启动中没有共同历史绑定的命令 495。main 工作区和稳定版产物未修改。

## 实现行为

`ApplyUnboundPoseReset` 将选中骨骼的局部位移清零，旋转和缩放恢复单位值。根骨骼、有父骨骼和其他无父骨骼使用相同目标。普通入口继续使用原有 30 槽撤销环，不额外建立历史栈，也不通过开启迁移测试绑定来改变产品入口。

有实际变化时，先准备骨骼快照、目标缩放副本及原撤销环所需的缩放与自由曲线状态。分配完成后复核对象、选择、帧、旧环和窗口上下文，再执行不分配、不发送窗口消息的数据发布。旧目标槽的 `bonePose` 和 `auxiliaryPose` 均释放，过时字段清零；新记录只包含实际变化的骨骼。一次撤销恢复位移、旋转、dirty 和缩放，保留原自由曲线。撤销和重做不读取外部文件。

无选择不修改数据或草稿。作者值已为目标时不增加撤销记录、不截断 redo，也不把原 dirty=0 改成 1。选中集合可以混合有变化和无变化骨骼。当前显示骨骼在集合内时，成功或合法无变化重置均取消其九个位置、旋转和缩放草稿；父绑定偏移仍保留在位置显示中。未选中的显示骨骼与无关输入保持。

准备失败不改变作者数据、旧环或草稿。首次遇到未登记模型时，普通入口会先建立稳定身份，再发布数据和读数。已有身份的无变化重置无需 C++ 分配。首次身份登记可能消耗内部代次或保留注册元数据，预留容器也可能改变容量；本批不声称这些内部缓存完全回滚。

数据完成后更新工程脏标志、原撤销按钮及协调器视口请求，再局部更新九框。每次同步文本消息后复核对象、绑定、选择、窗口与历史上下文，不调用完整 `PostViewRefresh`。文本写入失败时仍取消旧草稿的提交资格，后续无变化重置可以修正显示。

`EditSubclassProc` 的失焦分支仅对增强版、未绑定、骨骼模式下的九个数值框读取原 `EM_GETMODIFY`。没有待提交修改时不再执行旧数值提交，避免舍入后的回显或已取消草稿重新写入作者值并增加撤销步骤。真正修改过的位置、旋转和缩放仍走原提交路径。绑定入口、相机、其他控件、显式 `CommitEditControl` 以及原始兼容配置不改变这项语义。
