# 冻结骨骼通道的公开求值服务

## 本批能力

新增 `mms.scene.evaluate` 1.0 和 [SDK 调用文档](../../sdk/mms/evaluation.md)。插件使用原 `MmsHostV1::queryService` 获取函数表，通过七个入口查询能力、捕获源、读取描述、枚举骨骼、按时间采样、保留及释放源。不改动原 `mms.scene` 表的大小或求值阶段。

生产运行时在 UI 安全点把 `BoneMotionSnapshot` 绑定到已有场景对象和骨骼身份。源持有全部动作数据，后台采样不再读取活体模型。模型更新、删除及工程重载不改变已有源；已失效的对象引用不能再次捕获。每次成功捕获分配独立 `captureId`，`retain` 共享该标识。`hostRevision` 可以为零，只是历史元数据，不能用于判定动作内容是否相同。

时间使用有理数秒和固定 30 fps 基准，支持分数帧。先以整数分数检查范围，再约分转换；等价的大整数分数不会因为转换顺序得到不同的整数帧，略超宿主最大帧的请求不会因浮点舍入被接受。输出为已注册局部位移、四元数、完整尺度矩阵和原生物理开关通道。

每份源最多保留 64 MiB，每插件 128 MiB，服务总计 256 MiB。额度包含动作和服务索引的保守计费，不代表捕获临时峰值或整个进程内存。单插件最多 128 个句柄，全服务最多 1024 个。多个保留句柄共享数据及字节计费；最后一个句柄和所有已接纳采样均结束后归还额度。

句柄按插件实例隔离。插件停止后拒绝新操作，只保留 `release` 用于清理；已接纳采样完成后返回结果，未完成捕获不得在停止后发布新源。Manager 在源句柄或采样仍有效时保留实例和 DLL，覆盖正常停止、创建失败和依赖保留路径。插件仍负责停止任务并等待线程退出。

## 支持边界

此服务只提供层级、IK、表情、动作层与物理之前的已注册局部骨骼通道，不包含当前未注册编辑姿态，也不是 `ANIMATED` 世界矩阵或完整场景帧。外部父级和未支持的派生骨骼可枚举，采样明确返回不支持。附件、相机、灯光、负帧、独立物理、完整场景实例及帧租约仍待实现。

原始兼容配置编译公共存储及测试，但生产工厂未开放此服务。其测试以注入的可信捕获器验证公共运行时，不能据此声称原始配置已经支持真实模型采样。

本批仅用 CPU，不新增显卡厂商依赖或新系统接口；Win7 SP1 x64、CPU、AMD 要求保持。未修改 VMD 编码、插值协议及 MMS 标记策略。Win7、AMD 真机和完整洋葱皮/多视口仍未验收。
