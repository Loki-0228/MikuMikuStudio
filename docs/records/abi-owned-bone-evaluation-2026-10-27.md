# 独立骨架帧求值

`BoneEvaluationSource` 在同一个 UI 安全点捕获骨架定义、骨骼动作、显示轨道、表情定义和表情权重。`Evaluate` 在自有工作区执行动作采样、骨骼表情、层级、IK 和尺度计算，返回不可变 `BoneEvaluationFrame`。

这是内部完整骨架求值入口，尚未接入公开场景帧。它不模拟物理、不生成蒙皮网格，也不调度跨模型依赖。

## 输入与结果

来源拥有五个快照，核对骨数、表情数、格式、运行 IK 链及 selector 映射。捕获必须由调用方放在同一个串行 UI 安全点，不能与模型编辑并发。完成后来源可以供多个后台调用共享。

每次求值从加载器确定初值开始，不读取当前编辑姿态或旧矩阵。先准备注册动作、显示开关和骨骼表情，在物理前后两轮各准备一次局部姿态，并按实际层号升序执行原五阶段。层内保留原骨序和运行 IK 链顺序，跳过空层，避免按极大上界逐层循环。

结果提供以下数据：

- `rigid` 为完成两轮后的原生 `matInit`。
- `scaled` 为显式刚性矩阵与完整尺度合成的结果。
- `attachment[0/1]` 分别为每轮完成后的 `matExtra`，供外部附着使用。
- `jointPosition` 为静止骨骼位置乘 `scaled`，不是直接读取矩阵平移。
- 帧时间与原始显示字节随结果保存。

结果不保留来源、数学上下文、模型或依赖数组的指针。这些输入销毁后，结果仍可并发无分配读取。求值不修改播放头、工程、历史、作者曲线或宿主尺度缓存。

## 外部父级

每个活动 selector，包括全局 selector 0，必须提供一条 `BoneEvaluationDependency`。其原模型槽与骨骼索引必须匹配该时间的冻结选择。输入还包含目标静止位置及两轮各自的附着矩阵。

重复 selector、缺少依赖、多余依赖、非有限值或目标不匹配均拒绝。不同 selector 可以引用同一目标，但该目标的静止位置及两轮矩阵必须逐元素一致，正负零视为相等。检查只排序自有索引，不改变输入顺序，额外存储计入工作预算。

工作区用一个代理模型承载全部目标，不按原始槽号分配大型模型数组。这里的原始索引不是稳定身份。场景协调层仍须冻结目标动作、解析身份、安排两轮全场顺序并处理循环依赖。

## 预算与失败

默认来源和结果保留预算各为 64 MiB，工作预算为 128 MiB。所有计费乘加先检查溢出。工作预算包含结果、骨表、IK 链及嵌套链接、selector、依赖代理、尺度树节点、表情结果和工作数组容量。

预算衡量本层拥有的存储，不是进程峰值内存上限。嵌套求解、尺度和表情函数的瞬时分配不计入该上限。

非法输入抛出 `invalid_argument`，有限输入计算产生无效数值时抛出 `overflow_error`，超预算抛出 `length_error`，分配失败保留 `bad_alloc`。全部矩阵及关节位置通过有限值检查后才返回，不发布部分结果。
