# 模型视图拖拽与滚轮的共同历史

本批在 `codex/plugin-abi` 的 `dcfe98c` 后实现。改动及构建均位于独立的 `D:/MMD-Next/MMS-abi-dev`。

## 操作范围

受控宿主中的模型自由视图支持右键旋转、Shift 加右键平移、Ctrl 加右键改变距离，以及中键平移。Shift 与 Ctrl 同时按下时保留原有优先级；中键保留三档速度。跟随开启但没有父模型，或父模型不同于当前所选模型时，同样使用原有视图数学。

主窗口与浮动窗口的滚轮均修改模型视图距离。主窗口保持单精度乘加，浮动窗口保持原有双精度中间值后转为单精度的运算顺序。一次有效滚轮消息作为一次 Adjustment；一次拖拽在松开时提交一次 Adjustment，最后一次松开消息的位移也包含在内。

当跟随开启且父模型等于当前所选模型时，旧拖拽还有跟随提示及松开清理。本批继续拦截该特殊拖拽和主窗口滚轮，不退回旧写入。浮动窗口的滚轮没有此分支，可以使用。这是尚未迁移的界面状态逻辑，不是已确认存在物理求值。

## 历史与生命周期

模型操作复用已有视图数值快照、逐字段掩码、稳定模型身份及来源校验。准备阶段预留历史和对象引用，预览只修改允许的视图字段。松开后只发布发生变化的字段；撤销和重做不重新读取文件、求值模型或改变播放头，也不写骨骼、关键帧、作者曲线及旧撤销环。

两种历史记录模式沿用共同规则。全部操作模式记录每个手势或滚轮步骤，只记录显式提交时应用视图变化而不新增调整记录。无操作不清除已有重做分支。准备失败、预算不足或插件事务占用时，不进入旧操作路径。

相机与模型手势互斥。取消、失焦、捕获丢失、退出和同线程重建共用清理入口。取消只回滚仍属于该手势的预览，来源过期或外部修改后不覆盖新的状态。正式撤销分派所持的场景和 UI 保护，仅在已发布记录的宿主授权阶段放行；首次编辑与普通保护仍严格检查。

旧模型读数刷新假定所选模型和骨骼有效，还可能为非单位缩放建立变换缓存。因此本批在首次编辑和每次预览前检查读数来源：空模型槽、骨表缺失或非负骨索引越界时拒绝；负骨索引保留空读数。`bone_scale::TransformsApplied` 只查询已有缓存，不分配或应用变换。所选骨缩放非单位且尚未应用时暂拒绝，防止纯视图操作隐式改写骨矩阵；已应用缩放继续支持。首次候选发布再次检查这些条件，历史重放不受最初的选择限制。

共同历史的 `RefreshBoundPoseReadout` 同样检查缩放缓存，覆盖取消尾、提交失败和撤销重做后的派生刷新。未应用缩放时只跳过此次读数，不拒绝已经成立的历史重放，也不为刷新调用 `ApplyTransforms`。正常求值应用变换后，读数恢复更新。

普通启动的 `mms.edit` 继续关闭。HUD、完整跟随开关及其他未迁移写入仍按剩余清单推进。跟随开关会覆盖相机、灯光、阴影、重力和附件的未登记值，其完整事务范围另见[待实现方案](abi-follow-toggle-plan-2026-10-18.md)。
