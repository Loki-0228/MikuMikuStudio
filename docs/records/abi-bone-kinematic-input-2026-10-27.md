# 独立骨骼局部姿态输入

## 实现范围

内部 `BoneMotionSnapshot::PrepareKinematicChannels` 从同一次捕获的骨骼动作和显示快照准备局部姿态，供后续独立骨架工作区使用。真实 PMX／PMD 的移动骨骼与 IK 控制骨即使没有启用外部父级，也可能拥有 selector；新入口按原生规则处理这些轨道。

旧公开 `SampleChannels` 的限制保持不变：存在 selector 时仍返回 `ExternalParent`，派生类型仍返回 `UnsupportedBone`。本批没有新增公共 C ABI，也没有将局部结果声明为完整求值帧。

## 内部接口

```cpp
BoneMotionSample local;
const auto status = motion.PrepareKinematicChannels(bone, frame, display, local);
```

`motion` 和 `display` 必须来自同一模型、同一次捕获。函数检查实际使用的 selector 是否映射到请求骨骼，但不验证捕获身份；后续工作区装配须保证这一前提。失败不修改输出，成功只发布一次。捕获后读取无分配，允许多个线程共享快照。

| 输入规则 | 行为 |
| --- | --- |
| 普通骨骼精确关键帧 | 直接复制该键的位置和旋转。 |
| 两键之间存在父级窗口边界 | 按原生 start 优先、end 次之的规则选择前键或后键；即使父模型为 `-1`，窗口仍有效。 |
| 末键后的新窗口 | 符合原生清零条件时使用零位移和单位旋转，否则保持末键。 |
| 类型 7／9 | 跳过原生姿态键和 selector 查询，从新工作区的零位移／单位旋转开始。 |
| 尺度 | 保持完整 3×3 矩阵，独立插值，不受位置／旋转跳变影响；类型 7／9 也应用尺度。 |
| 自由曲线 | 最后覆盖位置、旋转及尺度，优先于窗口和派生骨骼默认值。 |

`physicsDisabled` 仍是前键携带的元数据，不代表已经模拟物理。原生 `SeekModelFrame` 对类型 7／9 保留已有局部姿态；此入口明确针对新建独立工作区，因此初始姿态固定为零／单位旋转，不复制当前编辑姿态。

新旧入口共用一个采样实现。旧浮点比例、插值、四元数和尺度计算顺序保持不变。没有读取当前播放头、实时骨骼矩阵或全局作者状态，也不求解外部目标矩阵、层级、IK 或物理。

## 验证

| 检查 | 结果 |
| --- | --- |
| 新局部姿态输入专项 | 10,204 项通过 |
| 旧骨骼动作快照 | 973 项通过 |
| 显示及父级窗口快照 | 4,426 项通过 |
| 独立骨架求解上下文 | 2,777 项通过 |
| 真实 PMX／PMD 宿主及 PMM 重载 | 两种格式均通过 |
| 完整配置、原始兼容配置产品构建 | 均通过 |

专项用实际 `SeekModelFrame` 对全部 0–9 类骨骼的位置、旋转和完整尺度进行逐位比较，覆盖非线性曲线、精确键、窗口开始／结束、末尾清零及连续未绑定父级。小数时间另覆盖 `nextafter` 边界、完整尺度与自由曲线原生对照。错误输出守恒、采样禁分配和源销毁后四线程读取均通过。

真实宿主夹具注册非零 IK 控制骨动作，验证新捕获读取新关键帧而旧捕获不变。源模型删除、槽位复用及 PMM 保存重载后，旧快照仍可后台读取；主播放头、当前姿态、关键帧池、选择器、自由曲线／尺度作者及共同历史保持不变。

首轮专项在尺度断言失败：夹具含剪切，测试错误地要求对角元素等于自由曲线指定的行长度。修正为检查行长度、方向、剪切保留及完整矩阵的原生对照后通过；生产实现未因此改动。独立代码审查未发现阻断问题。
