# 范围订阅的观察失败恢复

本批修复显式 DATA 与原属性范围订阅的失败恢复，继续使用原队列、来源、目标、依赖图及订阅句柄。公共 C 表、结构大小和全局 ABI 1.0 不变；普通生产 `mms.edit` 保持关闭。接口语义见 [DATA 范围订阅](../../sdk/mms/scoped-refresh-subscriptions.md)及[原属性范围刷新](../../sdk/mms/scoped-property-refresh.md)。

## 观察与真实变化

临时观察分配失败保留上一份完整成员、来源监听、等待原因、结果和工作代次。DATA 原路径不再提交空或部分成员，也不再把内存失败写成 GRAPH；原属性继续原子提交完整成员与来源。

真实相关图变化或成功发布的子树变化先记录有界待观察状态，再使用原队列请求。即使本次观察失败，真实变化仍有执行机会。原请求已尝试并失败后，后续成功观察只补齐元数据，不能再次消费同一个失败工作，也不能解除失败的 HOST_WAKE 停泊。

图事件按原依赖图的当前可达性判断。查询比较完整目标引用和客户端，使用最多 513 个顶点的固定数组，不分配、不访问 HWND 或插件。该上限来自每客户端最多 512 条保留边，不使用单次刷新 256 个成员的额度截断事件判断。新增可达节点和已经脱离的旧缓存节点分别处理，避免漏唤醒及误唤醒。

子树事件只来自真正成功且有变化的注册树发布。宿主用新旧保留树的父链比较成员集合；无差异同步、失败发布及无关子树变化不重试失败消费者。已接受的显式来源集合仍保持原快照，普通来源发布只安排后续工作。

- 完整回归在 `candidate-03` 的菜单测试第 13,956 项失败，断言要求新旧菜单堆地址各自不同。源码表明 cookie 是已释放 `MenuState` 的地址，不承诺地址永久不复用；前批冻结二进制与本批二进制的独立菜单专项各 1,088 项均通过。测试改为独立验证命令编号与同工程代次的呈现代次变化，旧完整目标返回 STALE 且输出不变，旧命令不得调用新对象，新请求与新命令必须实际成功。原生菜单项仍直接读回核对，地址只作诊断。
