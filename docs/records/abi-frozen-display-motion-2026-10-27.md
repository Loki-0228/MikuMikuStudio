# 冻结显示与外部父级选择轨道

## 实现范围

新增内部 `DisplayMotionSnapshot`，拥有从显示槽 0 可达的注册关键帧。它复制可见性原字节、每条 IK 链的开关原字节，以及每条外部父级选择的两个原始索引。IK 链到骨骼的映射、selector 到骨骼的映射也独立保存，selector 0 的模型全局父级不会被省略。

外部父级的选择还包括连续有效窗口。相同 `(modelIndex, boneIndex)` 的相邻键合并为一个区间，起点为该区间首帧，终点为下一次选择变化的帧，末段终点为 0。显示或 IK 单独变化不截断这个区间。即使 `modelIndex = -1`，窗口比较仍保留 `boneIndex`，与原生跳帧一致。

采样接受有限的非负帧，范围到 `frame_limits::maximum`。整数帧与直接 `SeekModelFrame` 的显示段一致，分数帧保持前键状态，不插值，也不加入实时播放路径的千分之一帧向上舍入。采样与映射查询不分配内存，不读取模型指针、当前游标或编辑姿态，可在源修改、销毁后并发调用。失败保留输出。

捕获在 UI 安全点与编辑串行执行，使用实际 `KeyPoolCapacity`，支持扩容后的显示键池。未注册借用数组沿用宿主的旧容量约定，调用方必须保证实际存储有效。只读取可达链，不根据 `allocated`、活动标志或显示键存在标志过滤；不可达垃圾不复制、不计费。链的帧顺序、双向链接、范围、嵌套载荷和映射边界均检查。

保留预算默认 64 MiB，按对象、实现对象和全部容器实际容量计算。在读取映射表前先检查一条键所需的最小额度，完整链确定后再次检查精确下限，分配后复核实际容量。超额抛出 `length_error`，结构无效抛出 `invalid_argument`，分配失败保留 `bad_alloc`。所有失败路径保持源不变；额度不代表捕获峰值或整个进程内存。

## 尚未完成的能力

此对象是完整姿态求值的内部前置数据，尚未加入公开 C ABI。`mms.scene.evaluate` 1.1 仍只开放骨骼通道与表情直接权重。

外部父级选择保留原始槽号，不解析目标身份，也不保证目标仍存在。它不把槽号当作稳定场景引用，不解引用外部模型。公开场景捕获仍需把这些选择解析为同一次捕获的对象与骨骼身份，并冻结目标动作和依赖关系。当前映射校验只验证本地范围，不提供依赖图完整性证明。

本批没有实现 IK 求解、骨骼层级、附加变换、世界矩阵、独立物理、负帧或完整场景帧，也未开放多视口。原始兼容产品配置不编译此模块。VMD 编码、插值、MMS 标记及运行数据目录未改变。CPU、Win7 SP1 x64、AMD 要求不变；未声称真机或视觉验收通过。
