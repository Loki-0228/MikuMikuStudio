# 背景图片来源预算与设置

本批在[不可变图片来源](abi-background-picture-source-2026-10-28.md)上补充共享总预算，推进背景共同历史的资源前置。没有开放背景摆放撤销，也没有修改总体目标。main 最新仍为 `6facf91`；阴影同步继续暂缓，未改 main 或覆盖稳定版程序。

## 实现范围

- `PictureSourceBudget` 用同一 SRW 锁串行化限额修改、预留、查询与退款。捕获先预留，再分配和读取；失败退回预留，保留原输出。
- 默认总额为 **128 MiB**。同一不可变来源的多个强引用只计费一次；最后一个强引用释放编码数据后归还额度。预算状态随来源保活，不要求公开预算对象比来源活得更久。
- 替换候选与旧图片同时计费，不能先释放旧图来绕过峰值检查。控制块或字节分配失败不会重复退款；并发捕获不能超售额度。
- 降低限额不会破坏已有来源。若现有占用超过新限额，后续捕获被拒绝，已有引用释放后才恢复可用额度。
- 完整配置的菜单／拖放候选加载读取统一设置，再捕获来源；超额、配置损坏或读取失败返回错误，保留原图片。没有更改原始兼容配置的旧 `LoadBackgroundPicture` 路径。

额度包含编码字节、来源对象及保守控制块开销，**不是进程内存总上限**，不覆盖解码临时内存、纹理、驱动、视频和其他历史对象。本批没有把它称为历史内存预算，也没有公开新的插件 C ABI。

## 配置约定

设置位于程序目录的 `data/settings.json`，字段路径为 `sections.resources.backgroundPictureSourcesMiB`，严格接受 **16～4096 的整数**，默认 `128`。只修改现有 `resources` 节中的该字段，不应以示例覆盖整份设置。内部写入沿用 `system_settings::WriteSection`，合并保留未知成员和其他节。

下次完整配置图片候选加载时读取并应用新限额。缺少节或字段使用默认值；字段类型或范围无效、文件损坏、锁冲突或读取失败均拒绝这次加载，不回退到无上限，也不改变已生效的预算。合法降低限额即使导致本次加载失败，也会保留新的限额。

本批当时只支持文件字段；后续[系统设置界面与原子保存](abi-picture-budget-settings-ui-2026-10-28.md)已补齐完整配置 UI，取得实际对话框验证。解码／纹理预算及历史总体预算仍须后续实现。

## 后续接线审查：不能跳过的生产入口

以下为源码审查结论和待实现方案，不是已完成能力：

后续[稳定图片资产及新建工程保留](abi-background-picture-asset-2026-10-28.md)已实现资产和 reset 保留，并取得完整宿主证据；以下 reset 问题为审查时状态。PMM、任意状态预备激活及共同历史仍未实现。

- PMM v1/v2 的整场景加载已持有图片／视频 `Mutation`。直接调用菜单使用的 `TryReplaceBackgroundPicture` 会被其 `Acquire` 门禁拒绝。需要抽出无 UI 的捕获、解码及准备激活实现，PMM 用受项目替换作用域授权的发布入口；不得放宽普通查询门禁。
- PMM 要在读取图片摆放和显隐值后整体发布，保留 clean 状态，不能走普通导入的标脏和历史提交行为。当前旧加载成功也没有来源对象；纹理非空而来源为空不能被解释为“原来没有图片”。
- `ResetAppState` 当前清除来源身份，但只关闭显示、保留旧图片纹理；菜单 233 又能重新显示。保留此既有行为时，重置应保留同一媒体资产并颁发新激活票据，不能只留下无法恢复的原生纹理。
- 现有 `PublishPicture` 强制 x=0、启用显示，且拒绝空纹理；历史恢复需要任意摆放、隐藏或无图片状态，并在准备阶段预留新票据，发布阶段不能再分配。
- 显示开关也必须进入相同历史模型；只接替换、遗漏显隐会让严格状态匹配把后续撤销拒绝为 STALE。

计划的内部 `PictureAsset` 保留稳定资产 ID、来源字节、路径、原始尺寸及解码参数；`PreparedPictureActivation` 私有准备资源并核对应用、场景、绑定、资产、激活票据和设备，发布只交换字段及已准备票据，随后在锁外释放旧 COM 资源。撤销恢复同一资产仍发放新激活票据，旧手势不可复活。

普通同设备 D3D9 Reset 不释放 `D3DPOOL_MANAGED` 图片纹理；现有 `PostDeviceReset` 释放的是 AVI 资源。因此不把“每次 Reset 都重新解码图片”列作缺陷。后续应分别验证同设备 Reset 保留来源／像素，以及真正设备替换时从保留字节重新准备资源。
