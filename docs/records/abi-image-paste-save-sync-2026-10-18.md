# 同步图片导出与粘贴、保存修复

ABI 起点为 `2492320`。来源为「排查 MMS 相机崩溃来源」中 2026-10-18 完成的图片导出及 issue 32 修复，读取时稳定分支基准为 `6af0514`，本批修复仍在其工作区中。图片生产改动与 PMM 名称检查分别保存为 `build/abi-image-sync-source.patch`、`build/abi-pmm-names-source.patch`。本次修改、产物和验证均位于 `D:/MMD-Next/MMS-abi-dev`。

## 图片导出

PNG、DDS 自动保留透明背景，其余图片格式保留场景背景，无需单独设置透明选项。单图和图片序列共用最终文件扩展名识别，支持大小写和 `.jpeg`。父目录或文件名中间包含 `.png` 不影响最终格式。

透明输出沿用 DX9 的 Alpha 渲染目标和覆盖率混合。编码前将预乘颜色转换为直通 Alpha，清除完全透明像素内的背景颜色，避免半透明边缘变暗。序列仍按明确的格式编码临时文件，完成后发布，不按临时文件的扩展名选择编码器。

单图导出增加独立清理路径。创建目标、复制、编码和创建窗口失败，以及取消和录制窗口退出，均清理单图会话、临时渲染目标及捕获请求，并恢复原窗口渲染尺寸。临时复制面在设备重置前释放。单图退出不调用视频停止和当前帧重新求值，保留未登记姿态及共同历史。图片序列的 ABI 调度入口和既有相机构图修复继续保留。

## 粘贴目标与共同历史

普通路径及 ABI 的骨骼、表情粘贴只检查本次实际使用的目标名称。未参与粘贴的辅助骨骼或表情重名不再阻止操作；实际目标重名和镜像映射出现多个候选时，整批在发布前拒绝。首次发布前复核目标，防止准备后新增冲突。

显示、IK 和外亲载荷保留原生逐项名称匹配规则，不再要求整个骨骼表名称唯一。骨骼、表情和显示混合粘贴仍先准备全部参与部分，后统一发布；后面的表情冲突不会留下前面的骨骼修改，也不会清除已有重做分支。历史记录保留已解析目标和数据，撤销、重做不依赖当前剪贴板。

## PMM 名称兼容性

兼容性提示依据实际 PMM 字段判断。模型中英文标题使用最多 255 字节的 CP932 长度前缀字符串；骨骼、表情的日文绑定名称须与实际短名称一致。英文骨骼和表情显示标题、显示组标题不再因旧模型格式的短名称限制触发 PMM 提示。无法表示的模型标题及真实绑定名称差异仍保留扩展数据和原提示。

本批还固定并审查源线程随后补充的 PMM v3 修复，快照为 `build/abi-pmm-v3-source.patch`，SHA256 为 `A094687602EC46F2AE5BF16FC1931DA5FD9861B2A4DB45DE6219BE98CC253D27`。实际内容超出旧版容量、帧范围、显示计数或引用路径限制时才选择 v3；预分配容量和可压缩的稀疏高槽位仍可保存为 v2。删减实际超限内容后可以恢复保存为 v2。

越界引用、指向未使用槽位的引用、缺失密集关键帧或非法帧范围单独标记为无效数据，并在创建插件保存事务及临时文件之前拒绝。不会把无效数据当成升级文件版本的理由。原版兼容配置的既有严格检查继续保留。此检查不等同于对全部关键帧链的顺序、环和归属进行完整验证。

完整版产品、图片导出、PMM 设置、共同历史、骨骼登记及相机测试目标构建通过，见 `build/abi-image-sync-build-2.log`。原版兼容配置的产品及原有 I/O、状态测试目标构建通过，见 `build/abi-image-sync-original-build-1.log`。两种配置均保持 Win7 基线开启、DX12 关闭。

骨骼粘贴专项 921 项、表情与显示粘贴专项 1,928 项、混合粘贴专项 2,125 项通过，见 `build/abi-image-sync-key-paste-1.log`、`build/abi-image-sync-model-paste-1.log`、`build/abi-image-sync-mixed-paste-1.log`。最终完整共同历史为 200,122 项，ABI 契约为 1,717 项；共同历史、契约、统一设置、相机跟随、导出构图、骨骼登记、可选图形导入共七组通过，见 `build/abi-image-sync-regressions-1.log` 和详细日志。原版兼容 I/O、状态及可选图形导入三组通过，见 `build/abi-image-sync-original-tests-1.log`。

实际图片导出的直接驱动路径通过 77,815 项，ABI 调度路径通过 77,779 项，见 `build/abi-image-sync-runtime-2/report.json` 及各目录 `result.log`。两条路径均启用真实 YYB Hatsune Miku NT PMX 的时序抗锯齿导出，检查实际几何、透明区域、编码后图像，以及额外采样不重复推进时间、物理和编码。空背景 MSAA、FXAA、TAA、SMAA 检查也均执行，本次没有跳过模式。调度路径省略直接路径已有的 36 项调用方时间步检查，计数差异与前批一致。

单图测试覆盖三种界面语言、七种实际菜单格式、最终扩展名和独立解码后的 Alpha。六类失败及取消覆盖目标创建、最终复制、透明目标、录制窗口创建、显式取消及录像结束入口，均检查尺寸、窗口、资源、捕获请求、未登记姿态及共同历史。半透明颜色使用独立像素夹具验证直通 Alpha。仍未注入设备重置本身失败及真实图片编码器失败，不能以这些测试推定所有驱动和编码器异常均已验证。

首轮图片测试在 DDS 行距检查失败，保留 `build/abi-image-sync-runtime-1`。实际 DDS 的 `DDSD_PITCH` 未启用，行距字段为零，载荷长度和 BGRA 掩码正确。根据本机 Windows SDK `ddraw.h` 中该标志定义修正测试读取器，并补充完整载荷、二维纹理和格式检查后，两条完整路径通过。

PMM 设置集成测试在同一报告的 `pmm-settings` 目录通过。覆盖八类关键帧池、帧与组数边界、引用路径、稀疏高槽位压缩、v3 内容减少后保存回 v2、名称扩展，以及错误数据拒绝后原 PMM 和真实插件侧车的逐字节保留。失败保存测试使用无弹窗的 `SaveSceneCopy`，未把此结果扩展为正常保存错误弹窗的交互验收。

本批不修改公共 ABI 或普通 `mms.edit` 的开放状态。Win7 SP1 x64、CPU 基础路径及 AMD 兼容要求保持；本机运行结果不替代 Win7 和 AMD 真机验收。
