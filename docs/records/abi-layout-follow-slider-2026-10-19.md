日期：2026-10-19。工作区为 `D:/MMD-Next/MMS-abi-dev`，分支为 `codex/plugin-abi`。本记录更新 [SELF DATA](abi-data-refresh-2026-10-19.md)、[全局删键与相机 HUD](abi-global-delete-hud-2026-10-19.md)、[模型视图](abi-model-viewport-2026-10-18.md)及[参数回显](abi-ui-render-paths-2026-10-19.md)的后续范围；旧记录保留各批当时的结果。

本批接入保留布局的 SELF LAYOUT、附件六轴 HUD 及同模型跟随的特殊视口分支。方向滑杆的交叉覆盖已修复并通过真实像素回归。完整 STATE、自动依赖、模型 HUD 和普通公共编辑服务仍未开放。

## 同一队列中的布局刷新

`mms.ui.refresh` 1.0 沿用原 C 表、目标引用和票据。原生布局后端为已有宿主按钮和已挂载 surface 提供 `LAYOUT + SELF`。插件须检查全局能力和目标的 `supportedKinds`，不能把全局 LAYOUT 能力视为每个目标都支持。

组合请求依次执行以下阶段；未请求的阶段跳过，不隐含执行。

| 阶段 | 本批行为 |
| --- | --- |
| DATA | 消费精确来源版本，准备并交换完整不可变显示模型。 |
| STATE | 只读查询目标按钮的命令，更新启用、选中及受支持的显隐。 |
| LAYOUT | 按现有描述、提示、文字量测和缓存状态重新测量、排列保留的布局树。 |
| REPAINT | 提交目标客户区损伤，后续绘制遵守正常 WM_PAINT 时机。 |

纯 LAYOUT 不遍历查询所有命令，不读取属性，也不准备 DATA。需要重新读取按钮可见性时，必须显式组合 STATE。LAYOUT 不创建未挂载的 surface；已有 surface 只接收必要的尺寸和显隐回调。布局不会清除既有面板错误提示。

SELF 仍是请求范围。保留树重排可能移动相邻元素，包括同一树中的其他插件元素；这不代表提供了跨目标订阅或自动依赖图。当前未提供 SUBTREE、DEPENDENTS、插件量测提供者或完整 STATE。

### 按钮收缩及恢复

单独 STATE 保留原规则：显隐变化需要有效的 `MMS_HINT_PRESERVE_HIDDEN_SLOT` 正尺寸槽位，不重新排版。STATE 与 LAYOUT 组合允许没有该提示的按钮隐藏并收缩空位。

收缩后的按钮可保留窗口、实例代次和工程代次，尺寸为零、`ready=0`。目标未暂停且支持 LAYOUT 时，含 LAYOUT 的请求可继续使用同一引用；STATE 与 LAYOUT 组合重新读取可见性并恢复尺寸。纯 STATE 或 REPAINT 仍不能绕过零尺寸检查。未挂载、停止、实例失效和工程切换的规则不变。

### SDK 与生命周期

`mms/cpp/refresh.hpp` 新增两种便利组合，均使用原 `Request` 和 `RefreshTicket`：

| 方法 | 请求 |
| --- | --- |
| `RelayoutCurrent(ref, ticket, key=0)` | LAYOUT、SELF、几何修订 0。不隐含状态查询或重绘。 |
| `RefreshStateLayout(ref, ticket, key=0)` | STATE、LAYOUT、REPAINT，SELF、几何修订 0。用于按钮收缩及同引用恢复。 |

二者没有独立对象身份、刷新队列或后台线程。工作线程使用已取得的服务表和目标引用提交；服务及插件实例须保持有效。票据仍按原规则查询、取消和释放，不能在 UI 线程同步等待。

布局及 surface 回调受只读保护。请求者和实际 surface 提供者在各自的刷新因果链中不能编辑、注册或递归提交 DATA、STATE、LAYOUT；限制传播到 UI 任务、取消回调及后代任务。无关插件的独立任务不因时间重叠而继承限制。

### 几何发布和失败

宿主先应用原生布局，再更新依赖该区域的视口几何，最后发布刷新目标和布局快照。刷新路径不调用 `HandleWindowSize`、`FrameDriver` 或偏好保存，不移动播放头、不写工程数据、不增加撤销记录，也不重新求值整个场景。

布局未完整成功时，刷新目标和公开几何保持暂停。新快照返回 NOT_READY，已有不可变快照租约仍可读。部分 HWND 可能已经移动，不承诺窗口事务回滚；后续正常宿主布局成功后恢复发布。

局部矩形绑定捕获时的几何。若同次 LAYOUT 改变几何，后续旧矩形以 FAILED/STALE 结束，不自动改成全窗口重绘。票据的 `completedKinds` 保留已成功阶段；后续失败也不回滚已交换的 DATA。需要随布局重绘时可使用无局部矩形、几何修订 0 的整目标请求，下一次局部损伤重新查询几何。

接口和示例见 [C 参考](../../sdk/mms/refresh.md)、[C++17 封装](../../sdk/mms/cpp-refresh.md)及[数据刷新](../../sdk/mms/data-refresh.md)。

## 附件六轴 HUD

HUD 指视口内用于拖动参数的操作轴。本批只开放相机面板中附件坐标下的三个平移轴和三个旋转轴，沿用原生 `ModeCameraAdjust`、`ModeAngleAdjust` 数学。模型 HUD、其他坐标和未迁移操作继续保留门禁。

整次按下、预览和松开组成一次 Adjustment。全部操作模式记录实际变化；仅显式提交模式保留预览结果而不记录 Adjustment。没有数值变化时不产生记录，也不清空 redo。原有显式登记不被替代。

取消、失捕、失活、关闭、重置和重新绑定使用统一取消链。取消按字段恢复仍匹配最后预览的自有修改，保留外部已经改动的字段。附件、父模型、父骨骼、资源、关键帧池及工程身份必须有效；不能跨新帧覆盖新的求值姿态。松开使用实际光标与原生居中拖拽语义收尾，避免旧消息坐标丢失最后样本。

历史保存实际对象及数值，撤销和重做不重新读取源文件，不依赖当前选择或当前模型槽号。未登记姿态、物理标志和旧撤销环不因刷新被额外改写。附件 HUD 专项最终 8,144 项通过，包含同步控件通知和释放期间的取消；实际 PMX／PMD 宿主及整合结果见验证表。

## 同模型跟随特殊视口

此分支要求处于模型面板、已启用相机跟随，且相机父模型就是当前选择模型。迁移保留原生分支差异：

| 操作 | 原生行为及历史 |
| --- | --- |
| 右键拖动 | 只更新原生视图提示，不旋转模型或写骨骼；没有数值变化就不产生历史。 |
| 中键拖动 | 按原 float 运算平移视图偏移，保留 Shift 优先于 Ctrl 的步长规则；整手势记录一次 Adjustment。 |
| 主窗口滚轮 | 只更新原生提示，不改变相机距离或骨骼；不伪造数值变化和历史。 |
| 浮动窗口滚轮 | 保留已迁移的原生距离计算，不替换为主窗口特殊分支。 |

特殊分支不隐含修改骨姿态或物理标志。它在两种记录模式下使用同一共同历史边界，真实 no-op 保留 redo。候选校验模型、父模型／骨骼、对象和资源身份，并按实际保留对象计入预算；失败不回退旧 undo 写入。

取消只恢复仍由本手势拥有的字段，纯 UI 选择变化不能使自有预览永久遗留。新帧、工程代次、关键帧池、父对象或附件关系变化仍须拒绝覆盖；撤销和重做保留当前无关字段。专项首轮 1,317 项包含与未绑定原生运算的逐样本比较，追加回归与最终结果见验证表。

### 同步控件通知中的取消

同模型平移写入偏移后，原生提示刷新会同步发送 WM_ENABLE；附件轴回显会同步发送 WM_SETTEXT。宿主先接受已经实际写入的样本，再发送这些通知。通知中发生捕获移交或取消时，回滚包含当前样本，并保留外部另行写入的字段。仅允许执行样本而尚未发生原生写入时，不预先认领其他作者的值。

相机及附件松开时的最后采样也可能触发读数回调。宿主持有旧手势的确切身份，在回调后再次检查；若旧手势已取消或被新手势替换，吞掉该旧释放消息，不结束新事务、不覆盖新鼠标坐标，也不释放新捕获。同模型原生释放执行相同身份复核。对应回归使用真实 EDIT、BUTTON 和窗口消息验证，不替换生产运算。

## 参数滑杆交叉覆盖

实际桌面轨迹确认方向滑杆 458、459、460 的客户区高 20 像素，原纵向间距只有 18 像素。相邻窗口重叠 132×2 像素；一个滑杆绘制时会改变未收到绘制消息的相邻滑杆像素。首轮 ordinary 和 bound 均观测到 12 次相邻像素变化，父窗口无子窗口绘制的像素变化为 0。

修复只调整 `ui_windowsize.cpp` 中方向组第一行和第三行的纵坐标，使三行相邻而不相交。保留每行完整 132×20 客户区，原生 thumb 和 channel 均在范围内；不缩短控件高度，也不更改原生数学、历史、绘制样式或缓冲机制。修复后的方向组同时避开上方 RGB 滑杆及下方读取、登记按钮。

第二次真实轨迹中，普通路径和共同历史路径均为 7 个控件实际拖动、7 个实时数值变化、父窗口像素变化 0、相邻控件像素变化 0。独立回归逐一检查 42 个空闲相邻样本；临时恢复旧几何时可以检测到交叉覆盖，恢复新布局后保持。

两模式的受控擦除观察仍各有 7 项暴露背景。该步骤主动触发擦除，用于分离绘制阶段，不能据此认定实际可见闪烁。已证明的是方向组交叉覆盖消失；RGB、视角等其余滑杆的残余肉眼闪动仍未声明验收。

## 保留的边界

- 普通宿主 `mms.edit` 继续关闭，可写属性尚未开放；受控宿主通过不等于公共编辑 ABI 已发布。
- 原始 `mmd932` 兼容产品配置不加载 ABI；独立契约或共享模块通过不改变该配置。
- 未增加公共 animation、render、独立求值、多视口、洋葱皮、格式编辑或复杂绘制接口。
- 未提供完整 STATE、订阅、自动依赖、SUBTREE、DEPENDENTS、插件量测提供者或布局撤销。
- Win7 SP1 x64、CPU 基础路径和 AMD 兼容约束保留；Win7 与 AMD 真机尚无验收。本机构建、PE 检查及测试不能代替目标设备。
- RGB/FOV 连续拖动的肉眼闪动、混合 DPI 跨屏和其他目标设备绘制仍需独立验收。

剩余工作以[需求核对](abi-remaining-work-2026-10-17.md)为准。本批不宣称全部 ABI 需求完成。
