# 独立网格场景来源（2026-10-27）

新增内部 `MeshSceneSource`，在调用方保证串行的同一安全点冻结骨架场景、各模型网格、表情定义和表情轨道。它复用骨架来源的对象身份、代次及跨模型依赖检查，不保留活体模型指针。求值时使用同一个 `EvaluationTime` 生成骨架与网格帧，结果拥有各自数据，源模型和来源销毁后仍可读取。

来源、结果和工作空间分别计费并检查上限，失败不发布部分结果。计费不等于进程峰值限制，表情求值自身的临时分配不包含在此上限内。该接口仍是内部实现，不提供插件 ABI、渲染、历史物理或 PMX 2.1/QDEF。当前连续表情采样使用与骨架一致的浮点时间，离散骨架选择使用 `EvaluationTime` 的精确离散值。

完整配置和原始兼容配置产品构建通过；原始兼容配置不编入新模块。网格专项 586 项通过，包含既有 PMD/PMX CPU 路径对照，以及同一来源结果对照、两个合成模型的身份和结果、重复来源拒绝、预算边界、逐分配点失败、并发求值和源销毁后的读取；骨架场景回归 10,477 项通过。表情回归在本批先前版本通过 873 项，本次最终修改仅调整捕获分配顺序和专项测试。证据保存在 `build/verification/abi-mesh-scene-20261027/`。
