# 骨骼数值输入共同历史验证（2026-10-17）

本批基于 `codex/plugin-abi` 的 `dc2bed5`，工作目录为 `D:/MMD-Next/MMS-abi-dev`。迁移真实视图菜单 `300` 的骨骼数值输入。相机模式未迁移，普通启动的 `mms.edit` 保持关闭。

## 交互及事务

沿用原有日文、英文及中文本地化对话框、六个数值字段、输入校验、确定与取消。位置使用原父骨骼绑定偏移，旋转保留原 Rz × Rx × Ry 次序和符号。位置分量未编辑时保留原动画位移；三个角度均未编辑时保留原始四元数，不做 Euler 往返。缩放、其他骨骼和选择不由此操作改变。

内部 `BoneNumericEdit` 分三步处理：

1. 打开前检查原生编辑准入，捕获对象 ID／代次、模型槽、骨骼及父关系、数组结构、帧号、共同历史修订、原姿态、缩放和显示值。
2. 运行原模态对话框，不持有共同历史预留，不持有模型资源所有者。取消时销毁会话，不写场景或历史。递归数值命令直接拒绝，包括递归时已切到相机模式的情况，防止共享输入缓存被覆盖。
3. 确定后重新检查绑定和编辑准入，验证对象存在及代次后才读取当前原生结构。所有来源仍匹配时先计算完整目标并检查有限值，再通过 `NativePoseScope` 预留、写入和采用为一个节点。失败回滚后释放预留；成功并解锁后才更新窗口读数及历史按钮。

相同输入不设置未登记标记、不标工程 dirty、不截断 redo。对话框期间选择、帧号、原姿态、父偏移、模型身份、数组结构或历史修订改变时，旧输入被拒绝；不会把输入写到后来选中的对象。共同撤销与重做按原对象执行，保持当时播放头。

## 代码复核

`SharedHistory::CheckNativeEdit` 是宿主内部预检查，包括插件未结束事务和回调限制。它不保留锁，也不改变通用 `Enter` 的混合事务行为。打开前及应用前均调用；真正写入仍由已有事务做最终校验。跨模态仅保存原模型和历史的身份信息及指针，不持有所有权。读取保存的原生指针前先校验当前绑定、活动槽位、对象 ID 和代次；应用本身仍要求 `MMDApp` 存活。

原始兼容构建通过编译条件保留旧命令路径；本批没有单独重建该 profile。未新增公共 C ABI、服务或系统／显卡依赖。普通宿主未绑定时仍保留原行为；局部迁移不能证明其余原生写入已经统一。

复核加强了两处边界：递归相机数值命令也须被外层骨骼对话框拦截；过期用例须使用与当前值不同的目标，避免无操作掩盖缺少校验。最终真实对话框用例在帧号或插件历史变化时尝试写入不同坐标，确认旧输入没有生效。
