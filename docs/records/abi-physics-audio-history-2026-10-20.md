# 物理模式与音频共同历史

日期：2026-10-20。目标为 `codex/plugin-abi`，普通 `mms.edit` 继续关闭。证据目录为 `build/verification/abi-physics-audio-history-20261020/`。

## 物理播放模式

菜单 265／269／270／272 在共同历史绑定时记录一次显式提交，两种历史模式行为相同。记录保存逻辑模式和稳定模型身份；撤销、重做根据当前各骨骼的物理开关，重新计算刚体模式及 kinematic 位。其他碰撞标志、当前骨骼草稿、选择和播放头不随记录回退。

发布不复制过去的物理世界、变换、速度或接触缓存。切换到启用模式仍提出原生重置请求，下一次真实物理泵按旧程序语义执行 settle；关闭物理不清除其他来源的待处理请求。不能把发布阶段保留世界状态写成后续模拟始终不改变世界。

重复选择同一模式不新增历史、不清 redo。存在瞬时派生状态差异时，只在历史互斥保护下修复这些运行字段，不写工程脏标志或新增重置请求。准备候选检查模型、骨骼、刚体及世界成员身份、模拟步数、存储别名和资源预算。

真实菜单、两模型共享 CPU Bullet 世界、另一个独立世界、后续 `PhysicsFrame` 与未绑定原生路径对照共 1,809 项通过。测试包括两种记录模式、无变化、忙碌、内存失败、预算、准备后失效、插件事务、其他模型姿态及真实模型删除恢复交错。

首两次运行失败保留在日志中。独立测试补齐 D3DX 初始化后，进一步发现夹具缺少真实根骨求值哨兵表；修复夹具后仍运行真实物理泵，没有删除相关断言。

## 音频资源

菜单 206、音频文件拖放及新增的「移除音频」菜单 32815 在共同历史绑定时进入同一事务系统。297 继续只控制静音。未绑定的普通宿主保留原加载流程，并提供真实移除操作。

准备阶段捕获或解码 PCM、波形、原文件名和必要的播放资源，并在本程序的 `data/audio-cache` 中持有私有 WAV。发布保持 `WaveAudioContext` 地址不变，只交换已经准备好的资源。当前活动音频有独立租约，历史记录淘汰后仍可继续播放。失败或取消不会先停止、清空或替换旧音频。

撤销、重做不重新读取原文件。已验证移走原文件后恢复波形，并启动真实 DirectSound feed。PMM 仍保存外部音频来源引用，本批没有实现音频嵌入工程或跨进程媒体打包。

非 WAV 解码缓存改到 `data/audio-cache/decoded`，按受控历史预算限制写出的 PCM；最终保留预算包括 PCM、波形、缓存及已准备播放缓冲。系统解码器内部单个 sample 的内存峰值不受此字节检查硬性限制。

本批还修复旧加载器的资源泄漏：重复打开 WAV 前关闭已有读资源，`CloseDataFile` 统一释放未启动的缓冲；活动 feed 仍负责自己的缓冲，完成标志发布后才能清理上下文。退出通过同一规则释放资源。原生 WAV 回归实际统计一次 idle buffer Release，并在退出后删除测试源文件，确认没有遗留读句柄。

音频专项 364 项通过，覆盖实际选择器取消、相同来源、Unicode 拖放、三语言移除菜单、两种历史模式、准备失败、预算拒绝、撤销／重做内存失败和插件复合事务。旧 WAV 波形对照测试曾因原加载链遗留句柄导致移走源文件失败，现已修复产品调用链并通过同一断言。

最终核心的四种真实压缩音频专项 217 项通过，两种记录模式都覆盖源文件移走、波形恢复、实际 feed、重做及小预算拒绝。原生 WAV 的 256 次并发停止／清理循环也通过。既有独立媒体测试完成四格式解码、Data 缓存、预算及视频往返检查。

受控 PCM 当前覆盖 8／16 位、单／双声道。24／32 位等旧加载器接受范围尚未迁移，普通入口保留原实现。MP3、AAC、M4A、WMA 取决于系统实际解码能力。上述边界仍是开放普通编辑服务前的待办，不能将这批迁移记为完整媒体扩展服务。

## 属性输入值模块

DSH 只交付 `ui_property_value.hpp/.cpp` 及其独立测试；Codex 负责接口约束、自审反馈、CMake 集成和编译运行。首次派发在执行前失败，用户要求重试后完成，正式结果保存在本批本地证据中。

内部 `UiPropertyValue` 拥有文本和字节存储，支持布尔、整数、浮点、向量、UTF-8、ID 和字节串的校验、解析、格式化及比较。失败保持原输出，内存不足返回 `MMS_E_MEMORY`。完整和基础配置均通过 617 项检查。没有修改 C ABI 布局。

此模块是原生属性输入的准备工作。`MMS_UI_INPUT` 控件、IME 草稿、提交冲突校验及原插件身份的编辑事务授权尚未接入，SDK 不能据此宣称已提供可写属性面板。

本批不增加特定显卡厂商或新系统依赖。构建仍保留 Win7 SP1 x64 和 CPU 基础路径；没有 Win7 或 AMD 真机验收结果。

完整和基础配置最终 Release 构建通过，完整配置产品原名及中文改名的隐藏启动、插件菜单、实时布局与退出通过。完整原生历史套件在既有 `morph Enter starts with one original ANSI EDIT on the current thread` 断言停止；本批二进制与此前保留的二进制独立执行该组均复现，因此没有登记整套通过。上述专项通过数只表示各自范围。
