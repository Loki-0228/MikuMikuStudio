# 独立 CPU 表情求值

## 结果范围

内部 `MorphEvaluationFrame::Evaluate` 将冻结的表情定义和一组直接权重计算为自有结果。输入无需保留到返回之后，计算和读取均不访问活动模型、播放头或渲染设备。不同线程可以使用同一份定义分别求值，结果互不覆盖。

| 输出 | 含义 |
| --- | --- |
| 顶点位置 | 恢复基础表覆盖的顶点，按实际模型顶点索引查询或按升序枚举 |
| UV | 五族分别查询，基础 UV 只计算 XY，附加 UV 计算四个分量 |
| 骨骼偏移 | 平移和累计四元数，尚未应用到骨架姿态 |
| 材质 | 基础通道、全部 28 个加算与乘算通道，以及合成后的 16 个材质属性 |

位置和 UV 是稀疏结果，不代表完整网格。没有基础表覆盖的顶点不会用当前编辑状态或零值补齐；定义引用缺失的基础值时，求值明确失败。骨骼结果不包含层级、IK、蒙皮或物理。PMD 只计算顶点表情，不产生 PMX 骨骼和材质结果。

本批没有新增公共 C ABI，也没有将该模块接入公开场景帧或渲染器。后续仍需将它与独立骨架上下文、基础几何和场景依赖组合。

## 原生运算语义

基础表按原序恢复，重复目标由最后一项覆盖。计算随后保持表情、组引用和载荷条目的原序。PMD 从表情 1 开始，PMX 从表情 0 开始。组只展开一层；组引用组不递归，被引用对象的直接权重不参与组贡献，但它仍可随后产生自己的直接贡献。

顶点和 UV 组贡献保持 `(offset * outerWeight) * referenceWeight`；骨骼和材质先计算 float 的 `outerWeight * referenceWeight`。不能将所有贡献合并为一个权重，也不能改变重复条目的累计顺序。只跳过原生已跳过的外层零权重，不新增组系数为零的提前跳过。

骨骼旋转保留原生的 `qw` 截断、轴角转换、负 `qw` 修正及近零轴判断。捕获和求值均不将输入四元数归一化。每条贡献按原序乘入累计四元数。

材质操作字节非零即加算，索引 `-1` 表示全部材质。16 个属性用 `mul * base + add` 合成。纹理、球面与 toon 的 12 个色调通道继续分别保存加算和乘算结果，供渲染器结合纹理采样使用，不冒充最终着色颜色。原生实现顶部关于这些通道未被使用的旧注释已修正，生产运算代码未修改。

## 输入、容量与寿命

权重数量必须精确匹配定义中的表情数，非空数组须有效；所有权重有限，允许负值和大于 1。所有顶点与 UV 定义目标均须有对应基础条目，包括本次权重为零的目标。

最终有效结果出现非有限数时，整次求值抛 `overflow_error`，不通过截断或改变运算顺序隐藏溢出。基础 UV 的 Z/W 保留最后基础项的原始位，材质内部保留字段不参与有效通道检查。

默认保留额度为 64 MiB，按自有对象和 vector 实际容量计费。稀疏位置与 UV 存储按基础条目数量分配，不按完整模型顶点数分配。重复项压缩后的容量仍计费。额度不代表构造期间峰值内存。

每次求值在私有候选内完成，异常不发布部分结果，也不改变输入。结果不保留定义或权重指针；读取无需分配，非法序号不改变输出。PMX 只有存在非空骨骼表情时才创建按骨骼索引覆盖的偏移数组，无骨骼表情不分配此数组。

专项使用 12 组私有模型对照真实原生路径。`PrepareGpuModelInput` 执行原生顶点和 UV 表情，`ModelApplyMorphs` 执行骨骼及材质表情，再逐位比较有效通道。对照覆盖重复基础项、组和直接贡献交错、负权重、过冲、非交换旋转、原生四元数特殊处理及全材质加乘。

独立手算用例还验证三次乘算因子 `.75` 的结果为 `.421875`，组引用组不递归，以及 PMD 基础表情不参与加权。边界用例覆盖稀疏索引、所有读取器的越界输出、输入不合法、零权重目标缺基础值、九类结果溢出、精确额度及逐次分配失败。接近 `INT32_MAX` 的顶点身份范围仍只按少量基础条目分配。

销毁源、定义及权重后，四个线程读取结果并禁止线程内分配。另有四个线程分别执行 100 次独立求值，检查输入不变且输出互不覆盖。

真实宿主从原创 PMX、PMD 文件加载模型，设置注册的 0、10、20 帧原生表情键，故意让当前未注册权重偏离它们。在后台采样 0、5、10、15、20 帧后计算，与手算位置、UV、骨骼偏移和材质通道核对。修改一个已注册峰值再捕获新运动源，两份旧新结果保持各自值。检查覆盖完整模型和表情载荷、键池、游标、CPU 顶点、骨骼、材质、作者层、播放头和修改标志。

删除模型、保存并重载 PMM 后，冻结输入仍可产生原结果；重新捕获已保存的运动也得到原手算值。最后销毁全部模型与输入快照，已发布结果仍可由工作线程读取。该流程不代表完整 PMM 格式往返验收，也不证明最终渲染或 IK 结果。
