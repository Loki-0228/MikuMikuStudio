# 地面阴影浓度共同历史验证（2026-10-17）

本批基于 `codex/plugin-abi` 的 `23fffac`，仅修改 `D:/MMD-Next/MMS-abi-dev`。菜单 `248` 无模式浓度窗口的文本和滑杆接入受控共同历史，普通 `mms.edit` 仍关闭。

## 作者数据与交互

文本 Enter／失焦由 `TryCommitBoundProjectedShadowText` 接管，滑杆 `WM_HSCROLL` 由 `TryCommitBoundProjectedShadowSlider` 接管，最终共用 `ApplyBoundProjectedShadowAmbient(app, value, changed, dialog)`。这些是宿主内部 C++ 接口，不是新增公共 C ABI。未绑定及原始兼容 profile 保留原有路径。

文本沿用 64 字节缓冲区、`strtof`、尾随字符容忍、非有限数值拒绝、`0..2` 限制及两位小数显示。滑杆位置沿用 float 乘以 `100.f` 的截断规则。修改标记为假时不把显示精度写回作者值，因此 Enter 后失焦、重新打开但未编辑均不产生舍入历史。有效输入仍设置原输入消费标记 `messageSeen`，该标记不进入工程历史。

滑杆沿用整数位置经 double 除以 `100.0` 再转 float 的原计算，成功后保留原始刻度。不能把该 float 再乘以 100 来替换当前刻度，部分数值会偏移一格。普通刷新在已有刻度仍表示当前作者值时保留它；不同值的历史刷新则计算相应刻度。普通刷新保留尚未提交的文本，提交失败或输入无效后恢复当前作者值的读数。

滑杆仍实时生效，每次有效浓度变化提交一条共同历史。相同位置的重复消息不增加历史，也不截断 redo。实现不跨窗口消息持有事务；尚未合并整次鼠标拖动的历史。关闭窗口保留已生效值，用户通过共同撤销恢复，关闭按钮不回滚该窗口期间的所有编辑。其他原生历史入口沿用既有无模式窗口互斥，通常在关闭窗口后撤销。

## 准备、发布与来源

`ShadowAmbientChange` 保存浓度、G、B、A 四项 float，目标四项同值。撤销恢复四项原值，即使来源镜像不相等。PMM 沿用既有浓度字段与加载规则，本批不增加文件格式字段，也不声称四项镜像均独立持久化。

记录检查工程相机键池身份。正常扩容不影响历史；替换工程来源后返回 STALE，保持数据和游标。首次准备核对捕获来源，短期候选另核对帧号、四项当前值、发布方向和记录代次。发布只写四项 float 及记录状态，不分配、不调用插件、窗口或 GPU，也不求值场景。提交完成后才标记 dirty 并刷新控件，不改变选择、播放头、模型姿势、关键帧、阴影显示或混合开关。

入口先检查共同历史门禁，拒绝插件未结束事务、回调冲突、播放、录制、场景替换、保存、其他模态编辑和不相关鼠标捕获。只有所属浓度窗口可使用窗口内的编辑入口；滑杆捕获仅允许其自己的滑杆，避免真实拖动时误拒绝。内存失败发生在私有准备阶段，作者四项值尚未写入，不需要逆向重演旧 UI 操作。UI 通知在发布后执行，可选刷新失败不把成功提交报告为失败。
