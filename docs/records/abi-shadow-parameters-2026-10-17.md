## 行为与接口

`CommitBoundShadowNumber` 在旧文本写入前消费 EDIT 修改标志，验证完整输入后按原七字符窗口读取。增强版旧路径 `SetShadowSliderPosition` 先接收整数，再限制到 `0..9999`，最后写 `float((10000.0 - position) / 100000.0)`。例如 `4321.875` 对应整数 4321，再换算为距离。本批保留这一规则；有限超大输入先限制范围，再执行整数转换，避免旧代码的超范围浮点转整数。原始兼容 profile 的直接 double 换算未修改。

距离读回沿用 `ShadowSliderPosition` 的四舍五入，文本和滑杆由 `SyncSelfShadowControls` 同步。撤销保存原始 float 距离，不从显示整数重建。未修改读数不写回，重复失焦和 Enter 不创建多条历史。完整非法输入、NaN、无穷、超长内容、尾随非空白、忙碌和准备失败不改变作者数据、dirty 或 redo，不回落旧写入。

内部入口 `ApplyBoundShadowDistance(MMDApp&, value, changed)` 接收作者距离；`TrySetBoundShadowMode(MMDApp*, mode)` 接收 0、1、2。后者在有显式绑定时消费拒绝和无操作。按钮在命令到达前可能已改变外观，因此拒绝和无操作也从作者数据恢复单选框；不为恢复外观追加历史。这些入口不属于公共 C ABI。

成功后按旧规则激活自阴影轨道。轨道已经选中时保留多行选择；激活未选中轨道时清除其他行。无操作和失败保留选择。模式和距离各自提交一条记录，可以与插件编辑按顺序撤销；没有独立取消对话框。未提交文本不创建场景历史，已提交操作使用共同撤销恢复。

## 记录与复核

`ShadowPoseChange` 保存距离和模式的 before/after，并标明本条记录编辑哪一项。短期候选验证自阴影键池身份、记录代次、帧号、距离及模式。首次准备要求来源未变化；发布仅写本次字段及记录状态，不分配，不调用窗口、GPU、插件或文件读取。

长期撤销和重做只覆盖本条记录的字段，因此撤销距离保留后来改变的模式，撤销模式保留后来改变的距离。支持恢复旧工程中已有的完整模式整数，包括符号扩展后的值。键池扩容保留身份，替换池拒绝旧记录且不移动历史游标。记录不持有 GPU 或场景资源，不求值关键帧，不跳转播放头，不修改模型旧环、关键帧或附件。

UI 通知在提交成功后执行，可选通知失败不把已完成编辑报告成失败。插件历史回调中的控件更新仍由既有安全刷新处理。本批没有新增 C ABI 表、运行库或系统接口，没有改变原始兼容 profile 或未绑定路径。
