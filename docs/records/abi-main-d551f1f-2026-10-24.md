# 原版阴影范围盒与动态精度下限同步

日期：2026-10-24。工作区 `D:/MMD-Next/MMS-abi-dev`，分支 `codex/plugin-abi`，起始提交 `52d1d5c`。本批同步 main 已提交的 `d551f1f`，main 核对 HEAD 为 `d551f1f`。

## 来源行为

`d551f1f` 取代上一批可见接收面覆盖的调优方案：

- 默认关闭「动态精度」时，远景覆盖层回到 MMD 9.32 原版阴影范围盒：以相机目标为中心，横向边长 `2 / NativeShadowLateralScale(阴影范围, 1)`，默认范围 0.01125 时为 88.889 世界单位；场景包围盒比盒子小时收窄到场景自身范围。一个盒子覆盖整幅画面，不随场景包围盒或大物体扩张，因此建筑、延长地面等大物体不会把人物身上的阴影贴图摊薄。
- 开启「动态精度」时取消范围限制，覆盖层按场景包围盒拟合，并以这个方案作为需求基准；投影仍用相机目标、光源方向和最终视图，动态需求在焦点深度计算。
- 贴图尺寸只升不降：需求超过选定覆盖尺寸 2.5 倍时升一档，回落到 1.6 倍以下才回到选定档位，每帧最多移动一档，且永不低于滑条档位。默认范围盒覆盖人物尺度，覆盖贴图直接使用滑条档位尺寸；动态模式覆盖盒更宽，覆盖贴图仍用半档尺寸，细节层使用完整档位。
- 默认范围盒之外的投影物不进入阴影图，这是原版范围限制的保留行为；动态模式取消这个限制，但大场景的覆盖精度会低于默认范围盒。

## 实现

ABI 侧文件在上一批已与 main `66bdaa2` 对齐，本批直接采用新的纯函数与测试：

- [adaptive_shadow.hpp](../../include/mikumikustudio/adaptive_shadow.hpp)：`DynamicShadowQualitySize` 改为只升不降，去掉降档分支与低于选定档位的范围；`ShadowCoverageSize` 保持半档定义。
- [native_shadow_projection.hpp](../../include/mikumikustudio/native_shadow_projection.hpp)：`NativeShadowProjection` 的第二个包围盒参数改为横向半宽上限 `halfWidthLimit`。拟合盒超过上限且上限有限时，横向宽度固定为上限、中心回到相机目标；未超限或上限无限时保留场景拟合；深度轴仍取整个场景。
- [adaptive_shadow.cpp](../../src/render/adaptive_shadow.cpp)：按是否开启动态精度选择 `halfWidthLimit`（开启为无穷大，关闭为 `1 / NativeShadowLateralScale(ShadowDistance(), 1)`）；删除可见接收面覆盖与视图相对深度计算，动态需求改用场景拟合宽度和焦点深度；默认模式覆盖贴图用选定档位，动态模式用半档；细节层仍按焦点深度画面区域规划。ABI 的阴影偏好仍在中央 `data/settings.json`，未移植 main 的帧内顶点包围盒缓存，包围盒读取路径不变。
- [native_shadow_tests.cpp](../../tests/native_shadow_tests.cpp)：采用 main 版本，新增范围盒检查（默认盒不超过原版范围、显著窄于场景拟合、场景更小时保留自身范围）与动态精度只升不降检查；原可见覆盖检查移除。
- [tests/README.md](../../tests/README.md) 与[渲染指南](../../docs/guides/rendering.md)同步新的默认盒与动态模式说明。

与 main 的剩余差异只有 ABI 既有的设置存储与阴影包围盒读取路径，功能数值与 main 一致。
