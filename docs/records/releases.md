## English

### Changes in this release

- Fix missing or misaligned operation axes and HUD when Ray-MMD is enabled. The editing overlay stays visible after post-processing and aligns with the selected bone. [#49](https://github.com/Loki-0228/MikuMikuStudio/issues/49)
- Keep the exact starting frame when exporting a video from the playback range. Accept spaces around the start and end frame values and give the Chinese FPS label enough room.
- Fix AVI export with Ut Video compressors that require RGB32 input.

### Packages and installation

Extract the `full` and `minimal` Windows x64 packages into separate folders and run `MikuMikuDance.exe`. The full package includes extended editing, anti-aliasing, modern media and baking, and is required for extended PMM `0003`. The minimal package uses the `mmd932` profile and saves standard formats.

For NVIDIA double-sided drawing with original MSAA, download the optional `MMSNvidiaAAFix.dll` separately. Place it beside the full executable, install it from Help, and restart.

## 中文

### 本次更新

- 修复开启 Ray-MMD 后操作轴和 HUD 消失或偏移的问题。编辑叠层在后处理完成后仍然可见，操作轴与所选骨骼对齐。 [#49](https://github.com/Loki-0228/MikuMikuStudio/issues/49)
- 视频输出沿用播放范围的准确起始帧，支持在起止帧数值前后输入空格，并修复中文帧率单位显示不全的问题。
- 修复使用要求 RGB32 输入的 Ut Video 编码器时无法输出 AVI 的问题。

### 选择与安装

将 Windows x64 的 `full` 和 `minimal` 分别解压到独立目录后运行 `MikuMikuDance.exe`。完整包提供扩展编辑、抗锯齿、现代媒体和烘焙，扩展 PMM `0003` 需要完整包。最小包使用 `mmd932` 构建档，保存标准格式。

使用 NVIDIA 原生 MSAA 双面绘制修复时，请单独下载可选的 `MMSNvidiaAAFix.dll`，放到完整版程序旁，从「帮助」菜单安装后重启。

従来の MSAA で NVIDIA の両面描画を修正するには、任意の `MMSNvidiaAAFix.dll` を別途ダウンロードし、完全版の実行ファイルの横に置きます。ヘルプメニューから導入した後、再起動してください。

## 中文

### 本次更新

- 修复「最近打开」菜单偶尔把「导出视频」误判成「打开工程」的问题。确认视频参数后才开始录制。
- 独立预览窗口现在也支持拖入 PMM。拖放路径过长时会提示。
- 视频输出预检保留已有文件的内容。路径无法写入时显示完整路径和 Windows 错误码。修复 MP4 写帧失败后可能卡住录制窗口的问题。
- 「实时物理设置」新增「恢复默认」。按「确定」后应用。

- 修复 [#48](https://github.com/Loki-0228/MikuMikuStudio/issues/48)。视频输出对话框自动带入播放范围，并在本次运行内记住上次确认的输出帧率。
- 「显示」菜单新增整数播放帧率、跟随播放帧率的显示上限和可选的连续帧补间。播放帧率默认 30 FPS，设为 60 FPS 时同一段帧序列以两倍速度播放。时间轴会标出整秒位置。
- 内置实时物理默认以独立的 60 Hz 固定步长计算。可在「实时物理设置」中调整参数或跟随播放帧率。修复 [#46](https://github.com/Loki-0228/MikuMikuStudio/issues/46)，跟踪模式下向前逐帧时会继续使用已有的物理状态。
- 完整包的「全工程帧率缩放」默认保留相邻镜头的直接切换。压缩时合并关键帧会保留裁剪后的曲线。应用后打开工程另存为。
- 修复含旧式首帧前驱标记的 PMM 保存失败。在写入时规范化标记，保留工程内的关键帧和撤销状态。

### 选择与安装

`full` 提供扩展编辑、抗锯齿、现代媒体和烘焙。`minimal` 使用 `mmd932` 构建档，保留原版 MMD 功能及共享修复，保存标准格式数据。扩展 PMM `0003` 需要完整包。将两包分别解压到独立目录，运行 `MikuMikuDance.exe`。

可选的 `MMSNvidiaAAFix.dll` 单独下载。用于 NVIDIA 原生 MSAA 双面绘制修复。放在完整版程序旁，在「帮助」菜单安装并重启。设置绑定 EXE 完整路径，移动程序后需重新安装，卸载也通过「帮助」菜单。

## English

### Changes in this release

- Fix an intermittent menu routing error that opened a project picker when Export Video was selected. Recording starts after confirming the video settings.
- Drop PMM projects onto the detached preview as well as the main window. A message appears when a dropped path is too long.
- Check output permissions without truncating existing files. A failed check displays the path and Windows error code. Fix a possible recording hang after an MP4 write failure.
- Restore defaults in Real-time physics settings and choose OK to apply them.

- Fix [#48](https://github.com/Loki-0228/MikuMikuStudio/issues/48). Video export starts with the playback range and remembers the last confirmed output FPS for the session.
- The View menu adds an integer playback FPS, a display cap that follows it, and optional interpolation between adjacent frames. Playback defaults to 30 FPS. At 60 FPS the same frame sequence plays twice as fast. The timeline highlights each whole second.
- Built-in real-time physics uses independent fixed steps at 60 Hz by default. Real-time physics settings lets you adjust simulation parameters or follow the playback FPS. Fix [#46](https://github.com/Loki-0228/MikuMikuStudio/issues/46) so a forward step in tracking mode continues from the existing physics state.
- Project-wide frame rate scaling in the full package preserves adjacent camera cuts by default. Compression keeps the trimmed curves where keys merge. Applying opens Save As.
- Fix PMM saving for legacy first-key predecessor markers. The writer normalizes the markers without changing live keys or undo state.

### Packages and installation

The `full` package provides extended editing, anti-aliasing, modern media, and baking. The `minimal` package uses the `mmd932` profile and saves standard data. Extended PMM `0003` requires the full package. Extract the packages into separate folders and run `MikuMikuDance.exe`.

The optional `MMSNvidiaAAFix.dll` is a separate download for NVIDIA double-sided drawing with original MSAA. Place it beside the full executable, install it from Help, and restart. The setting applies to the full EXE path. Reinstall after moving the program and uninstall from Help.

## English

### Changes in this release

- Fix [#43](https://github.com/Loki-0228/MikuMikuStudio/issues/43): remove the fixed 2560×1920 main-window limit in both full and minimal packages, supporting ultrawide and 4K windows. The client area remains bounded by GPU capabilities and the current rendering buffer dimensions.
- Fix [#44](https://github.com/Loki-0228/MikuMikuStudio/issues/44): use the modern Windows save dialog for still-image export, retaining all seven image formats, automatic default-extension changes and overwrite confirmation.

### Packages and installation

The `full` package provides extended editing, anti-aliasing, modern media and baking. The `minimal` package uses the `mmd932` profile, retaining original MMD features and shared fixes while saving standard data only. Extract the packages into separate folders and run `MikuMikuDance.exe`.

Application packages include the executable and licenses. Models, user settings, MME, MMV, FFmpeg and the NVIDIA helper DLL are separate.

### Animation and files

Custom morph display groups authored in PMX files retain their membership and support expanding, collapsing, and mixed bone/morph groups. A morph may appear in multiple groups; all references share one morph track and keep keyframe display and selection synchronized.

Cross-model keyframe paste matches bone and morph names, using model order for duplicate names. A held Enter after a file dialog does not register a pose over loaded motion. Returning from another application does not treat released keys as new presses or delete selected keys.

PMM stores projects; VMD stores motion. Original MMD cannot restore MMS-only extensions, and re-saving in original MMD or the minimal build discards them. Extended PMM `0003` requires the full build. Keep separate copies when exchanging files.

<a id="optional-nvidia-fix"></a>
### Optional NVIDIA fix

Download `MMSNvidiaAAFix.dll` separately, place it beside the full build, install it from Help and restart MMS. It addresses NVIDIA double-sided drawing with original MSAA and applies to the installed EXE path. Reinstall after moving folders or computers. Uninstall from Help; deleting the DLL does not remove the setting.
