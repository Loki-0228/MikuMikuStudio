## 已核对的执行规则

模型窗口使用同一个 `Session.history`，共同撤销通过实际 `RunBoundObjectHistory` 执行。简单切换曲线来源不创建第二个撤销栈。模型来源的读取、写入及选择回调检查当前模型身份、稳定对象 ID 和历史绑定代次；换选模型后的旧来源拒绝写入。旧窗口只读不应阻止主窗口执行共同历史。

计划器在私有容器中构造目标原生关键帧与作者层。发布前准备共同历史；取消、内存不足和预算拒绝应保留原数据及历史游标。发布后宿主只刷新当前读数和通知，不使用整场景重新求值覆盖其他对象的未登记姿态。新增真实窗口回归检查提交前后焦点和窗口启用状态。

多骨骼及显示修改先汇总，再进入一次桥接、一次计划和一次共同历史提交。输入存在一项非法内容时，应整批拒绝；不能先发布合法骨骼再返回失败。

## 显示、IK 与绘制边界

显示曲线修改的是已有帧上的模型可见状态及 IK 启用状态。计划应按当前播放帧立即发布 `loadComplete` 和 `IkChain.enabled`；在其他帧撤销、重做时重新选择该帧的离散值，而不是恢复初次提交时的播放帧状态。

`PlanDisplayRegistration` 中的骨骼求值分支处理外亲选择器窗口，不是 CCD IK 求解。正常绘制的 `BoneFrameTransform_StandardLocals` 重建派生旋转，`BoneTransform_CcdIk` 按 `enabled` 消费 IK 状态。仅切换 IK 不应为此重新采样作者的 `trans` / `rotQuat`，否则可能覆盖未登记姿态。

新增隐藏窗口用例只验证离散状态即时发布、跨帧共同历史及作者姿态保留。其模型没有 CCD 链接、没有渲染器，不能据此宣布 IK 视口求解完成验收。完整 CCD/正常帧驱动的显示结果仍需相应运行用例。

## 新增真实窗口回归

入口为 `curve_sync_tests --bound-model-history`，也已接入默认运行。测试使用实际 `OpenMorph` / `OpenInterpolation` 窗口、托管原生池、共同历史门禁和真实 `EditStore` 插件事务。

- 在两种历史模式下交错记录表情、插件、原生插值、自由骨曲、显示、IK、另一骨骼和另一模型，再逐步共同撤销、重做。
- 在各次操作间切换当前帧，比对两模型原生记录、原始作者数据、PMM 作者记录、模型/全局帧上限和插件值。
- 检查隐藏系统表情选择、所选模型/骨骼及无关的未登记姿态。
- 检查取消真实拖动、预算拒绝、原生入口拒绝新增值/帧、旧模型来源只读及主窗口仍可撤销。
- 构造合法修改与坏表情通道混合的批次，验证整批拒绝；直接调用实际来源写入函数，不使用伪造的历史回调。
- 模型来源路径从开始即不存在；撤销、重做应依靠保留的数据完成。

上述断言已由主任务运行：模型专项入口通过，包含同一入口的默认 `curve_sync_tests` 也在完整回归中通过。
