# 显示通道的公开求值服务

## 本批能力

`mms.scene.evaluate` 1.2 追加源描述、IK 链枚举、外部父级选择器枚举、可见状态采样、IK 开关采样及父级选择采样。Windows x64 函数表为 152 字节，保留 1.0 的 72 字节和 1.1 的 104 字节函数前缀。旧创建入口仍只捕获骨骼。完整字段、线程及错误约定见 [SDK 参考](../../sdk/mms/evaluation.md)。

生产能力掩码为 `7`。骨骼位 `1`、表情位 `2` 和显示位 `4` 可以组合，所选轨道共享捕获身份、内存额度、句柄和停止保护。未选轨道损坏不阻止其他通道捕获。组合捕获在所有校验完成后才发布，失败保留输出。

显示状态与 IK 开关保留原始字节，分数帧读取前键，不归一化为布尔值。外部父级选择返回捕获时的目标模型引用、骨骼 ID 及连续有效窗口，模型全局选择器与骨骼零号明确区分。捕获检查所有可达键，包括未来键；启用引用失效时返回 `MMS_E_STALE`。目标删除、重载或槽位复用后，旧源仍保留原身份。后台采样只访问快照和冻结身份映射，不重新查找模型槽位。

所有入口复用原 CPU 求值服务。最后句柄释放后，已经接纳的采样仍保留源及插件上下文，结束后才归还额度。退役期间拒绝新工作，允许清理已有句柄。

## 支持边界

父级身份是元数据，返回启用状态不代表目标现在仍存活。本批未冻结目标动作，也未实现层级变换、IK 求解、表情形变、物理或完整场景帧。动作层、负帧、独立时钟与多视口继续待实现。未注册编辑姿态不参与采样。

原始兼容产品没有开放生产求值工厂；该配置的存储和 DLL 测试通过注入捕获器验证公共运行时。本批不修改 VMD 格式、插值协议及标记规则，不新增显卡厂商或新系统依赖。Win7 SP1 x64 与 AMD 真机仍待验收。
