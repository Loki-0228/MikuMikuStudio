# main 后台保存与图形功能同步

日期：2026-10-20。接续 `d60e02a`，同步 main 已提交的 `59ce650` 与 `877cdd3`。按功能适配 ABI，没有合入 main 工作区的未提交内容。

## 功能

| 功能 | ABI 实现 |
| --- | --- |
| 手动保存、另存为、定时备份 | UI 线程捕获独立快照，后台写盘。快照包含 PMM、扩展记录、插件数据及网格缓存引用；后台不访问场景、窗口、MME 或图形资源。同步保存接口仍可供旧调用方和紧急备份使用。 |
| 保存期间继续编辑 | 区分整个保存任务与捕获／完成临界区。磁盘写入期间可继续编辑；捕获拒绝尚未完成的事务，完成通知等待事务和拖拽结束。场景代次、场景修订、共同历史修订及插件运行时身份共同决定能否清除未保存状态。 |
| 插件数据 | PMM 与插件附属文件仍成对发布。`ProjectSave` 分为 UI 捕获、后台 `PublishDisk` 和 UI `Complete`，完成只更新已保存的字节基线，不重新载入插件数据或增加历史。 |
| 备份轮换 | 新备份发布成功后才删除旧备份，沿用 ABI 的配对删除规则；保护当前打开的恢复工程。覆盖、已满、失败等状态显示在原有标题栏。 |
| 导出前保存 | 视频与图片序列导出选择“完成后关闭”且有未保存改动时，显示说明及保存按钮。另存为由当前对话框持有；保存不关闭导出对话框、不重置导出参数。新增提示行沿用 DPI 和批次重绘机制。 |
| 相机模式切回模型 | 使用 ABI 的对象身份映射恢复已加载模型，保留相机行的实际选中状态；拒绝损坏映射，不误开模型文件选择器。 |
| 抗锯齿 | FXAA、TAA、SMAA 使用统一描边预处理；时域算法补充两像素外缘运动匹配。独立多重采样描边菜单退役，原生 MSAA 算法仍保留。旧配置读取时规范化为自动描边，不改写集中设置中的未知字段。 |
| 固定画面捕获 | 同步 MME 场景捕获工具及像素格式记录；此工具用于开发验收，不是发布插件。 |

首次直接运行自动备份测试缺少生成的 PMD 夹具，改用仓库夹具运行器后通过。首次模型控件宿主缺少其要求的本机 MME DLL，补入隔离测试目录后继续验收。这些环境失败保留在日志中，不记为通过。

专项测试发现并修复三处问题：本地化重建列表会把记忆模型覆盖成相机行；截图工具在 MME 首次场景初始化前重置设备会崩溃；首次成对替换失败时遗留的恢复记录会在后续读取时发布已报错的新版本。现在分别保留模型身份、先完成不推进时间的初始化渲染、在验证旧文件均未变后撤销本次失败发布。真正断电或部分替换时的恢复能力仍通过原有故障注入。

模型控件专项在开启测试 MME 自动保存时遇到第三方 EMM 映射提示。仅在独立控件测试目录关闭其自动保存后完成 UI 验证；用户配置不变，不据此宣称该材质映射问题已修复。实际 MME 抗锯齿和截图验收使用另一个隔离目录。

构建仍有既有共享中间目录及测试 `/UNDEBUG` 提示，未记为零警告构建。原版配置在 ABI 工作区的独立构建目录验证，没有覆盖 main 的稳定版。

## 边界

快照编码仍在 UI 线程执行，后台化减少的是磁盘等待，不能声称大工程保存完全无停顿。新建／打开工程在安全边界等待既有保存任务；最终退出先等待线程结束，避免释放宿主后再执行回调。

MME 的保存通知由 UI 线程发出，实际 EMM 写入仍由 MME 的后续渲染回调及其配置决定；通知不等于 EMM 已完成写入。

本批不改变标准 VMD 数据格式，不引入 MDS 标记兼容，不恢复独立曲线修复工具。Win7 SP1 x64、CPU 基础路径与 AMD 兼容要求保留；本机回归不能替代 Win7／AMD 真机验收。
