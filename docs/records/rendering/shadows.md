## 原版阴影范围盒与动态精度下限

2026-10-24 同步 main `d551f1f`。默认关闭动态精度时，远景覆盖层回到 MMD 9.32 原版阴影范围盒：以相机目标为中心，横向边长 `2 / NativeShadowLateralScale(阴影范围, 1)`，默认范围 0.01125 时为 88.889 世界单位；场景包围盒更小时收窄到场景自身范围。盒子不随场景包围盒或大物体扩张，因此人物大小场景的精度与同数值滑条一致。开启动态精度时取消范围限制、按场景包围盒拟合，需求在焦点深度计算，贴图尺寸只升一档且永不低于滑条档位（需求超过选定覆盖尺寸 2.5 倍升档，回落到 1.6 倍以下才回落）。默认模式覆盖贴图直接用滑条档位，动态模式用半档，细节层仍按焦点平面画面区域规划。

验证与限制见[范围盒同步记录](../abi-main-d551f1f-2026-10-24.md)。本节取代本页下方 2026-10-13 实现更新中的范围盒描述；中央设置与旧 `Data/adaptive_shadow.ini` 迁移约定不变。

## 动态阴影共用范围与分辨率计算

原始记录：`ADAPTIVE_SHADOW_RANGE_20261012.md`。其中的版本、日期和验证范围沿用原记录。

<a id="record-adaptive-shadow-range-2026-10-13-实现更新"></a>
### 实现更新

当前完整包从实际 MMD 9.32 的光源投影变换生成参考矩阵。模型包围盒已在覆盖范围内时保留该矩阵；超出时只扩展必要的轴，并处理齐次 W 接近零的情况。异常光向使用安全投影。原版光源网格会随相机移动，当前验收检查沿同一光线的世界坐标保持相同阴影 UV，不再要求平移相机后矩阵逐字节不变。

固定与动态模式共用 `ShadowDistance()`，防裁切不回写项目或关键帧。动态需求根据实际投影的局部 UV 雅可比、视口和视距计算，保留精细端倍率、分辨率升降迟滞，以及远景屏幕包围盒的上限。实际分配最低为 512，最高受普通/美影档和硬件限制。

`Data/adaptive_shadow.ini` 第一行保存动态精度开关，命名键 `filter_enhanced` 保存独立滤波开关。旧文件中的第二个纯数值字段仍被忽略。滤波从当前 GPU 纹理读取尺寸，不通过美影勾选状态推测尺寸，因此动态分配变化会更新采样参数。

最新防裁切检查在 MME 环境中通过两模式、固定/动态及相机平移共八组。此前独立候选的十四组检查还覆盖轨道旋转、极轴光源和可见大小需求，近景 2048、远景 512。证据位于 `.local/artifacts/shadow-grid-candidate-20261013/`。

<a id="record-adaptive-shadow-range-2026-10-12-历史实现与验收"></a>
### 历史实现与验收

以下记录描述早期正交拟合实现及当时测量，供追溯使用；当前投影和分配结果以以上更新及最新测试记录为准。


动态缩放与固定模式现在共用 `ShadowDistance()`。滑块、数值框和阴影关键帧读取同一份值；实际投影在这个范围基础上增加模型覆盖保护。切换「动态缩放」只改变阴影贴图的分配策略，保留范围的完整浮点值。两种模式都显示「阴影范围」，左侧精细，右侧远处。

<a id="record-adaptive-shadow-range-原因"></a>
### 原因

旧实现用 `ShadowDistance()` 控制投影覆盖区，用另一个 `DynamicShadowPrecision()` 控制动态分辨率倍率。切换时复制滑块位置，只改变了界面显示。动态模式下继续向右拖动，原来的窄覆盖区仍参与绘制。平移视点使覆盖边界扫过模型时，自阴影会成片消失。

现在移除独立精度字段。`Data/adaptive_shadow.ini` 只保存动态缩放是否开启，读取旧文件时忽略第二个精度字段。项目与关键帧中的阴影范围仍沿用原保存格式。精细端的采样倍率直接从这份范围值计算，不另存一套滑块状态。

<a id="record-adaptive-shadow-range-覆盖保护"></a>
### 覆盖保护

高精细度不再以裁切模型为代价。每次绘制阴影时，程序读取当前变形后的模型顶点，以及可见附件经过世界变换后的范围，计算场景包围盒，再将八个角转换到光源坐标。

横向和纵向使用能容纳整个包围盒的正方形覆盖区；前后深度也要容纳整个包围盒。每侧增加半尺寸的 5% 作为余量，且不少于 0.25 个模型坐标单位。实际范围取滑块请求范围和这个安全范围中的较大值。固定和动态两种分辨率策略都应用此保护。

投影中心跟随模型范围，不随镜头平移。没有几何数据时才使用视点作为后备中心。安全范围只影响当帧投影，不回写滑块、项目或关键帧。滑块继续向精细端移动而范围已达到安全下限时，实际覆盖区保持不变。

<a id="record-adaptive-shadow-range-范围和像素密度"></a>
### 范围和像素密度

滑块位置 `p` 的有效范围为 0 到 9999，对应原有范围参数：

```text
s = (10000 - p) / 100000
k = 2（模式 1），或 3（模式 2）
请求的光源平面覆盖宽度 L_requested = 2 / (k × s)
实际覆盖宽度 L = max(L_requested, 包围盒所需宽度及余量)
```

`s` 是投影比例，数值越小，实际覆盖范围越大。以模式 1 为例：

| 滑块位置 | 请求覆盖宽度，模型坐标单位 |
| --- | --- |
| 0 | 10 |
| 8875 | 约 88.89 |
| 9500 | 200 |

覆盖宽度与分辨率分开计算。动态模式读取拟合后的投影矩阵，按实际覆盖宽度估算整个覆盖区投到画面上需要多少像素：

```text
Q = max(画面宽度 × abs(P00), 画面高度 × abs(P11))
精细端采样倍率 F = 2 ^ clamp(40 × s - 2, 0, 2)
透视相机的需求 N = 1.25 × Q × L × F / (2 × z)
正交相机的需求 N = 1.25 × Q × L × F / 2
```

`P00`、`P11` 来自当前相机投影矩阵，`z` 是场景包围盒在镜头前方的最近深度。包围盒跨过相机平面时，深度下限为 0.0001；全部位于镜头后方时使用最低分辨率需求。`1.25` 留出采样余量。扩大覆盖范围或靠近模型会增加需求，拉远镜头会降低需求。正交相机的需求不随镜头距离改变。

采样倍率在滑块 5000 及右侧为 1，向左提高，最精细端为 4。这恢复了此前最精细档的采样需求，避免覆盖保护生效后滑块继续向左却完全不影响分辨率。

包围盒包含屏幕外的几何。大型三角形可能覆盖画面，但所有顶点都在屏幕外。旧算法把这种情况误认为没有几何需求，会过早降低分辨率。保守估算可能为屏幕外的近处模型保留较高分辨率，换取平移时稳定的像素密度。

覆盖保护扩大范围时，按 `实际宽度 / 请求宽度` 补偿分辨率上限，并向上选择二次幂。最多增加一档：普通档由 2048 提高到 4096，美影档由 4096 提高到 8192。未扩大范围时仍保留原上限。此补偿同时用于固定与动态模式；固定模式直接使用补偿后的上限，动态模式按当帧需求选择分辨率。

实际尺寸还受显卡能力限制，分配失败时逐档回退。动态模式保留原有升降阈值：超过当前尺寸的 1.1 倍时升级，低于 0.4 倍时降级，避免边界附近频繁重新分配。

<a id="record-adaptive-shadow-range-边界"></a>
### 边界

保护覆盖参与范围计算的模型和附件。大场景或相距很远的多个模型会扩大覆盖区；达到分辨率上限后，每个模型单位获得的像素数会减少。第三方 FX 在顶点着色器中额外产生的位移没有计入此包围盒。

本次没有改变光源、自阴影模式或第三方 FX。包围盒读取遍历全部顶点，避免稀疏采样漏掉极值；尚未测量这一步的性能开销。独立的原版功能兼容构建继续使用原版投影，正式 MMS 完整构建使用上述覆盖保护。

## MME 自阴影滤波与两种构建档

原始记录：`MME_SHADOW_FILTER_20261013.md`。其中的版本、日期和验证范围沿用原记录。

完整包采用已确认的候选效果：默认阴影恢复 9.32 的线性深度采样和明暗过渡，同时保留模型边界防裁切与动态采样。最小包采用修改前参考代码的阴影投影和 SM2、SM3 着色器，包括范围过小时的原有裁切行为。

<a id="record-mme-shadow-filter-完整包"></a>
### 完整包

`skin_effect_sm3.fx` 的 `DefSampler` 使用 `LINEAR`。模式 1 按深度差乘以 1500，再减去 0.3 后限制到 0 至 1。模式 2 使用 8000，并乘以阴影贴图的纵向坐标。材质明暗混合恢复线性插值，不再使用候选之前的比较结果重建、接收面导数修正和 `smoothstep`。

投影从实际 9.32 的光源变换恢复，再由 `FitReferenceShadowProjection` 扩展到模型和附件边界；异常光向才使用安全投影。`UpdateAdaptiveShadowMap` 根据有效覆盖范围、屏幕尺寸及视距选择采样分辨率。两种模式都保留最高精度下的覆盖保护；切换动态采样不另存一套阴影范围。

YYB Miku NT 的同名 EMD 会为衣服、袖子和裙子自动加载 `AlternativeFull` 系列特效。其采样器未完整声明过滤状态，因此宿主的线性采样状态仍必须正确。模型、EMD 和外部特效文件未修改。`MdsShadowMapSize` 每帧取当前 GPU 纹理尺寸。默认原生滤波不依赖该参数；可选「滤波加强」使用它把样条核换算为实际纹素，并结合屏幕足迹调整积分范围。高分辨率增加参与纹素数，不把少量采样点直接拉开。此开关只在完整包的 SM3 路径提供，默认关闭。

<a id="record-native-shadow-coverage-投影与材质"></a>
### 投影与材质

旧投影在相机旋转后的坐标中构造光源矩阵，再施加与视角有关的透视扭曲和纵向偏移。视点目标落在阴影贴图边缘，导致模型部分区域被裁切；旋转相机时裁切位置也发生变化。复现时，模型只占据阴影贴图底部的局部区域。

现在按场景坐标中的光源方向生成正交投影，以当前观察目标为中心。相机旋转不再改变投影矩阵和深度贴图。阴影范围仍由滑条控制，模式 1、2 分别使用原有常用横向尺度的 2 倍、3 倍系数，并保留各自的深度比较容差。此处替换了旧的视角相关扭曲，不能视作完全保持旧投影外观；没有引入全场景自动包围盒拟合。

PMX 投影材质也有两处错误：描边宽度为零时整块材质被跳过；是否双面投影读取了实际上保存「描边启用」的旧字段。现在投影取决于材质的投影标志，双面剔除取决于真实双面标志，均与描边开关、宽度独立。

SM3 和 SM2 材质着色器此前在坐标越界时直接返回亮色和高光，跳过 toon 明暗及暗部高光遮罩。现在越界只取消阴影采样，保留材质明暗。SM3 在覆盖判断前求导；SM2 使用紧凑范围判断及等价混色，满足 `ps_2_0` 指令上限。

「动态缩放」复选框接入既有面板复选框绘制，背景按实际位置绘制自阴影分区渐变，文字跟随同区浅色标签；保留勾选、悬停、禁用和键盘焦点处理。

### 行为

自阴影投影原先把镜头距离作为覆盖中心的 Z 坐标。拉远镜头会把精细阴影覆盖区域移离模型。本次将该中心固定在轨道视点的目标平面，保留光源方向、颜色和阴影范围参数。

自阴影栏目新增「动态缩放」，默认关闭。开启后按画面内网格到镜头的距离、投影比例和输出分辨率选择 512、1024、2048 或 4096 的阴影贴图；关闭美影时上限为 2048，实际分配也受显卡限制。分辨率变化使用不同的升降阈值，减少临界位置来回分配。该开关只控制阴影贴图分辨率，不移动光源或改变投影覆盖范围。

动态模式下，原范围滑条改为精度调节，5000 对应匹配结果的 1 倍，左右两端约为 0.25 倍和 4 倍，再按可用分辨率档位及上限取值。光源与原阴影范围不会写入该精度值。关闭后恢复原范围滑条，开关和精度偏好保存到程序 Data 目录。

视频导出的录制预览支持拖动边框和角点，保持导出宽高比。标题栏最大化按钮在原始输出像素尺寸与当前屏幕工作区适应尺寸间切换，预览大小不影响导出分辨率。

模型操作列表优先显示模型内部名称，仅在名称缺失时使用文件名。MME 材质分配列表在绘制文字时应用相同的语言选择、双向缺失回退和字典翻译。未知字典词保持原名；模型数据、MME 存储的列表文本、材质绑定标识和插件名称查询不随显示翻译改变。

自动翻译变灰的原因是旧代码按 Help 菜单位置禁用模型扩展菜单，该位置在新增条目后变成了翻译开关。现在按扩展子菜单的命令定位，加载 PMX、播放和重置不会误禁用翻译选项。

加载 MME 时，透明排序关闭使用原始材质记录顺序的一轮绘制。开启时保留优化绘制；再次关闭恢复原顺序。两种原生模型绘制入口使用同一条件。

## 插件默认绘制与原生阴影修复

原始记录：`PLUGIN_NATIVE_RENDERING_20261011.md`。其中的版本、日期和验证范围沿用原记录。

<a id="record-plugin-native-rendering-修复内容"></a>
### 修复内容

完整包关闭透明排序时保持既有原生“不透明、透明”两遍顺序。此前仅加载 MME 就会改成单遍，导致相同场景的遮挡改变；本次移除了该特殊分支。MMV 主场景使用宿主给出的材质分类，保留组内对象和材质顺序及附件边界。自定义 FX 仍只提交一次，不增加默认材质的实心纹素预遍历。

MMV 的新帧尾部接收本帧原生 R32F 自阴影贴图、投影矩阵、尺寸与模式。两端共用 DX9 设备，传递 GPU 引用，不逐帧回读 CPU。宿主检查阴影绘制与状态恢复结果，失败时清除输出，避免显示旧帧。MMV 有变形、删面或隐藏输出时，按同一原生矩阵重画完整阴影，避免保留变形前的投影。

MMV 内建默认着色器的技术名原先与输出目标 `Main` 重名，技术选择优先命中了无阴影路径；现改为专用技术名。外部 FX 的名称和选择优先级未改。

`MmvMmsFrame` 仅追加按长度检查的可选尾部；不改变嵌入场景和材质数组步长。旧调用方保留旧行为。此修复需要配套的新 MMS 和 MMV4MMS；MME 和 MMV 仍分别启用。

动态缩放开启时，三语面板改为左“高”、右“低”。关闭动态缩放时沿用原范围标签。

<a id="record-plugin-native-rendering-已知限制"></a>
### 已知限制

发布时扩大的透明排序回归有 5 项失败：`occlusion` 为 212 个像素断言，`low_alpha` 与 `maximum_limit`（各含 MSAA）各 9 个；提交 `12f75de` 的不可变发布源码结果逐条相同。后续逐项隔离发现测试遗漏纹理查询缓存失效、使用关闭排序的默认值，以及保留了已撤回的阴影遮罩实验断言。测试条件与当前功能的区别、复测结果见[透明排序回归复核](transparency.md#record-transparent-sort-validation)。这次复核不改变本发布的透明排序算法或阴影行为。

最小档不编入透明排序或 MMV。其格式边界与双向互导待验收状态见 [原版兼容构建档](../../reference/minimal-build.md)。
