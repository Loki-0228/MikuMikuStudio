# 背景媒体与音视频

## 格式与解码

最小包保留 WAV、AVI/VFW 背景和 AVI 输出。完整包通过 Windows 媒体组件导入现代音视频，并提供 MP4/H.264、透明 MOV 及图片序列输出。可用编解码器取决于系统，不能把本机支持推广到旧系统。

Windows H.264 解码器报告格式变更时，重新验证 RGB32 格式、步幅和裁切后复制画面；定位处理首帧时间偏移与片尾边界。

Windows 无法解码的视频可使用可选 FFmpeg。搜索顺序为程序旁 `tools/ffmpeg.exe`、同目录 `ffmpeg.exe`、`PATH`。FFmpeg 隐藏运行，仅继承专用管道句柄，RGB 画面经内存管道传递，不生成图片序列或转码缓存。替换或关闭视频时结束对应进程。

后备路径按媒体声明帧率采样，高位深输入转换为现有 8-bit RGB32 背景，不保留 HDR/10-bit 显示精度。主程序包不捆绑 FFmpeg。

## 后台视频预览

MP4、MOV 在独立线程解码，时间轴请求立即返回上一张可用画面。连续拖动只保留最新目标，停止后仍刷新已解码画面。预览长边最多 1024 像素；高分辨率或长关键帧间隔的视频仍可能追赶滞后。

录制与图片序列等待目标帧完成，避免把滞后的预览帧写入输出。异步取帧减少界面等待，不保证整个模型场景的帧率。

## 移动与缩放

[操作指南](../../guides/background-media.md)说明 Ctrl 拖动。图片与视频共用移动、缩放按钮，同时显示时优先操作上层视频。拖动目标在按下时确定，松开 Ctrl 不切换对象；捕获结束恢复光标。

位置按视口比例换算并保留小数，缩放保持背景中心。刷新背景顶点不重新解码当前视频帧。位置和比例保存在 PMM 既有字段。

## 图片与透明输出

图片、背景开关及输出透明度分别处理。PNG、DDS 透明输出和透明 MOV 不应把背景叠加到透明区域；导出需按对应输出方式核对实际结果，不能只看预览。

## 回归入口

`native_media_tests`、`media_render_tests` 和 `background_overlay_tests` 覆盖解码、定位、后台追赶、关闭、位置变换及输出。素材生成与命令见 [tests/README.md](../../../tests/README.md)。请求接口耗时不等于整帧渲染速度。
