# 模型 Toon 文件表共同历史

菜单 261 在共同历史绑定宿主中使用私有十项草稿。确认时一起准备文件表、纹理保活、缓存增量及历史预算，再发布一次显式事务。普通启动仍使用原入口，公共 `mms.edit` 尚未开放。

## 编辑与资源

打开窗口前固定模型身份、场景和绑定代次、历史修订、全部 1,000 字节原始字段、模型目录、材质引用、独立 PMX Toon 路径、共享纹理及颜色表。窗口使用 Unicode EDIT，Enter 只更新草稿；取消、关闭、无变化及准备失败不发布缓存或模型字段，也不清除既有 redo。

两种历史模式都将一次确认记为一次显式提交。新文件名必须精确编码为 CP932，并在 100 字节字段中留出终止符。未改字段保留完整原字节，包括首个 NUL 后的内容。撤销和重做恢复完整文件表，不移动播放头、不覆盖未登记姿态，也不重置物理。

旧自定义纹理必须已经存在于准确匹配的缓存项中。即使文件可读，缓存缺失或空纹理也拒绝编辑，避免捕获时加载一张此前未显示的图。新纹理可在私有准备阶段读取；文件丢失、空结果、不可计量资源、预算不足或分配失败均不能留下部分修改。纹理测量复用既有资源计量逻辑；COM 查询抛出异常且已写出引用时也会释放该引用。

发布前验证资源来源及完整预算。最终发布仅转移已准备缓存项并复制文件表，不分配内存或读取文件。历史保留前后纹理资源，重放不重新调用加载器。缓存替换先返回 `MMS_E_STALE`；真实资源描述不完整仍返回 `MMS_E_NOT_READY`，内存失败仍返回 `MMS_E_MEMORY`。

## 实际渲染路径

DX9 固定管线纹理和效果材质颜色共用同一组 Toon 引用规则。未分配引用使用中性槽位，标准名称可跨槽位选择 `toon01.bmp` 至 `toon10.bmp`；自定义表项通过模型目录和 CP932 文件名查找。PMX 独立 Toon 仍使用材质自身路径，PMX 共享表改为自定义文件名后使用模型相对路径。

路径查询使用有界栈缓冲，保留完整目录与文件名，不在每帧构造 C++ 字符串。PMD 初次导入同样按 CP932 解码，避免中文系统 ACP 将日文路径误解后回退到默认 Toon。导入先将完整 100 字节复制到带额外终止符的临时缓冲；合法满长字段可读取，原始字段不因解码被截断。满长但未终止的旧字段仍不进入当前私有编辑计划，不能把安全读取当作该编辑边界已解除。

可选 DX12 路径也接入相同纹理解析。独立启用配置已编译该源文件；正式 ABI 产物继续使用 Win7 基线、DX9 和 CPU 路径。没有把可选 DX12 编译结果当作硬件运行验收。
