# 曲线编辑器导航、快捷键与速度图修复

本批修改位于 `codex/plugin-abi`，本任务只写 ABI 工作区。完整配置和原版兼容配置产品均已构建；实际验证结果见本文末尾。

## 顶部帧刻度同步主时间轴和视图

编辑器把帧刻度画在曲线图上方，旧命中区却位于曲线图底部内部的 18 像素。因此点击可见刻度不能切换时间，反而在曲线图底部形成不可见的跳帧区。

`CanvasMouseDown` 现在按实际顶部刻度区域启动跳帧拖动。按下、拖动与松开都处理最新位置；重复到达相同帧不重复求值。底部范围条继续负责平移和缩放显示范围。

场景、表情和骨骼／缩放编辑器通过同一 `SeekMain` 路径更新当前帧，执行正常帧求值，并刷新主窗口帧号和视口属性读数。模型编辑器跳帧前验证捕获的模型身份。正在播放时先沿主窗口播放命令停止，再切换到目标帧。

跳帧检查窗口启用状态、UI 线程、烘焙锁、保存状态、场景发布状态及模态编辑状态。绑定共享历史时通过只读 `CheckNativeNavigation` 检查待提交事务、序列化准备和回调状态；此查询不使用禁止播放中编辑的业务门禁，允许安全停止播放。宿主另行检查原生对象操作、列表刷新待处理及各编辑对话框。导航不登记关键帧，不设工程修改标记，也不创建撤销记录。

## 激活编辑器的键盘操作

编辑器窗口、画布、通道树、普通子控件和原生插值面板共用以下命令映射：

| 按键 | 操作 |
| --- | --- |
| `Insert` | 按当前帧号和数值输入添加关键帧 |
| `Delete` | 删除选中关键帧 |
| `Ctrl+Z` | 撤销当前曲线编辑器的操作 |
| `Ctrl+Y`、`Ctrl+Shift+Z` | 重做 |
| `Enter` | 保留原有登记／应用行为 |

命令走现有按钮入口，沿用可写性、选择和禁用状态。拖动中、禁用窗口、Alt 组合及自动重复按键不触发这些编辑命令。文本框保留自己的撤销、删除、插入及 IME 消息处理。未把上述按键转发到主窗口，因而不会误操作主窗口的模型登记或历史。

`src/main/winmain.cpp` 不运行全局 accelerator；其中插件快捷键只接收主窗口及其子窗口消息。曲线编辑器是独立的拥有窗口，原消息循环无需修改。主窗口每帧登记／删除轮询已有 `OwnsWindow` 排除条件。

## 速度图保留连续导数

原生相机值采样使用单精度和固定 12 步时间反解。旧速度计算在前后各 `0.001` 帧取差分；长区间中两个值常落在同一量化格，结果形成接近零的水平线，偶尔出现尖峰。骨骼原生采样存在同类问题。

新增 `src/animation/native_curve_sample.hpp` 计算底层 Bezier 的双精度时间映射及 `dy/dx`。相机和骨骼平移速度按原始区间长度及数值变化换算。骨骼旋转和缩放先按精确时间映射采样，再按区间尺度求局部差分。奇异垂直切线用局部割线生成有限显示值，避免 NaN 或无穷大进入自动适配和绘制。

原有播放值采样不变，原生相机单帧保持规则不变；速度修复不写原生关键帧或改变运动。图线、关键点与自动适配继续使用同一通道的采样回调。

## 验证入口

以下回归均已通过：

- `animation_curve_editor_tests --timeline-input`：顶部刻度点击、连续拖动、松开最终位置、同帧去重、播放时跳转；编辑器根窗口及不同子控件的快捷键、输入框和 IME 排除、只读及禁用状态。
- `curve_sync_tests`：真实场景曲线宿主的主帧号、相机／灯光／自阴影／重力求值同步；禁用窗口和烘焙期间拒绝导航；工程状态及登记范围不变。绑定与生产相同的播放门禁后，跳转和停止按钮仍能停止播放；序列化准备及原生编辑对话框期间，两者都不能修改播放状态。
- `plugin_abi_tests` 的 `SharedHistoryNavigationChecks`：播放拒绝编辑时允许空闲导航；历史进入、准备、已应用和重置令牌、序列化准备／回调、插件事务／提交回调以及错误线程分别拒绝导航。
- `animation_curve_host_tests`：十万帧原生相机区间的线性速度及缓动速度，排除量化零平台与尖峰。
- `morph_curve_host_ui_tests --timeline-speed`：真实表情、骨骼及缩放宿主的帧号同步，以及十万帧骨骼位移、四元数旋转和缩放速度。

这批回归使用 CPU 与隐藏 Win32 窗口。它们不能替代真机鼠标、Win7 SP1 x64 或 AMD 设备验收。

最终整合十一组通过，见 `build/abi-curve-regressions-2.log` 及详细输出。编辑器全量 **2,145** 项，表情／骨骼宿主 **233** 项，ABI 契约 **1,804** 项，共同历史 **208,941** 项。顶部刻度与快捷键单独通过 **24** 项，见 `build/abi-curve-timeline-focused-1.log`；真实模型宿主导航与速度单独通过 **19** 项，见 `build/abi-curve-speed-1.log`。

真实场景同步见 `build/abi-curve-sync-1.log`，实际 VMD 读写见 `build/abi-curve-vmd-native-1.log`。最终相机保形与长区间速度专项见 `build/abi-curve-host-4.log`。最初速度断言用较短区间对量化值差分，误差超限；现改用独立前向参数的 `dy/dx` 参考，保留量化差异诊断，没有改变原生播放值。

产品构建见 `build/abi-curve-full-build-1.log`、`build/abi-curve-full-build-2.log`、`build/abi-curve-host-build-4.log`，最终相关目标重新链接见 `build/abi-curve-final-link-1.log`。原版兼容产品构建和四组回归见 `build/abi-curve-original-build-2.log`、`build/abi-curve-original-tests-1.log`。原名及中文改名产品启动、真实插件菜单／面板／队列、侧栏和关闭通过，见 `build/abi-curve-product-smoke-1.log`。
