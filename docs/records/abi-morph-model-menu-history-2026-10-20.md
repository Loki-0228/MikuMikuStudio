# 口型、眨眼与模型关键帧乘加共同历史

日期：2026-10-20。分支：`codex/plugin-abi`。接续[原生菜单迁移](abi-native-menu-history-2026-10-20.md)，补齐菜单 225、227、251、252。在共同历史绑定下，一次确认形成一次显式提交，两种记录模式均可撤销和重做。普通宿主的 `mms.edit` 继续关闭。

## 操作范围

| 菜单 | 行为与事务范围 |
| --- | --- |
| 225 口型偏移 | 对 mouth 分类的非零关键帧及其作者层重定时，保留零帧。负向移出有效范围的键被删除，修复剩余链头的 previous；撤销恢复原始池和完整作者数据。未登记权重、其他模型、骨骼和无关通道不变。 |
| 227 随机眨眼 | 确认后只生成一次随机序列，在私有池中准备全部关键帧、容量和作者层。共同历史保存该结果及本操作拥有的阶段／高水位元数据。重做不调用随机源，准备失败不留下部分键。非前进随机源有重试上限。 |
| 251 骨骼乘加 | 只修改实际选中键，保留原生位置运算、Z／X／Y 欧拉重组、角度符号和浮点精度。MMS 缩放按原矩阵行长度乘加并保留方向与剪切，缩放和自由作者数据与原生键同一提交。 |
| 252 表情乘加 | 对实际选中键按原生浮点乘加，不额外限制为 0～1。原始作者层与派生层保留，撤销精确恢复，未选键和未登记权重不被刷新覆盖。 |

对话框打开前捕获来源。确认后重验稳定对象、绑定、完整键与作者状态，再准备候选。取消、空范围、恒等操作和无变化保留已有 redo。范围错误、非有限值、溢出、内存或预算拒绝均在发布前处理。

历史预算包括来源快照、目标负载和 retained owner 的实际资源账本，发布前核对账本覆盖。模型乘加只进行当前模型的局部干净姿态求值，不增加无关模型的全局物理重置请求，也不清除此前已有的待重置状态。

提交后的可选绘制、曲线通知和计数提示与提交结果分开处理，UI 失败不会把已提交的历史报告为已取消。252 通知表情来源，251 通知骨骼来源。
