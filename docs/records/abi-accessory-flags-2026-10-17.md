## 行为与接口

原生三条命令通过 `TryToggleBoundAccessoryFlag(MMDApp*, field)` 接管。字段 `0..2` 分别对应显示、加算混合和投影。切换根据附件作者字节决定，零变 1，非零变 0，不读取复选框决定方向。拒绝后恢复复选框，避免原生按钮已改变外观而作者数据未改变。

内部显式入口 `ApplyBoundAccessoryFlag(MMDApp&, slot, field, enabled, changed)` 接收目标布尔值，与数值编辑使用相同历史。先检查编辑绑定、运行状态、事务、对象及键池，再准备和提交；准备失败不写活动对象、旧模型环、选择、dirty 或 redo。同值不创建历史，也不截断后续重做。该入口是 C++ 内部接口，不是新增公共 C ABI。

显示和投影成功后按旧规则激活附件轨道，已经选中的附件保留多行选择；加算混合沿用旧行为，不激活附件轨道。窗口与控件刷新在历史发布后执行，插件历史回调使用既有安全刷新。可选通知失败不把已完成编辑报告成失败。普通点击每次切换都改变值并记录一条；没有独立取消对话框，已提交开关通过共同撤销恢复。

## 共享记录与复核

扩展 `AccessoryPoseChange`，在同一快照中分别保存八项 float 数值和三个 byte 开关。数值按数组内容比较，开关按元素比较，不对含填充字节的整个结构体执行 memcmp。短期候选检查对象代次、当前帧、完整数值、三个开关及父绑定，发布只写本次字段，不分配、不调用窗口、GPU、插件或文件读取。数值历史的换算及单字段语义保持。

撤销精确恢复原字节，包括 7 等非标准非零值；新切换目标仍只写 0 或 1。长期往返保留其他开关、数值姿态与绑定，不以当前附件选择重新定位目标。稳定对象 ID、槽位、指针及键池身份均须一致；受控删除恢复允许对象代次更新，正常池扩容保留身份，槽、池或同址新对象身份替换则拒绝旧历史。

开关记录复用附件文本的寿命安排，不新增网格或大容量备用键池所有者。受控导入／删除记录持有资源，共同历史先恢复删除，再撤销更早的字段；更早字段节点先于后续删除节点淘汰。未迁移代码绕过历史释放对象仍不属于支持范围。
