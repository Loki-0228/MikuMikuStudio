# NVIDIA 双面绘制修复的重新安装同步

日期：2026-10-24。工作区为 `D:/MMD-Next/MMS-abi-dev`，分支 `codex/plugin-abi`，起始提交为 `a1c3d3b`。本批同步 main 已提交的 `c48c156`，main 核对 HEAD 为 `66bdaa2`。

## 来源行为

`c48c156` 修正 `MMSNvidiaAAFix.dll` 的帮助菜单入口和安装语义：

- 已安装时帮助菜单同时提供「重新安装」和「卸载」两个命令，不再只能先卸载。
- 重新安装调用同一注册流程；`nvidia_antialias_fix::Execute` 不再把「已启用」视为空操作，每次显式安装都重新写入并保存设置。
- 安装与卸载结果提示改为说明设置只作用于当前目录的 `MikuMikuDance.exe`，换目录、换程序或换电脑需要重新安装；提示保留 DLL 才能保留菜单入口。
- 抗锯齿文档补充安装范围、重新安装条件与白边排查顺序。

## 实现

ABI 的四个代码／测试文件在上一轮核对时与 main 改动前完全一致，因此本批直接采用 main `66bdaa2` 版本，没有行为改写：

- [nvidia_antialias_menu.cpp](../../src/window/nvidia_antialias_menu.cpp)：`InstallLabel`、`UninstallLabel`、`RemoveEntries`、三语结果文本、安装与卸载命令分支。
- [nvidia_antialias_menu.hpp](../../include/mikumikustudio/nvidia_antialias_menu.hpp)：新增 `kUninstallCommand = 34921`。
- [nvidia_antialias_profile.hpp](../../src/render/nvidia_antialias_profile.hpp)：已启用路径也执行写入与保存，使重新安装成为真实操作。
- [nvidia_antialias_fix_tests.cpp](../../tests/nvidia_antialias_fix_tests.cpp)：重复启用的写入次数期望改为重新安装语义。

文档按 ABI 现有布局补充：[渲染指南](../../docs/guides/rendering.md)增加「安装范围与重新安装」与「安装后仍出现白边或锯齿」，[抗锯齿记录](../../docs/records/rendering/anti-aliasing.md)记录本机核对边界。
