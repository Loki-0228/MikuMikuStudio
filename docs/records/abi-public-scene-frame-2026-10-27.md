# 公开骨架场景帧（2026-10-27）

本批基于 `codex/plugin-abi` 的 `d440323`，为 `mms.scene.evaluate` 追加 1.4 骨架场景来源与帧接口。插件可在 UI 安全点冻结全部模型，再在后台求值、读取和保留独立帧。接口参考及 C 示例见 [SDK 文档](../../sdk/mms/evaluation.md)；设计边界见[接入方案](abi-public-scene-frame-plan-2026-10-27.md)。

## 已实现范围

场景来源按原槽位捕获全部模型、注册动作、显示和外亲依赖，包括未来键中的目标。模型对象及每根骨骼沿用 BIND 快照的身份注册表。模型删除、槽位复用或工程重载不会改变旧来源或帧的数据；帧不保留活体模型指针。

求值从独立工作区及确定的加载初值开始，按原计算顺序先完成全场物理前阶段，再完成全场物理后阶段。结果包含局部动作、骨骼表情、层级、IK、外亲和尺度，返回刚性与含尺度变形矩阵、两阶段附着矩阵、关节位置及原始可见字节。关键帧选择使用[精确离散时间](abi-scene-exact-time-2026-10-27.md)。

该帧关闭物理模拟，不提供网格蒙皮、附件、相机、灯光、独立播放时钟或视口渲染。循环外亲采用原生两轮扫描和确定初值，不声明等价于依赖上一帧残留矩阵的连续播放。原始兼容产品未开放生产求值工厂；内部接口库仍参加双配置回归。

## 共享身份与寿命

1.4 表为 232 字节，保留 1.3 的 160 字节前缀。九个追加函数查询能力、创建和描述来源、枚举模型和骨骼、求值、描述帧并读取骨架结果。旧 `retain` 与 `release` 适用于三类载荷；错误类型返回 `MMS_E_UNSUPPORTED` 并保留输出。全部模型和骨骼 ID 在一个来源中全局唯一，失效的未来目标拒绝整个捕获。

旧通道来源、场景来源和帧共用同一句柄表、插件所有者和退役状态。场景来源和帧分别计入完整身份映射，即使底层只存一份共享映射。求值中持有来源载荷及工作区预留；来源最后句柄释放后，已接纳的计算仍可完成。停止开始后不能发布新帧，在途读取可以完成，宿主在调用结束前保留插件 DLL。

单份来源或帧最多 64 MiB，单插件保留总量 128 MiB，服务保留总量 256 MiB。单次工作区上限 128 MiB，单插件同时预留上限 256 MiB，服务同时预留上限 512 MiB。预留覆盖候选帧及身份映射直到发布或失败释放。嵌套计算的部分瞬时分配未纳入，不能将这些额度视为进程峰值内存的精确上限。

独立审查还发现旧 `CreateChannels` 的失败清理顺序：候选数据原先在在途计数解除后才析构。本批改为在锁外先销毁候选，再解除在途保护。两条失败路径均以阻塞析构及另一线程查询租约验证；超时会使测试失败，避免测试本身死锁。

真实宿主逐模型、逐骨对照 BIND ID，按原生两阶段计算比较所有骨骼矩阵。仅修改目标模型注册动作后，新来源改变消费模型和传递模型结果，旧来源保持原结果。严格位于关键帧前的分数不会提前切换外亲。两个后台线程并发求值期间，播放头、编辑姿态、原生键、作者数据及共同历史保持不变。

PMM 保存、所有模型删除、槽位复用和工程重载后，已发布的旧帧仍返回原身份和矩阵。来源释放后帧也能独立读取；失效未来目标不发布来源。运行中的注册可见字节 `197` 由旧帧保留，标准 PMM 保存将非零值写成 `1`，重载后的新帧按此标准值读取。该验证使用真实应用代码和原创测试夹具，但不等同于所有第三方模型或插件的兼容性验收。
