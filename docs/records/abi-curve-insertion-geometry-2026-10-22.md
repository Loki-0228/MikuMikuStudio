# 原生插帧的输入几何与写入边界

本批修复同一会话中窗口尺寸变化后，原生保形插帧继续使用旧鼠标坐标的问题。输入视图包含画布与编辑器客户区、绘图区、滚动条、DPI、显示模式、数值范围及拖拽偏移。准备期间变化时，旧输入终止，仅安排异步重绘，不提交候选或清除 redo。

## 修复内容

读取画布尺寸后保存输入视图，在取消拖拽、聚焦、私有通道复制、每次采样、细分闭包复制、执行和最终释放后复核。提交前的来源预检也须保持该视图。已有关键帧路径在释放私有候选后复核，避免旧坐标继续影响选择或时间轴。

私有通道仍只复制一次；逐点命中调用该私有 sampler，不增加每像素闭包复制。细分回调只准备候选，正式写入仍走原 `apply`。

审查发现写入闭包复制也属于准备阶段。`InsertionWriteBoundary` 由本地及外部历史共用。私有 `apply` 副本复制完成、几何校验通过后，紧邻正文调用才标记写入开始。复制失败和释放收尾继续复核原会话与几何。正文开始后的尺寸变化不按几何回滚或重试，原会话及来源代次检查始终保留。

本批不改 VMD 编码、原生插值数学、文件标记或存储格式。

## 准备修正与限制

初始常量曲线右端点恰在数值滚动条边界，点击未选中关键帧，redo 准备失败。夹具改为选择左端关键帧，原公共准备函数未改。晚期复制夹具首次外部历史检查失败，因为未把已打开 HWND 交给复用 journal 的查询；补齐引用后再记录正式反例。失败日志保留。

受限桌面的首次启动 `geometry-red-full-01` 无输出并在 240 秒超时，不能当作功能反例。后续均继承 Default 桌面，未新建私有桌面。

旧的[堆链表现场](abi-curve-heap-observation-2026-10-21.md)及前批未解释超时仍未归因，本批通过不关闭这些调查。Win7 SP1 x64、CPU 和 AMD 基础要求保持，未完成对应真机及真实鼠标验收。main、正式 release 和用户工程未修改。
