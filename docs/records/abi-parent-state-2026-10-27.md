# 公开父级状态求值（2026-10-27）

本批基于 `codex/plugin-abi` 的 `3efc24c`，修复公开显示捕获将地面父级 `-2` 误判为过期目标的问题。在 `mms.scene.evaluate` 1.3 中追加明确的父级状态入口，保留 1.0、1.1、1.2 的表布局和函数语义。

## 状态与接口

`MmsEvaluationApiV1_3` 为 160 字节，前 152 字节保留 1.2 的全部字段，末尾增加 `sampleParentState`。输出 `MmsParentStateV1` 为 64 字节，包含父级类型、目标身份和连续窗口；定义见 [SDK 参考](../../sdk/mms/evaluation.md)。

| 原生选择 | 公开类型 | 含义 |
| --- | --- | --- |
| `-1` | `MMS_EVALUATION_PARENT_INHERIT` | 保留原父骨骼或全局外亲继承 |
| `-2` | `MMS_EVALUATION_PARENT_GROUND` | 地面；局部选择器跳过原父级或全局外亲继承 |
| 有效模型槽位 | `MMS_EVALUATION_PARENT_MODEL` | 使用捕获时冻结的目标对象与骨骼身份 |

继承和地面的目标身份均为空，但类型不同。全局选择器也保留原始类型，不能仅以空身份将两者合并。`kind` 是单值类型，不是位掩码；窗口沿用精确有理数时间的离散取整规则。

旧 `sampleParent` 不能表达地面，遇到地面返回 `MMS_E_UNSUPPORTED`，不修改调用方输出。其他状态按旧记录返回。捕获会检查全部可达键，包括未来键：继承和地面不查目标身份，非法负槽位、丢失模型或越界骨骼仍使整个捕获失败。

## 共用实现与寿命

宿主只提供新状态回调，旧入口由 `EvaluationStore` 转换。内部仍支持只提供旧回调的捕获器；转换前验证原 flags、reserved 和身份。两个回调同时存在时，新回调优先，失败不会回退到旧回调。

新旧入口共用来源、选择器索引、窗口校验、内存额度、互斥锁和在途调用计数。停止后拒绝新采样；已经接纳的采样可以完成，释放最后一个源句柄不会提前释放数据或插件 DLL。没有第二套状态缓存或租约。

该接口只采样注册状态，不求解 IK 或父级变换，也不发布世界空间骨架帧。原始兼容产品仍未开放生产求值工厂；其内部接口库参加本批回归。
