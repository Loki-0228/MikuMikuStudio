# 独立骨架尺度计算

## 本批实现

内部 `bone_scale::BuildTransformsPrivate` 用自有骨骼定义、完整 3×3 尺度和显式刚性矩阵计算最终尺度变换。它不读取宿主尺度注册表或骨骼当前 `matInit`，可以在独立工作区中调用。

新旧入口共用同一个父链计算循环。独立审查将新循环与 `c792dc1` 比较，确认逐字一致。原 `BuildTransforms` 的前缀也保持不变：先清空输出，按显式 baseline、已应用缓存、当前 `matInit` 的顺序选择输入。没有更改原有操作的尺度规则。

## 接口边界

```cpp
bone_scale::BuildTransformsPrivate(ownedModel, pose, rigid, corrected);
```

`rigid` 必须恰有 `boneCount` 个矩阵，非零骨数必须提供骨表，骨数不能超过 `INT_MAX`，否则抛出 `invalid_argument`。调用方负责验证并稳定骨骼引用、尺度和矩阵输入。函数只读取骨骼的父级和静止位置，不修改模型、尺度作者、缓存或历史。

计算先生成临时结果，成功后交换输出。参数错误或分配失败均保留原输出内容、地址和容量，`rigid` 与 `corrected` 可以是同一个容器。零骨骼和空 baseline 成功得到空输出。求值会分配内存，不能称为无分配接口。

非均匀缩放和剪切继续使用完整矩阵。子骨骼枢轴跟随父变形，继承尺度在未摆姿态的模型基底中作用，保留子骨骼旋转后的形状。原矩阵乘法方向、双精度累加、父链遍历及奇异逆矩阵的单位回退保持不变。旧算法对环和越界父级的终止行为也保留；这不替代冻结骨架定义的校验。

原计算可能产生非有限结果，最终帧发布层还须拒绝溢出。此内部入口没有新增公共 C ABI，不执行 IK、物理、蒙皮或场景依赖调度。原始兼容产品没有开放该入口。
