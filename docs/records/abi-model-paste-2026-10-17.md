# 表情与显示关键帧粘贴

命令 `421` 在受控共同历史绑定下新增两类单独粘贴：剪贴板只含表情键，或只含显示／IK／外亲键。多条源记录作为一次显式提交，两种历史记录模式均记录一次。普通未绑定运行保留旧路径，普通宿主仍未开放 `mms.edit`。

## 表情键

`PlanMorphKeyPaste` 在私有目标池中按名称及源顺序处理全部记录。同一目标和帧的后条记录覆盖前条，帧零覆盖头节点，追加时清除空闲槽残留链接。目标重名时按旧命令预检规则拒绝。

计划器一次保存三族选择标记、模型最大帧和游标。最终游标沿用旧普通粘贴重置到显示键池的规则，不修改最后登记帧。完全无名称匹配或只有标记、游标差异的同值重贴不生成记录，也不清空重做。

提交、撤销和重做只采样受影响的表情。当前权重不同于轨道求值时保留未登记权重，原作者曲线保持；采样只生成私有目标，不先改当前模型再回滚。候选保存代次，撤销与重做往返后，早先准备的候选仍失效。

## 显示、IK 与外亲键

`PlanDisplayKeyPaste` 复用现有显示键的深拷贝、私有增长和求值。历史保存每个键的可见性、IK 状态数组和外亲引用数组，撤销及重做不依赖这些剪贴板指针。首次粘贴即可更新当前显示状态，受外亲影响的干净骨骼重新求值，未登记的脏姿态保留。

IK 按固定 20 字节名称匹配，未匹配字段保留目标键原值；外亲槽零沿用旧首条映射规则。命令原有的全骨表重复名称拒绝保留，不改变显示登记和范围操作各自的规则。

缺失外亲模型只在私有副本中断开，不修改剪贴板。外亲骨索引等于骨骼数量时也修正为零，避免旧路径只检查大于数量而留下越界引用；负索引及未终止的外亲名称拒绝。记录保留前后轨道引用模型的身份和骨骼表边界，槽位被新模型复用后拒绝重放。

## 剩余边界

骨骼、表情与显示混合的普通粘贴仍整批拒绝。各族计划均持有模型最大帧、游标和其他族选择标记，不能直接组合，否则先发布的族会使后续候选过期。后续需要将本族数据与共享元数据分开，再由一个聚合事务统一准备、校验和发布。

相机、灯光、自阴影、重力及附件粘贴仍未迁移，具体接口和依赖见 [全局粘贴方案](abi-global-paste-plan-2026-10-17.md)。VMD 导入和视口拖动也仍待迁移。完整生产绑定保持关闭。

本批没有增加新版系统 API 或特定显卡依赖。Win7 SP1 x64、CPU 基础路径及 AMD 兼容要求保留；Win7 和 AMD 真机验收仍未完成，隐藏窗口测试不替代人工视觉验收。
