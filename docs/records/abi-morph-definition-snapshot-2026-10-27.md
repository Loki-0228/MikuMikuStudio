# 独立持有表情求值载荷

## 实现范围

内部 `MorphDefinitionSnapshot` 保存已加载的 PMD 顶点表情、PMX 0–8 类表情及模型级恢复基准。它补充已有的表情权重快照，为独立场景求值提供不依赖原模型寿命的数据。本批没有新增公共 C ABI，没有生成最终形变，也没有将新模块接入公开求值帧。

| 数据 | 保存内容 |
| --- | --- |
| 描述 | 模型格式模式、顶点、骨骼、材质数量、附加 UV 数量，原顺序的表情短名、类型、面板及有效载荷数量 |
| 顶点表情 | 最终模型顶点索引和三个偏移分量 |
| 骨骼表情 | 骨骼索引、平移与原始四元数，不在捕获时归一化 |
| 组表情 | 目标表情索引和权重，保留顺序、重复、自引用和环，不展开 |
| UV 表情 | 五族独立条目及四个原始分量 |
| 材质表情 | 材质索引、原始操作字节、全部通道和内部保留字段 |
| 恢复基准 | 模型级顶点基础表、PMX 五族 UV 基础表和材质基础通道 |

PMD 的类型字节通常为 0，但其载荷仍是顶点表情。加载器已经将非基础表情的索引映射到模型顶点，快照不重复映射。PMD 第 0 个表情的基础含义由格式和序号确定；PMX 第 0 个表情没有这项特殊含义。

当前原生组表情只展开一层。定义快照不改变这一行为，也不合并重复贡献。未来求值须保留原序；骨骼旋转和材质乘算不能简单合并权重后再应用。

快照不访问宽字符长名、实时权重、关键帧游标、变形后的顶点、材质累加池或设备资源。固定 20 字节双语短名按位保留。因此它是求值载荷快照，不是完整的模型编辑或无损格式承载。

## 校验与所有权

捕获须在 UI 安全点与编辑串行执行，调用方保证原生表的实际分配范围。只读取当前格式和类型启用的条目，正计数要求有效指针。顶层计数、活动计数和目标索引在发布前检查；材质索引 `-1` 保留全部材质语义。

活动浮点通道须有限。权重不限制到 `[0, 1]`，四元数不归一化，任意非零材质操作字节仍保留原生加算含义。基础 UV 的 Z/W、材质内部保留字段及操作填充字节按位保存，不施加活动通道校验。附加 UV 的四个分量均参与有限数检查。

默认保留额度为 64 MiB。先预检顶层最小容量，再汇总活动载荷需求，在访问或分配大型载荷前拒绝超限。最终额度按自有对象、嵌套容器和所有 vector 实际容量计算，不代表捕获期间峰值内存。异常销毁私有候选，不修改源。

读取接口不分配内存，支持源修改或销毁后的并发读取；非法序号不改变输出。

## 尚未支持

PMX 加载器目前没有实现翻转和冲量表情的载荷解析。新快照拒绝 PMX 类型 9、10 及其他未知类型，也拒绝非空不透明载荷指针，避免按未经证实的结构长度复制。完整支持仍需补齐加载、承载与求值语义。

完整独立场景求值还需装配骨架、动作、表情载荷、外部模型依赖和自有求值工作区，并执行层级、IK、形变及受支持的物理阶段。本批未改变原生 VMD、PMM 读写协议或已发布 ABI。

真实宿主使用原创 PMX 夹具，包含全部 0–8 类表情、四套附加 UV、重复和负权重组条目，以及全材质索引和原始非零操作字节。PMD 基础表重排后，文件局部索引 0 经真实加载器映射到顶点 3，冻结结果直接与加载后的原生数据核对。

宿主期望值直接读取原生表，不以快照自身生成答案。捕获前后比较完整模型记录、表情记录、嵌套载荷、恢复表、工作池、播放头及修改标志。修改顶点偏移生成第二份快照，再恢复原值保存 PMM；删除和重载模型后，两份快照仍分别保持原值和修改值。该 PMM 流程验证数据寿命，不代表新增格式或完整往返验收。

首次权重回归 `weights-full-01` 在受限环境中持续无输出，核对程序路径和父进程后终止，退出码 1，不计为通过。相同二进制在正常权限环境下的独立复验 `weights-full-02` 通过。构建保留既有 sidebar 中间目录及布尔比较警告，新增模块没有编译警告。
