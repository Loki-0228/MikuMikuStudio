# 动态精度恢复与可见接收面覆盖同步

日期：2026-10-24。工作区为 `D:/MMD-Next/MMS-abi-dev`，分支 `codex/plugin-abi`，起始提交为 `6880412`。本批同步 main 的三个已提交提交 `cd3fb78`、`1579f02`、`66bdaa2`，main 核对 HEAD 为 `66bdaa2`。未读取或覆盖 main 工作区文件；ABI 侧按自身设置与配置分层重新实现。

## 来源与行为

- `cd3fb78` 恢复独立动态精度开关。默认关闭时所有场景使用精度滑条选定的同一档贴图尺寸；开启后按视图内的相对深度在选定档位上下各一档内调整。需求由覆盖世界宽度、投影像素密度和相对深度推出；超过选定覆盖尺寸 2.5 倍升一档、低于 0.4 倍降一档，回到选定档位另有迟滞，每帧最多移动一档。正交视图需求不随距离变化。旧 `Data/adaptive_shadow.ini` 第一行重新保存开关。
- `1579f02` 恢复滑杆旁的原始「far／远处」标签，不再显示 `coarse`。
- `66bdaa2` 把远景覆盖层横向范围改为场景包围盒与相机视锥的交集，深度仍覆盖整个场景，画面外投影物继续落在可见接收面上。动态精度与近景细节层改用视图内的相对深度：最近可见接收面优先，贴在投影近平面时退回帧焦点深度。

## 实现

- [adaptive_shadow.hpp](../../include/mikumikustudio/adaptive_shadow.hpp) 采用 main 的动态精度纯函数：`DynamicShadowMapDemand`（反比深度需求）、`DynamicShadowQualitySize`（档位与迟滞）、`FittedShadowResolutionLimit` 的新补偿上限与 `ShadowQualityMapSize`。ABI 保留了已同步的近景细节层与精度尺寸接口。
- [native_shadow_projection.hpp](../../include/mikumikustudio/native_shadow_projection.hpp) 增加可见接收面覆盖所需的纯函数与拟合路径：`VisibleShadowReceivers`、带稳定接收范围的聚焦拟合、`VisibleShadowCoverage` 等；细节投影与相机深度区域接口保持。
- [adaptive_shadow.cpp](../../src/render/adaptive_shadow.cpp)：`UpdateAdaptiveShadowMap` 计算可见覆盖包围盒与视图相对深度，远景覆盖投影取二者交集，深度仍取整个场景；动态精度需求与细节层深度都用相对深度。ABI 差异：阴影偏好仍存 `data/settings.json` 的 `shadow` 段，`adaptive` 与 `filterEnhanced` 都在同一段内；旧 `Data/adaptive_shadow.ini` 只在中央段缺失时作为迁移来源（第一行动态开关、`filter_enhanced` 行滤波）。没有移植 main 的 `model_vertex_cache::ShadowBounds` 帧内包围盒缓存，包围盒数值不变，仍每次锁定顶点缓冲读取。
- [mmd_app.hpp](../../include/mikumikustudio/mmd_app.hpp)：恢复 `DynamicShadowQuality()` 状态，仅用于分配策略的迟滞。
- UI：`ui_init` 重建动态精度复选框，`ui_windowsize` 恢复与滤波复选框同排布局，`command_control_500` 恢复真实设置与保存，`wm_paint` 恢复「远处」标签，`ui_translation` 移除 `coarse`，`native_ui_catalog` 重新登记该控件。
- 测试：`native_shadow_tests` 采用 main 版本（动态精度与可见覆盖 CPU 检查、相机画面、细节网格、GPU 像素）；`display_compatibility_tests`／`sidebar_resize_tests` 适配 ABI 中央设置并保留原始兼容配置的跳过分支；`frame_benchmark` 恢复动态精度开关与距离缩放校验；`tests/README.md` 同步说明。
