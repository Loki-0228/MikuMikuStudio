# 分层 UI SDK 验证（2026-10-17）

本批基于 `codex/plugin-abi` 的 `817e0f2`，在 `D:/MMD-Next/MMS-abi-dev` 实现基础 C++17 UI 包装。依据统一扩展架构中的分层 SDK 要求，便利接口组合已有 C 函数表，复杂插件继续操作同一批底层注册。

## 需求与交付

| 需求 | 本批交付 |
| --- | --- |
| 一套 C ABI，不同层级的开发入口 | 新增头文件 `mms/cpp/ui.hpp`。`UiServices` 查询原服务，`RegistrationBundle` 管理注册，`CommandUi` 组合声明。未改变 C 表布局或宿主运行时。 |
| 简单插件便于注册 | 一个声明可以创建命令、可选菜单、按钮、工具栏分组及默认布局提示。启用、可见、选中状态直接使用同一命令回调；菜单按登记顺序排列。 |
| 复杂插件继续操作同一对象 | 返回原始 kind/handle，可通过原 C 表更新；`get` 借用，`detach` 显式移交所有权。包装不维护第二套状态或代次。 |
| 生命周期与失败处理 | 注册前预留记账容量；失败回收受阻时保留原句柄及清理错误。`Close` 处理包内重排后的父子依赖，未清完元素时保留命令及工厂。插件在 UI 线程显式关闭，宿主按原租约规则保留实例。 |
| 开发环境与接口说明 | [SDK 手册](../../sdk/mms/cpp-ui.md)给出工具链、声明字段、线程、错误、清理与能力边界；`hello_menu` 改为可独立构建的 SDK 示例。 |

只读属性和原生面板工厂通过基础注册包装使用。独立租约类、属性及面板的一键表单生成、命令溢出、更多挂载点、统一刷新、动画和多视口仍待实现，本批不将它们标为可用。

## 审查与修正

独立审查覆盖注册前分配、句柄记账、所有权移交、关闭失败保活、重排后的依赖及高低层互操作。服务表检查已修正为接受同 major 的兼容前缀与更高 minor，不因尾部扩展误拒绝；短表及错误 major 仍拒绝。

上下文寿命按宿主规则保留到 `destroy`，不能在 `Close` 成功后立即释放可能仍被租约引用的回调数据。析构只尝试清理，不承诺修复错误线程析构或调用者提前销毁上下文。
