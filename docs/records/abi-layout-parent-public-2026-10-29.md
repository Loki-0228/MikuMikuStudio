# 临时换组公共接口 1.2

本批将已验收的同区域父节点预览开放给插件，继续使用原 UiRegistry、NativeUi、刷新队列与布局历史。目标范围未改变，跨挂载区域、DOCK、其他插件／本体目标和临时视觉变换继续待办。

## 接口与兼容

`mms.ui.layout.session` 新增精确协商 1.2。128 字节扩展表保留原 88 字节前缀及九个回调，并追加能力、目标、声明、应用及声明查询五个 Ex 回调。前缀继续使用 1.1 行为；旧 1.0／1.1 表大小、记录及能力保持不变。新 Target／Value 分别为 32／48 字节，追加父元素 handle，使用 h 1.2 和数组 recordVersion 2，保留字段必须为零。

公共接口仅验证记录并转发到已有会话。旧状态查询、回退、提交和释放可操作同一个新会话；旧声明查询明确拒绝仍有 Parent 的记录。声明 Begin 不换组，Apply 才发布；部分接管后按实际剩余字段继续操作，父字段撤回不再返回旧父值。

C++17 在原 `LayoutSessionServices`／`LayoutSession` 上增加新记录重载和 Parent 便利函数，不创建第二套会话管理。协商、输出验证、显式修订、线程限制和停止清理保持；构造便利函数只创建 C 记录。

两配置隔离回归（本地证据，未随本文发布）共 **22 组全部通过**。每配置新公共 C 专项 142 项、新 SDK 204 项假宿主检查；旧公共 C 316 项、旧 SDK 239 项、内部预览 25,237 项、真实 NativeUi 858 项、INPUT 755 项、工作区 660 项、溢出 675 项、surface 265 项均通过。ABI 契约全集本次完整配置 45,145 项、原始兼容配置 45,133 项通过，按实际日志记录，不沿用旧批次计数。原始兼容产品不因此开放 ABI。

C/C++ 编译断言固定新旧记录大小、父字段偏移和全部旧表成员偏移；生产拒绝测试覆盖错误 header、数组版本、精确步长、保留字段、遗漏 Parent 和失败输出保持。测试也验证旧会话经 Ex 读取／应用、Parent 部分撤回后旧 apply 可继续、停止、错误线程、权限、循环及一次布局历史。SDK 测试涵盖缺失函数、协商错误、调用重入、显式修订、转移、Detach、析构和释放失败后的重试。

真实 DLL／宿主验证（本地证据，未随本文发布）的 ordinary／bound 两场景全部通过。隔离 manifest 必需服务声明为 1.2，实际经过 Manager 发现及协商；DLL 验证旧表尾部未覆盖、短缓冲和错误版本输出保持，以及 C 回退／提交／撤销重做与 SDK 同对象换组。宿主在九个阶段独立检查有效／持久父关系、原 HWND 和元素 handle 不变、窗口矩形确实移动并精确恢复、布局几何当前有效以及最终对象清理。原有四区域分隔线接管和历史边界检查继续执行。只有全部通过才输出新的 1.2 标记，不能用 DLL 自报步骤代替宿主断言。
