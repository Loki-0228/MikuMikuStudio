# 独立 CPU 网格求值（2026-10-27）

本批新增内部 `MeshEvaluationFrame`：从网格定义、表情结果和骨架帧计算私有顶点位置、法线及基础和附加 UV。它不访问活体模型或图形设备；结果独立持有，可在输入销毁后并发读取。它尚未作为插件 ABI 公开，也没有实现材质、轮廓、物理或 PMX 2.1/QDEF 求值。

调用者必须保证输入来自同一模型、捕获代次及精确采样时间。现有单独帧无法验证这些关系；后续须由同一安全点捕获的聚合来源绑定身份与 `EvaluationTime`，再向插件发布结果。相同骨骼数或相同浮点帧号不能证明输入匹配。

表情帧中的稀疏位置和 UV 是最终值，命中时替换绑定值。附加 UV 只输出已启用的组；其他组的表情索引仍验证。骨骼采用最终 `scaled` 矩阵，PMX 为每根骨骼使用私有上下文计算四元数；缺骨保留原 CPU 零矩阵与辅助值。BDEF1/2/4、SDEF 和 PMD 权重沿用原核函数及运算顺序，不重基 SDEF 偏移。保留和工作预算分别计算，均不是进程峰值限制。

有限输入若产生非有限中间结果会被拒绝；原 CPU 路径没有相同的检查，目前尚无实测证明合法模型触发这一差异。测试包含空网格，但未单独构造零骨骼帧。
