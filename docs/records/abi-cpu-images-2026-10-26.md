# CPU 图像租约实现与验收

## 本批实现

新增 `mms.render.image` 1.0 和 [开发说明](../../sdk/mms/render-image.md)。插件可发布不可变 RGBA8/BGRA8 CPU 像素，读取描述、retain 图像、获得独立映射及释放。源像素同步深拷贝，行尾填充不读取；输出紧密存储，设备代次为零。

宿主以插件实例校验句柄归属。图像和映射引用同一 payload，retain 不复制像素、不重复计费；最后一个引用消失才归还额度。限制为单图 64 MiB、每插件 128 MiB、服务总量 256 MiB、每插件 4,096 图像句柄及 1,024 映射；像素额度不包含输入和其他进程内存。

服务所有表调用使用同一锁，不执行插件回调。输入运算溢出、地址回绕、未知格式、越界跨度、配额及分配失败均在发布前拒绝。失败保持输出与已发布对象，句柄不复用。

Manager 在发布实例前绑定 client，避免重复查询服务时与后台读取发生 owner 写读竞争。停止时回收图像句柄，已有映射仍可读取和 `unmap`；新查询及创建操作拒绝。映射未释放时保留 DLL 与上下文。依赖保留而尚未进入 `StopOne` 的插件也先退役；失败创建且返回空实例的路径同样保活。插件仍须在 `stop` 中等待自己的工作线程退出。

现有 `mms.render` 设备租约语义保持不变。新服务没有 UI 写入、播放头、场景求值、工程数据或历史操作。
