# 运行、备份与故障恢复

## 启动与平台边界

完整包和最小包独立构建。DX12 和现代媒体按可用能力加载；不存在可选后端时保留对应基础路径。构建成功和 PE 导入表检查不能替代 Win7 SP1 x64、不同 CPU/GPU 及实际媒体编码器的真机验证，见[Win7 构建](win7-build.md)。

## 自动备份

备份设置位于程序旁 `data/autosave.ini`。默认备份、崩溃恢复和错误报告写入 `backups/`，自定义位置按设置解析，见[本地数据](../reference/local-data-storage.md)。定时保存与崩溃备份是独立能力。

容量扫描先构造完整结果，再更新提示状态；扫描或分配失败不清掉此前状态。提示构造或窗口创建失败时保留重试机会。命名、增量保存及 `.pmm1` 行为见[文件操作](../guides/files.md#自定义备份与增量命名)。

## 故障报告

致命错误、未捕获异常和终止路径尽力写报告并尝试恢复。日志槽使用非等待的占用标志，竞争时允许跳过记录，避免故障线程持有槽位导致报告线程永久等待。

磁盘不可写、空间不足或进程状态损坏时，报告和备份可能失败。成功生成备份仍需重新打开核对，不能保证完整恢复全部未保存状态。

## 编辑与保存一致性

曲线类型、预设和数值变化通过同一提交规则维护历史；没有实际变化不增加撤销。关键帧精确位置返回作者值，不能将近似插值反写成原值。打开工程或动作时保留载入结果，消耗关闭文件对话框遗留的登记按键。

保存与重开检查需要覆盖工程状态及整数、小数帧求值。单个场景通过不能证明所有第三方工程无损往返。

## 验证入口

日志、自动备份、原生状态、媒体、MME、曲线和真实场景各有独立测试入口，见[测试说明](../../tests/README.md)。区分合成夹具、隐藏窗口及实际系统测试；记录真实程序身份、加载路径和失败日志，不累积过往通过次数作为当前质量保证。
