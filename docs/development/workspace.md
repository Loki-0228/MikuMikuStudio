# 工作区布局

仓库根目录是源码、构建命令和下列相对路径的基准。

| 目录 | 用途 |
| --- | --- |
| `src/`、`include/` | 程序实现与接口 |
| `tests/` | 回归测试、运行器和测试用途说明 |
| `scripts/`、`tools/` | 资源生成、转换、诊断和维护工具 |
| `docs/` | 使用指南、格式参考、开发资料和专题记录 |
| `build/` | 本地构建目录；是否启用测试取决于配置 |
| `build/Release/` | 正式程序的本地产物目录 |
| `build/cmake/`、`build/conan/`、`build/release/` | ABI 开发目录的构建树、Conan 依赖和发布目录，见[Win7 x64 基础构建](win7-build.md) |
| `.local/builds/`、`.local/worktrees/` | 独立构建和隔离工作树 |
| `.local/artifacts/` | 本地测试、截图、测量与清单 |
| `.local/releases/`、`.local/archives/` | 本地发布快照和保留的历史文件 |

`.local` 内容不保证存在于其他机器，也不随源仓库自动提供。文档中的原始证据路径标识采样时的位置，不代表当前文件仍在该路径。

当前正式程序的身份应从实际文件哈希、构建日志和对应源码确认，不能使用某篇历史文档中的「当前 EXE」描述。旧工作区状态和清理结果见[工作区记录](../records/development/workspace.md)。

清理时先核对构建配置、测试运行器、文档引用和活跃进程。源码、测试素材与正式产物按用途判断，不以日期或是否被 Git 忽略作为删除依据。
