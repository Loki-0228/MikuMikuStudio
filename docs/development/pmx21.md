# PMX 2.1 原生支持

完整档 `full` 可读取 PMX 2.0 和 2.1，支持 UTF-16LE、UTF-8 和 1／2／4 字节索引。`mmd932` 兼容档继续使用原版的 PMX 2.0、UTF-16 导入限制。模型记录、关节记录和插件 ABI 布局未扩充；软体定义及运行状态由模型地址关联的内部表管理。

## 实现范围

- QDEF：CPU 和 DX12 均支持四骨骼双四元数混合，统一四元数半球并归一化；兼容宿主的骨骼缩放、法线变换。几何准备缓存、骨骼影响筛选和烘焙变形比较读取完整的四组权重。
- Flip morph（9）：按权重区间选择一个目标并覆盖本次求值的目标权重；支持 group 驱动，不改写滑块或关键帧。
- 冲量 morph（10）：在 Bullet 实际子步前应用局部／世界冲量和角冲量，普通画面求值不会重复施加。
- 关节：保留弹簧 6DOF（0），加入 6DOF（1）、点对点（2）、锥扭（3）、滑块（4）、铰链（5）。新增类型使用 PE 的限位、弹簧字段复用及电机参数约定。
- 软体：三角网格／绳索、配置参数、刚体锚点、近接锚点、固定顶点、弯曲约束及簇。完整档使用 Bullet 软刚体世界，将模拟位置和法线写入原生顶点缓冲。
- 材质：扩展 UV1 的 RGBA 顶点颜色、点绘制及线绘制。点／线采用 PE 默认的 F3 面索引解释，分别通过点填充和线框填充提交；不生成反壳描边。普通材质与透明剥离着色器共享颜色计算。

## 生命周期与边界

事务式导入期间只保留软体定义，在模型进入最终场景后创建 Bullet 对象。再次导入其他模型时，场景宽相位检查允许已有软体。删除模型、替换刚体及释放模型会清理软体锚点；撤销恢复时从当前骨骼姿态重新建立软体，不保存过去每个软体节点的模拟轨迹。跳帧重置也从当前姿态重新开始。

离线物理烘焙使用独立软体定义、顶点数组、刚体和关节，避免改动编辑器中的物理状态。骨骼关键帧不能表达软体节点的独立运动；保留这类表面运动需要网格缓存导出。

此实现面向原生导入、求值、物理与渲染，不扩充外部插件的能力声明，也不保证自定义 MME 着色器采用新增材质标志。独立 `MeshDefinitionSnapshot`／`MorphDefinitionSnapshot` 求值接口原有的不支持类型检查仍然有效。

含 QDEF 或软体的模型不再触发整模 CPU 蒙皮回退。模拟节点覆盖对应顶点，其他顶点继续使用 GPU 蒙皮；没有面法线的绳索保留骨骼法线变换。软体模型逐帧刷新顶点输入，以免静态缓存漏掉节点更新。

## 现代系统构建与 GPU 软体

`modern-x64` 预设面向 Windows 10/11 x64，关闭 `MIKUMIKUSTUDIO_WIN7_BASELINE` 并启用 DX12。先按 [Bullet 软体依赖说明](../../recipes/bullet275-softbody/README.md) 构建修复版，使用 `profiles/modern-x64.lock` 安装到 `build/conan-modern`，然后执行 `cmake --preset modern-x64` 和 `cmake --build --preset modern-x64-release`；产物在 `build/modern/Release`。原有 Win7 预设与依赖锁保留，其 baseline 会强制关闭 DX12。

“帮助 → 运算器”分别提供主渲染设备、顶点计算设备、软体计算设备。后两项通过 DXGI 枚举 D3D12 硬件，独立于主画面的 D3D9 适配器列表；修改保存到安装目录的 `data/settings.json`，下次启动生效。旧配置键 `cloth` 保留兼容。

软体 DX12 路径覆盖连接约束的速度／位置／漂移迭代、固定点、刚体锚点、刚体接触、软体间顶点／面接触以及簇节点冲量分配和阻尼。链接按无冲突批次并行；共享节点、动态刚体或簇的接触保持顺序，独立分组并行。跨软体接触写回双方节点；簇接触在世界级阶段统一提交，包含刚体反作用力。

碰撞检测、预测、簇姿态与惯性准备、接触生命周期和法线更新仍在 Bullet CPU 执行。每个软体子步一次 GPU 提交与读回；有 GPU 簇迭代时增加一次世界级提交。自动模式跳过少于 512 节点的小型软体，并计入打包、上传、计算及读回耗时，与 CPU 实测比较；少于 128 个簇约束时簇迭代保留 CPU，菜单明确显示混合状态。显式选择 GPU 可跳过这些性能门槛。

四面体体积软体保留 CPU 求解，带自定义角约束的簇迭代也保留 CPU；无效输入、设备失败时安全回退。此限制不影响其余模型的 GPU 蒙皮。并行链接批次改变约束处理顺序，长时间轨迹不保证与串行 Bullet 逐位相同。

先行交付的 `build/release-modern` 保留基础 GPU 软体版（簇与软体间接触回退 CPU、旧菜单名称）；扩展版位于 `build/release-modern-softbody`，不覆盖先行交付目录。

本机 RTX 4070 Laptop GPU 的合成网格 ABBA 测试（16,384 节点、48,641 链接、16 次迭代，4 组各 32 步）在基础版测得整步平均 CPU 9.8468 ms、GPU 6.9397 ms；扩展版复测为 CPU 8.2451 ms、GPU 6.5576 ms。两次仅可各自比较组内结果，不用于比较版本间性能；这不是用户实际模型或完整渲染帧率的测量。

## 验证

软体拓扑使用哈希去重结构边、稀疏邻接表按指定图距离生成弯曲约束，避免逐边线性查重和节点数平方的临时矩阵。保留 Bullet 原有端点方向、插入顺序及弯曲标志；测试覆盖重复／退化面、断开网格、环和一般图，并逐项比较多个距离下的原始 Bullet 结果。现代物理库另修复 x64 距离场缓存键的未初始化填充，不改变碰撞算法。

`pmx21_tests --topology-only` 单独运行拓扑对照。`pmx21_tests --model <PMX绝对路径> [--gpu|--auto]` 提供隐藏窗口的只读加载与三步物理诊断，报告实际缓存条目和唯一键数量，并检查节点有限性；默认选择 CPU。它不包含完整界面的渲染、骨骼更新或播放追帧，不能作为实际界面 FPS。

2026-11-15 本机实际模型验证（183,698 顶点、7 个软体、19,825 个软体节点、820 刚体、1,120 关节）：初始化从约 600 ms 降到 31–33 ms，链接数量不变。旧库在第三步出现约 93,835 个 SDF 条目、仅 11,710 个唯一键；修复后两者均为 11,710。相同 CPU 求解路径下，接触数量保持 16,573／16,294／14,113，后两步整步物理约 50–57 ms，旧库约 777–788 ms。显式 GPU 后两步约 180–206 ms，此模型建议自动模式。

完整 `frame_benchmark` 使用同一模型、默认自动策略、1080×608、每次一个预热帧和三个采样帧；按旧／新／新／旧运行，平均帧耗时依次为 5120.9632／342.6442／335.3901／6696.6198 ms。组内均值旧版 5908.7915 ms、新版 339.0172 ms；这是短程加载后对照，旧缓存随帧数增长，不能推导长期稳定 FPS，也不代表已经流畅。日志位于本地 `build/validation/soft-load-abba-*.log`，未把用户模型纳入仓库。

修复版发布目录为 `build/release-modern-softbody-loadfix`，主程序 SHA-256 为 `DFB100A08D661F935094FBA7E4AE24A248D527DEB3952AA649E7992A37261615`。现代构建的 PMX 2.1、GPU 软体、物理姿态、关节、缩放及烘焙六组 CTest 全部通过。

启用 `MIKUMIKUSTUDIO_BUILD_EFFECT_TESTS` 后，完整档提供 `pmx21_tests`。该测试使用自有隐藏 D3D9 窗口和程序生成的 PMX：两种编码、三种索引宽度、QDEF 旋转／平移／缩放、Flip、冲量、六种关节、软体重力／固定点／重置、绳索与锚点、二次导入、删除／恢复、离线烘焙和截断文件清理。材质测试编译实际 SM2 资源并读取 GPU 像素，检查 UV1 RGBA 和普通单 UV 顶点布局。

相邻回归包括 `pmx_text_regressions`、`pmx_joint_tests`、`pmx_vertex_parallel_regressions`、`model_geometry_cache_regressions`、`mesh_bake_bone_selection_regressions`、`physics_pose_tests`、`physics_scale_tests` 和 `physics_bake_tests`。兼容档的关节测试使用 `--indices-only`；其原版导入通知会额外弹出，不能套用完整档的单一中文警告数量断言。

程序生成夹具不等于任意第三方大型模型、全部碰撞配置或外部插件的视觉验收。

现代档增加 `cloth_compute_tests`，核对 GPU 固定点、静态／动态锚点、刚体接触、速度／漂移求解、软体间接触对双方的更新、簇冲量／反作用力／节点分配／阻尼，以及自动选择不重复推进、设备失败和恢复；`--benchmark` 运行基础网格 ABBA 测试。`pmx21_tests` 同时检查软体帧更新与绳索法线仍使用 GPU 蒙皮，`skinning_backend_tests` 的 144 组硬件对照包含 QDEF。

连续世界步进夹具由 Bullet 生成接触：簇碰撞 100 步中记录 70 个接触约束、35 次 GPU 簇求解；双软体 40 步中记录 3,902 个接触，双方共 80 次 GPU 求解。检查结果有限且不中断 GPU 路径；不等同于第三方模型的长期视觉验收。
