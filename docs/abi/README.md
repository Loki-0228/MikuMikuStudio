# ABI 功能总览

人工阅读或修改目标请先看[开发与验收目标](goal.md)，按里程碑、功能、优先级和验收条件分段维护。

执行前先查[需求执行顺序与优先级](execution-priorities.md)，按需求ID对照功能、实现入口和验收证据。

按功能查找接口、实现边界、未完成项和验收证据。功能页是日常维护入口，日期仅用于追溯。保留 13 个父目标和 44 项要求，近期独立达到日常可替代 main。负帧登记、保存及跨零粘贴保留为较低优先级扩展，每个阶段结束后重新评估全局优先级。

想知道当前版本离试用还差哪几步，先看[候选版验收表](candidate-acceptance.md)。

[剩余需求与目标清单](remaining.md)将 13 个父目标细化为 44 个可跟踪子项，包含未实现服务、生产未开放能力及待验收要求。

近期按[日常可替代 main](main-parity.md#近期里程碑日常可替代-main)推进完整操作验收，已开放功能的已知错误必须修复。全部ABI需求继续保留；独立功能并行，负帧每阶段收口后重新排序。

## 阅读方式

先看功能页的「当前推进范围」，再查「相关专题」中的具体问题。「实现与验收依据」保留历史上下文，旧记录的通过结果不自动代表当前分支通过。共 310 份既有 ABI 专题按主要功能归类，跨功能的综合审计与同步记录集中在宿主页。

## 维护方式

新结果更新所属功能页的当前范围与验收证据，不在总览顶部追加日期流水。跨功能问题在主要所属页完整说明，其他页链接引用。既有日期命名文件保留作原始证据，功能索引按专题名称组织；后续内容优先归并到功能页。
