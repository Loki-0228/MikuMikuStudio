# ABI 开发与验收目标

本页是供人工阅读和修改的目标正文。按功能和里程碑组织，具体完成状态及证据仍由原清单维护。

## 1. 工作范围与当前状态

- 工作区：`{ABI_REPO}`。
- 保留现有 **13 个父目标、44 项需求**，以及文档和 main 对照中新确认的遗漏。
- 候选试用进度以[候选版验收表](candidate-acceptance.md)为准。
- 保留所有已验收的阶段成果、未验收项、真实失败和外部阻塞。整理文字不改变完成状态。

## 2. 近期里程碑：日常可替代 main

先形成一对可复测的 main／ABI 版本，完成隔离候选的「打开 → 编辑 → 保存 → 重开 → 导出」。以验收表的操作结果、风险及证据判断试用范围。数据一致性是日常替代的放行条件，完整 ABI 范围另有终点。

以下功能分别形成可独立验收的完整操作。不要求先完成所有 ABI 扩展，再交付日常可用版本。

- **工程加载与恢复**：正常打开、错误提示、取消与失败恢复；选择一个模型或效果位置后，根据共同目录层级寻找其余资源，减少重复选择。
- **日常编辑**：时间轴选择、拖动、复制粘贴、登记、撤销重做；曲线控制柄与关键帧拖动、表情贝塞尔恢复、局部重绘、选中关键帧适配。
- **界面**：保持 main 对应子界面的布局，采用 ABI 新绘制方案；修复选择控件高度、间距、输入与窗口生命周期问题。
- **缓存与读入**：冷热加载、工程归属、预算和保留策略、可见清理、失败恢复及并发安全。
- **保存与备份**：手动保存、另存、后台保存、自动备份、增量命名、旧版本保留链，以及工程与效果的实际重开。
- **渲染与性能**：原生及 MME 阴影、抗锯齿、透明排序的开启和关闭；在相同场景、帧和设置下核对画面与实际性能。
- **导出**：视频、压缩编码与图片序列；覆盖确认、取消、失败后重试、导出后关闭和未保存提醒。
- **格式与对象身份**：路径和名称兼容、同名轨道对应、模型选择及绘制顺序；保留无法由旧格式表达的数据及明确提示。

参考程序为 `{MAIN_RELEASE_EXE}`。视觉对照要求两侧使用一致的 PMM 文件，当前已有夹具为 `Review.pmm`；源码版本、工作树和实际二进制来源分别核实，不假定三者一致。

## 3. 全量里程碑：剩余 ABI 能力

近期里程碑通过后，以下范围继续保留在总目标中：

- 生产编辑接口、共同历史、动画轨道及动作生成。
- 视频来源、帧租约、统一预算和取消。
- UI 公共服务、原生控件语义、第二宿主及实时交互。
- 独立求值、计算、物理、绑定和烘焙。
- 完整渲染服务、有序后期、多视口和设备呈现。
- 格式提供者、公共数据服务及未知数据保留。
- 旧 MME 剩余兼容验收、缓存并发安全。
- Win7、AMD、CPU 路径、真实设备及长时间运行验收。

已验收的旧 MMD 窗口观察插件子目标复用原证据。没有变化或新失败时不重复执行。

## 4. 优先级与阶段终点

1. **P0：已开放功能缺陷。** 优先处理崩溃、数据损坏、错误编辑、保存恢复失败、交互和渲染错误、明显性能退步。
2. **P1：日常 main 等价可用。** 完成独立操作闭环、近期插件需求及必要的可见和平台验收。
3. **P2：其余 ABI 扩展。** 按真实依赖推进；仅提升 P0/P1 必需的最小前置步骤。

- 负帧登记、版本化保存、跨零粘贴和拖动完整保留，新增能力降低优先级，既有功能错误不降低标准。
- 每轮只选一个边界明确、可验收的步骤；写明成功分支、失败分支和停止条件。
- 完成阶段后回到全局队列，重新比较优先级，不自动沿同一模块扩展。
- 外部阻塞只挂起受影响步骤，继续其他就绪任务。未归因的历史异常保留原证据，不能用后续通过覆盖。

## 5. 验收与进度汇报

- 以完整用户操作验收，例如“保存失败后保留原工程，再次另存并重开成功”。
- 记录需求 ID、复现步骤、源码和产物版本、配置、真实退出结果、证据路径及适用范围。
- 隔离测试不能替代必需的用户可见结果或真实设备证据。未实现、未验收、缺设备和待决策分别记录。
- 性能结论使用公平的实际对照，注明预热、负载、样本和限制。
- 复用仍然有效的验收，不以检查数量代替进度。汇报完成操作、仍失败操作、阻塞和下一步。
- 每轮以候选版为单位，只汇报已通过的用户操作、仍挡住试用的问题、下一项要关闭的验收。外部阻塞写明解除条件。
- 新问题关联固定版本、配置、复现及证据。修改后复验受影响操作及必要相邻路径，未受影响的结论复用原证据。
- 近期里程碑通过单独汇报；只有全部已授权需求实现并通过验收，才完成总目标。
