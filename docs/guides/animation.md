# 动画编辑

先选择要处理的轨道，再进入对应编辑器。骨骼缩放、自由曲线和部分烘焙功能只在完整包中提供；最小包保留原生插值方式。

| 任务 | 操作说明 |
| --- | --- |
| 编辑骨骼、表情、附件或场景曲线 | [关键帧与曲线编辑](animation-curves.md) |
| 整体或沿 XYZ 缩放骨骼 | [骨骼缩放](bone-scaling.md) |
| 按目标帧率调整整个工程 | [帧率修正](frame-rate.md) |
| 在指定范围内按随机间隔和速度插入表情片段 | [选中帧序列散布](sequence-scatter.md) |
| 将物理运动记录为关键帧 | [物理烧录](physics-baking.md) |
| 缓存最终几何或导出 ABC | [网格导出与烘焙](mesh-export.md) |

保存工程前，确认目标程序是否支持所用扩展。兼容副本和自动扩容规则见[文件与兼容性](files.md)。

## 编辑负数帧与选择范围

在 0 帧按左方向键进入 -1，或在当前帧输入框输入负数。切换帧会重新求值，未登记的骨骼与表情编辑随之复位。负帧支持登记、选择、删除和普通复制粘贴，并随 PMM 保存。负帧尚未接入原生曲线编辑和反转粘贴。

播放与范围选择的两端按以下规则解释：

- 左端不大于右端时，按输入的帧号处理。例如 `-10..-1` 选择这十个负帧。
- 左端大于右端时，右端的绝对值表示倒数第几帧，1 是最后登记帧，0 也按最后登记帧处理。例如最后登记帧为 600，`0..-1` 选择 0 到 600，`100..-5` 和 `100..5` 都选择 100 到 596。

播放排除负帧，从负帧位置开始播放时起点不小于 0。`0..0` 只播放或选择 0 帧。

操作差异和回归范围见[编辑控件与曲线记录](../records/animation/editing.md)、[物理状态记录](../records/animation/physics.md)和[烘焙验收记录](../records/animation/baking.md)。
