# 物理烧录与高级物理设置

「烘焙」菜单提供两个独立窗口：

- **烧录关键帧…**（English: **Bake keyframes…**；日本語：**キー焼き込み…**）按设置的步长重采样所选轨道。模型页默认选择当前模型的骨骼；相机、灯光、附件页默认选择相机。可用「通道…」调整目标。此窗口不写入模拟得到的物理骨骼结果，也不会添加物理烧录的边界键。
- **烧录物理…**（English: **Bake physics…**；日本語：**物理焼き込み…**）把模拟得到的物理骨骼运动写成关键帧。模型页写入当前模型；相机、灯光、附件页写入场景内所有符合条件的模型。「同时重采样」选项可以在本次操作中一并处理模型的普通骨骼关键帧或所选场景通道，默认关闭。

停止播放或录制后再打开窗口。两者均使用原生烧录路径；加载 MMV 不会自动触发删除 FX。同一菜单下的[网格烘焙](mesh-export.md)保存最终顶点并可导出 ABC，使用独立的网格缓存，不覆盖骨骼关键帧。

## 使用方法

1. 输入起止帧及步长（默认 1）。「末帧」填写场景时间轴的最后一帧，不开始计算。范围包含两端，允许单帧；帧号为程序支持范围内的非负整数。
2. 使用「通道…」调整目标。在模型页，「骨骼范围…」可限制为当前选择的骨骼；如果已在通道窗口逐根指定骨骼，则以通道中的选择为准。
3. 进行物理烧录时，选择「Bullet 默认」，或打开「高级设置…」修改参数、读取预设；「视窗滚动预览」仅影响显示，不改变烧录结果。
4. 点击「开始烧录」。目标骨骼范围已有关键帧时，确认覆盖提示。骨骼采样期间显示进度，可以取消。
5. 完成后用常规 PMM 保存或 VMD 导出流程保存结果。物理烧录的撤销与重做包含骨骼关键帧、物理禁用标记和模型末帧。

物理计算在独立世界中从第 0 帧开始；起始帧之前的动画参与预计算。场景中全部模型的刚体参与碰撞，结果只写入当前模型的目标骨骼。取消或计算失败时不写入部分结果，也不改变编辑器中的骨骼、关键帧或实时物理世界。参数仅用于本次烧录。

物理烧录写入的关键帧带有原生「禁用物理」标记，回放时使用记录的骨骼运动。为使物理状态在范围两侧恢复，程序会在起始帧前一帧（存在时）和结束帧后一帧补充边界关键帧；已有边界关键帧保留。边界帧可能使模型末帧增加 1。其他已有范围外关键帧的姿态不覆盖，但边界附近的插值和状态切换会随新增关键帧变化。

「烧录关键帧」按步长重采样所选轨道，不做 IK 展平或关键帧精简。未选中的 IK 和表情轨道保留；单独烧录普通骨骼关键帧时，原有物理开关随采样保留。选择同时烧录物理与普通骨骼时，物理骨骼使用模拟结果。关键帧池按需要扩容；无法扩展或超出索引范围时拒绝写入。

原生骨骼缩放参与逐子步物理求值，所有绑定骨骼的刚体形状、偏移和 joint 连接点随之缩放。物理烧录保存求解后的缩放，普通重采样保存原曲线缩放，两者都参与撤销与重做。缩放通过 PMM 扩展和同一个 VMD 的尾部扩展保存；原版 MMD 只读取位置、旋转等标准动作，不显示缩放。具体约束见[原生骨骼缩放](bone-scaling.md#刚体与-joint)。

## 实时与烘焙参数

「物理 → 实时物理设置…」与「烧录物理 → 高级设置…」使用相同的滑块、输入校验和求解参数换算。两处设置仍各自生效：实时设置用于当前会话，烘焙设置用于本次烧录。模型编辑器里的刚体、关节属性不在此窗口修改。

| 参数 | 默认值 | 滑块范围 | 精确输入范围与作用 |
| --- | --- | --- | --- |
| 物理帧率（Hz） | 60 | 15–480 | 正整数；每秒实际物理步数，不改变播放速度、时间轴或视频帧率 |
| 误差修正（ERP） | 0.2 | 0–0.8 | 有限数 0–1；控制接触和关节的位置误差修正，1 容易引起抖动 |
| 关节柔化（CFM） | 0 | 0，以及对数分布的 0.000001–0.1 | 非负有限数；允许关节误差，数值很大时约束接近释放 |
| 每步求解迭代 | 10 | 1–100 | 正整数；在同一时间点反复求解，提高收敛精度，不增加物理步数 |

滑块端点是交互与计算成本上的选择，不是引擎保证稳定的边界。输入框可输入高于滑块上限的合法值；滑块显示在端点不会截断输入值。整数按有符号 32 位保存，CFM 按单精度有限数保存；不能表示的数值、NaN 和无穷大均拒绝。很低的帧率会漏过快速碰撞，很高的帧率或迭代次数会显著增加耗时；合法参数也不能保证任意模型都稳定。

原有「子步数」「内部倍率」「基准频率」实际上都乘入同一个物理步频，现合并为「物理帧率」。求解迭代是单独的精度参数。旧预设仍按 `基准频率 × 倍率 × 子步数` 读取；新界面保存时将两个因子置 1。物理帧率不再通过界面绑定播放帧率，修改播放速度不会暗中改变求解设置。

CFM 与 ERP 分别表示允许的约束误差和修正速度，并非同一个刚度旋钮；两者共同决定约束响应。Bullet 2.75 的接触行固定 CFM 为 0，因此此处 CFM 只柔化关节。项目在关节求解行中把 `CFM / 时间步` 加入有效质量对角项，并同步归一化 RHS、CFM，避免直接使用大 CFM 造成迭代发散。CFM 为 0 时保留原求解器路径。

### 自动时间步补偿

不增加简单/高级模式开关。只修改物理帧率时，计算层自动换算 ERP/CFM 与软体逐步阻尼，其余输入值无需跟着调整。新设置以 60 Hz 为参考：ERP 0.2、CFM 0、每步 10 次迭代。ERP 和 CFM 的标签注明参数基准频率，下方显示换算后的实际求解值。

CFM 为 0 时按 `ERP(h) = 1 − (1 − ERP参考)^(参考Hz / 实际Hz)` 换算位置误差修正。CFM 大于 0 时用官方弹簧/阻尼关系同时换算 ERP 与 CFM，保持相同的等效刚度、阻尼系数。求解迭代次数只控制收敛精度，不改变时间步。

软体阻尼 `kDP` 来自 PMX 模型，本窗口不增加这个输入项；按 `kDP(h) = 1 − (1 − kDP模型)^(60 / 实际Hz)` 在每一步临时换算，求解后恢复原值，不改写 PMX。刚体阻尼在 Bullet 中本来就按秒计算，因此不做重复补偿。

这使误差衰减和软体阻尼有一致的时间尺度，**不是不同帧率的轨迹或所有材质刚度完全相同的保证**。软体链接刚度、碰撞接触、约束收敛与高速运动仍受时间步影响；需要严格复现时保持相同物理帧率和模型设置。离线模拟使用独立世界并从第 0 帧开始，不承诺与编辑器实时播放或原版 MMD 逐位一致。重力噪声按时间索引，重复烧录可复现。

### 官方依据

- [Bullet ERP/CFM 说明与弹簧阻尼换算](https://github.com/bulletphysics/bullet3/blob/master/examples/Utils/b3ERPCFMHelper.hpp)：ERP 的定义域为 0–1，建议常用 0.1–0.8；CFM 非负。`ERP = h·k / (h·k + d)`、`CFM = 1 / (h·k + d)`。范围说明与公式来自官方；上述滑块范围和 60 Hz 参考是本项目的选择。
- [Bullet 刚体阻尼实现](https://github.com/bulletphysics/bullet3/blob/master/src/BulletDynamics/Dynamics/btRigidBody.cpp)使用时间步指数；项目实际依赖的 Bullet 2.75 源码也采用此形式。
- [Bullet 软体求解实现](https://github.com/bulletphysics/bullet3/blob/master/src/BulletSoftBody/btSoftBody.cpp)在位置求解后的速度更新中应用 `1 − kDP`。实现依据另核对了项目依赖的 Bullet 2.75 源码；不能把新版 PyBullet 的默认 240 Hz 当成本项目默认值。

## 纯文本预设

在高级设置中使用「保存预设… / Save preset…」和「读取预设… / Load preset…」。文件为不加密的 UTF-8 JSON，可用文本编辑器查看、修改与共享。文件名和预设名称支持 Unicode，界面语言不影响格式。

下面记录初始设置；它没有采用截图中的示例值。

```json
{
  "format": "MikuMikuStudioPhysicsPreset",
  "schemaVersion": 2,
  "name": "Bullet defaults",
  "erp": 0.2,
  "cfm": 0,
  "substeps": 1,
  "simulationRateMultiplier": 1,
  "baseSimulationRateHz": 60,
  "solverIterations": 10,
  "parameterReferenceRateHz": 60
}
```

保存格式版本为 2，全部十个字段必填；版本 1 的八字段旧预设仍可读取，采用每步 10 次迭代，并将原来的实际步频记录为 ERP/CFM 的基准频率：保持原步频时，求解参数仍与旧预设相同；改变步频后再自动换算。软体阻尼始终使用 60 Hz 基准补偿。拒绝未知或重复字段、错误类型、缺失字段、非法 UTF-8、截断 JSON、NaN/Infinity、溢出与超范围数值。允许 UTF-8 BOM、合法 JSON 转义和科学计数法。整数参数必须具有整数值。名称最多 128 个 Unicode 字符，不允许控制字符；文件最大 64 KiB。

`format` 必须为 `MikuMikuStudioPhysicsPreset`；旧 `MikuDanceStudioPhysicsPreset` 不作为读取别名。读取失败时保留当前参数。

读取先完整校验，再替换当前参数；失败保留当前设置并按界面语言提示原因。保存先写同目录临时文件，再替换目标；失败保留原有预设。高级设置中的取消不会应用未确认的参数，已明确另存的预设文件保留。

预设独立保存，不写入 PMM 扩展。PMM 与 VMD 保存的是烧录生成的原生骨骼关键帧和物理状态标记，不要求额外的预设文件才能回放。

## 视频和图片序列导出的物理预计算

两个导出窗口的「从指定帧开始计算物理」均支持负数帧。输入框默认取工程中最早的有效注册帧；没有负帧关键帧时为 0。启用后，若手填的起点晚于已注册的负帧，会自动前移到最早注册帧；手填更早的起点则保留，用于额外预热。物理起点不得晚于输出起始帧。

预计算按物理步频采样骨骼、表情和重力，跨过第 0 帧后继续正常计算；未注册负帧关键帧的轨道保持第 0 帧状态。预计算区间不生成视频帧或序列图片，也不改变输出编号、帧数和时间戳。取消预计算可终止导出。未勾选时仍从输出起点开始计算。

## 通道选择、稀疏采样与容量

通过「通道…」选择要记录的轨道和子参数。场景范围的物理烧录在启用「同时重采样场景通道」后才可选择场景轨道。

- 相机/灯光/附件主页：选择相机、灯光、自阴影、重力和每个 `.x` 的原生通道及子参数，不要求 MMV。
- 模型页：只列当前模型，可逐骨骼、表情、显示/IK 选择。在物理窗口中，骨骼选择同样有效；其他模型参与碰撞，结果不写入其他模型。
- 起止帧与步长控制采样；总会包含结束帧。骨骼稀疏烘焙替换区间内旧键，物理键携带原生禁用物理标记，边界恢复原状态。MMV FX 网格物理使用「烘焙网格…」及实例启停键，见 [网格说明](mesh-export.md)。
- 骨骼关键帧池按需扩容，保留槽位、MME 模型布局和原有文件格式。容量受内存及索引表示范围约束，分配失败不提交半段结果。PMM/VMD 保存、读取、编辑、撤销与重做使用实际容量。
- 新通道重采样保留未选轨道与区间外曲线。贝塞尔边界通过曲线分割保存形状；无法用当前手柄格式精确表示时拒绝操作并提示，避免静默修改区间外动画。
