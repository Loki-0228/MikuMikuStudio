# 物理烧录与高级物理设置

物理烧录是原版 MMD 之外的新增功能。入口为 **烘焙 → 烧录关键帧…**（English: **Baking → Bake keyframes…**；日本語：**ベイク → キー焼き込み…**）。先选择模型并停止播放或录制，再打开窗口。同一菜单下的[网格导出与烧录](mesh-export.md)保存最终顶点，使用独立的网格缓存，不覆盖骨骼关键帧。

「烘焙方式」默认是「原生」，加载 MMV 或拥有第 0 层不会自动触发删除 FX。原生物理烘焙允许部分骨骼和部分帧范围，不要求表情通道或 MMV 截层接口。只有主动选择 MMV 层时才应用完整输出与删除检查，见[警告逻辑验收](../records/animation/baking.md#record-bake-warning-logic)。

## 使用方法

1. 输入起始帧和结束帧。「末帧」填写当前模型的最后一帧，不开始计算。范围包含两端，允许单帧；帧号为程序支持范围内的非负整数，超出范围时拒绝操作。
2. 勾选「物理烧录」，将受物理驱动的骨骼运动逐帧记录为骨骼关键帧。需要重采样其他骨骼时，同时勾选「关键帧烧录」。
3. 选择「Bullet 默认」，或打开「高级设置…」修改参数、读取预设。在「关键帧烧录设置…」中可以限制为选中的骨骼；该限制也用于物理烧录。
4. 点击「开始烧录」。目标范围已有关键帧时，确认覆盖提示。计算期间显示进度，可以取消。
5. 完成后用常规 PMM 保存或 VMD 导出流程保存结果。一次烧录对应一次撤销；撤销与重做包含关键帧、物理禁用标记和模型末帧。

物理计算在独立世界中从第 0 帧开始；起始帧之前的动画参与预计算。场景中全部模型的刚体参与碰撞，结果只写入当前模型的目标骨骼。取消或计算失败时不写入部分结果，也不改变编辑器中的骨骼、关键帧或实时物理世界。参数仅用于本次烧录。

物理烧录写入的关键帧带有原生「禁用物理」标记，回放时使用记录的骨骼运动。为使物理状态在范围两侧恢复，程序会在起始帧前一帧（存在时）和结束帧后一帧补充边界关键帧；已有边界关键帧保留。边界帧可能使模型末帧增加 1。其他已有范围外关键帧的姿态不覆盖，但边界附近的插值和状态切换会随新增关键帧变化。

「关键帧烧录」每帧重采样已有骨骼动画，保留 IK 和表情轨道，不做 IK 展平或关键帧精简；同时启用物理烧录时，物理骨骼使用模拟结果。只启用普通关键帧烧录时，原有物理开关随采样保留。关键帧池按需要扩容；无法扩展或超出索引范围时拒绝写入。

原生骨骼缩放参与逐子步物理求值，所有绑定骨骼的刚体形状、偏移和 joint 连接点随之缩放。物理烧录保存求解后的缩放，普通重采样保存原曲线缩放，两者都参与撤销与重做。缩放通过 PMM 扩展和同一个 VMD 的尾部扩展保存；原版 MMD 只读取位置、旋转等标准动作，不显示缩放。具体约束见[原生骨骼缩放](bone-scaling.md#刚体与-joint)。

## 参数与默认值

截图中的 `ERP 0.500、sub step 2、CFM 0.100、倍率 2` 仅供参考，**不是初始配置**。初始 ERP 和 CFM 从项目所用 Bullet 2.75 的 `btContactSolverInfo` 默认初始化结果取得。

| 中文标签 | English | 日本語 | 默认值与范围 |
| --- | --- | --- | --- |
| 误差修正系数（ERP） | Error reduction (ERP) | 誤差補正係数（ERP） | `0.2`；有限数值，0–1 |
| 物理子步数 | Physics substeps | 物理サブステップ数 | `1`；整数，1–16 |
| 约束柔化系数（CFM） | Constraint softness (CFM) | 拘束の柔らかさ（CFM） | `0`；有限数值，0–1000000 |
| 内部计算倍率 | Internal simulation rate multiplier | 内部計算倍率 | `1`；整数，1–16 |
| 基准频率（Hz） | Base rate (Hz) | 基本周波数（Hz） | `60`；支持 30 或 60 |
| 物理计算频率 | Simulation rate | 物理計算周波数 | 基准频率 × 倍率，只读 |

- ERP 控制接触与关节约束的位置误差修正。增大数值可能引起抖动。
- CFM 放松关节约束，允许一定误差；它不改变碰撞接触硬度或弹簧刚度。当前 Bullet 2.75 的接触路径固定使用 CFM 0，本功能在烧录关节的约束行中应用设置值。
- 物理子步数把每次更新分成等长时间步；它不是求解器迭代次数，也不是追帧上限。每个时间步明确调用一次 Bullet，步长为 `1 / (基准频率 × 倍率 × 子步数)` 秒。
- 内部计算倍率提高物理更新频率；子步数进一步细分每次更新。两者分别保存、分别生效，不改变 30 fps 动画时间轴和视频输出设置。

输入框提供中、英、日三语悬浮说明，键盘聚焦时也在窗口下方显示相同说明。小数输入接受科学计数法，例如 `2e-1`，小数点使用 `.`。

「Bullet 默认」采用上述初始值。「MMD 60 Hz」是相同频率的参考入口，当前参数与 Bullet 默认相同，不标为经过原版 MMD 运动一致性验收的兼容预设。离线模拟使用独立的碰撞世界和从第 0 帧开始的初始状态，不承诺与编辑器实时播放或原版 MMD 逐位一致。启用重力噪声时使用固定、按时间索引的本地噪声，以使重复烧录可复现。

## 纯文本预设

在高级设置中使用「保存预设… / Save preset…」和「读取预设… / Load preset…」。文件为不加密的 UTF-8 JSON，可用文本编辑器查看、修改与共享。文件名和预设名称支持 Unicode，界面语言不影响格式。

下面记录初始设置；它没有采用截图中的示例值。

```json
{
  "format": "MikuMikuStudioPhysicsPreset",
  "schemaVersion": 1,
  "name": "Bullet defaults",
  "erp": 0.2,
  "cfm": 0,
  "substeps": 1,
  "simulationRateMultiplier": 1,
  "baseSimulationRateHz": 60
}
```

全部字段必填。格式版本固定为 1，拒绝未知或重复字段、错误类型、缺失字段、非法 UTF-8、截断 JSON、NaN/Infinity、溢出与超范围数值。允许 UTF-8 BOM、合法 JSON 转义和科学计数法。整数参数必须具有整数值。名称最多 128 个 Unicode 字符，不允许控制字符；文件最大 64 KiB。

读取先完整校验，再替换当前参数；失败保留当前设置并按界面语言提示原因。保存先写同目录临时文件，再替换目标；失败保留原有预设。高级设置中的取消不会应用未确认的参数，已明确另存的预设文件保留。

预设独立保存，不写入 PMM 扩展。PMM 与 VMD 保存的是烧录生成的原生骨骼关键帧和物理状态标记，不要求额外的预设文件才能回放。

## 通道选择、稀疏采样与容量

通过「通道…」选择要记录的轨道和子参数。

- 相机/灯光/附件主页：选择相机、灯光、自阴影、重力和每个 `.x` 的原生通道及子参数，不要求 MMV。
- 模型页：只列当前模型，可逐骨骼、表情、显示/IK 选择。物理开启时骨骼选择仍有效；其他模型参与碰撞，不写入其他模型的轨道。
- 起止帧与步长控制采样；总会包含结束帧。骨骼稀疏烘焙替换区间内旧键，物理键携带原生禁用物理标记，边界恢复原状态。MMV FX 网格物理使用「烘焙网格…」及实例启停键，见 [网格说明](mesh-export.md)。
- 骨骼关键帧池按需扩容，保留槽位、MME 模型布局和原有文件格式。容量受内存及索引表示范围约束，分配失败不提交半段结果。PMM/VMD 保存、读取、编辑、撤销与重做使用实际容量。
- 新通道重采样保留未选轨道与区间外曲线。贝塞尔边界通过曲线分割保存形状；无法用当前手柄格式精确表示时拒绝操作并提示，避免静默修改区间外动画。

MMV 参数区位于默认配置与项目文件按钮下方，分隔线和留白区分两部分；窄窗使用参数区内部滚动。
