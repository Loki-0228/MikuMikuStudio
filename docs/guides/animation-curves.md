# 编辑关键帧与曲线

附件操作区的曲线按钮打开原生浮窗。在顶部「来源」中选择当前附件、摄像机、灯光、自阴影或重力。MMV 的材质分配和骨骼分配页，在参数区提供同一曲线编辑入口。模型表情曲线也在同一浮窗里编辑，入口见[模型表情曲线](#模型表情曲线)。

浮窗是 MMS 的原生功能，不依赖 MMV：原版模型、没有安装 MMV 时同样可用。它只读写曲线数据和本机设置，不改变渲染路径。

## 模型表情曲线

四个表情选择框（眉、眼、口、其他）最左侧各有一个曲线按钮。按钮打开浮窗，打开时的活动曲线是该面板当前选中的表情，其余表情都在左侧列表里。设计上一个模型是一个来源，四个面板的表情各是一条通道；面板号为 0 的隐藏系统表情不进入列表。

### 曲线列表

| 操作 | 效果 |
| --- | --- |
| 单击一项 | 只切换该曲线的显示与隐藏，不改变活动曲线，也不影响其他项 |
| 双击一项 | 把该项设为活动曲线并自动显示它 |
| 空格 | 切换光标所在项的显示与隐藏 |
| 回车 | 把光标所在项设为活动曲线并显示 |
| 方向键、Home、End | 只移动光标，不改变活动曲线 |

活动曲线在该行前面显示 `●`。双击包含前一次单击（Win32 的固定消息顺序），所以双击不会把曲线关掉，也不会误改其他曲线。

**列表勾选就是画面**：勾选的行一定是画布上画出来的曲线，没勾的一定没画。区间一次筛选、自动模式、手工显隐都遵守这一条，没有关键帧的曲线因为画不出东西，永远不会被勾上。

隐藏的活动曲线不再绘制，它的关键帧、切线和一个原版手柄一起隐藏，但仍可用「帧」「数值」和手柄面板编辑；画布上会提示该曲线已在列表中隐藏，双击列表项或按回车恢复显示。

### 对比显示

对比控件是三格连成一体的分段控件，点击哪一格立即选中哪一格，只有当前格显示选中态。

| 位置 | 中文 | English | 日本語 | 背景曲线 |
| --- | --- | --- | --- | --- |
| 左 | 同组变化 | Same group | 同グループ | 活动曲线所在表情分类里已登记且有变化的曲线 |
| 中 | 自由显示 | Free | 自由表示 | 曲线列表里勾选的曲线 |
| 右 | 四组对比 | Four groups | 4 グループ | 四个表情分类里已登记且有变化的曲线 |

- 进入浮窗时沿用上次的模式；模式由宿主记在本机设置里。
- 没有「关闭」档：不支持对比的来源不显示这一行控件。
- 自动模式是「算出要显示哪些曲线」的一种方式：选中它时会立刻把结果写进列表勾选，主曲线保持勾选，所以列表和画面始终一致；来源没有对比能力时（例如相机、旧 MMV 来源）这一行不出现，列表行为与以前完全相同。
- 手工单击显隐、双击激活会自动切到中间「自由显示」：切换时先原样保留当前画面上已有的曲线，再只改被点的那一行，因此不会把自动模式刚隐藏的曲线一起放出来。
- 再次点同组或四组，会重新算出该模式的集合（手工勾选被覆盖），并同时把活动曲线恢复到打开浮窗时的主表情。
- 「自由显示」不改变活动曲线，也不改动任何勾选：它承载的就是手工显隐、双击激活和区间筛选的结果。
- 模式写入宿主失败时不切换、不改勾选、不改活动曲线，只在状态行报告原因；任何模式操作都不写曲线数据。
- 在列表中隐藏的曲线，在任何模式下都不再作为背景绘制。

### 区间一次筛选

「筛选非常值」按一次执行一次：

1. 取时间段。当前曲线选中两个以上关键帧时，用这些帧的最小值和最大值；否则用「起始帧」「结束帧」两个输入框，先后顺序自动纠正。
2. 勾选该范围内有变化的曲线并显示它们；活动曲线无论范围如何都保留勾选，没有关键帧的曲线不会被勾选。
3. 把显示切到「自由显示」，并在底部状态行写明实际范围与来源，例如「对比范围 10 – 20（来自选中关键帧）：已勾选 2 条非常值曲线…」。
4. 没有可用时间段时报告原因，且不改动任何勾选；切换显示这一步写入失败时，勾选结果保留，状态行同时给出失败原因。

「有变化」是精确判定，不按几个帧采样：两端值相同但贝塞尔或 Hermite 中段隆起同样算有变化；阶梯区间的值一直保持、两端相同则算常值；未登记的空轨道从不纳入。

### 悬浮说明

指针停在控件上时，状态行上方的一行提示说明该控件的操作，覆盖曲线列表、三格模式、筛选按钮、添加／删除／应用关键帧、画布、原版手柄、时间条和数值条。提示有中、英、日三种语言。

提示写在独立的一行，不覆盖状态行：出错时的错误信息在悬停期间和指针离开后都保持可见，离开控件只清空提示行。

## 增加、删除和移动关键帧

1. 选择通道，在「帧」和「数值」中填写数据。
2. 点击「添加关键帧」。该帧已有关键帧时会选中原关键帧，不重复插入。
3. 选择关键帧后，修改帧号或数值，再点击「应用」。也可在图中拖动关键帧。
4. 要删除已选关键帧，点击「删除关键帧」。宿主轨道必须保留第 0 帧关键帧。

修改立即提交给对应轨道；失败时保留原数据并显示原因。浮窗中的撤销和重做以当前来源为范围。原窗口中修改轨道后，重新激活浮窗会读取新数据。

## 调整曲线

「数值」视图显示参数值，「速度」视图显示每帧变化率。选择区间的结束关键帧，点击「阶跃」「线性」或「贝塞尔」即可改变该区间的插值，无需再点击「应用」。多选时，一次操作修改所选关键帧之前的各个区间，并可整体撤销。第一个关键帧没有前方区间。布尔和枚举通道保持阶跃变化，不提供插值和切线编辑。表情权重按数值通道编辑。

插值决定区间如何计算数值；切线决定贝塞尔手柄如何编辑。阶跃和线性区间不读取手柄斜率，因此选择切线模式或预设时，需要手柄的相邻区间会自动切换为贝塞尔。两组按钮均立即写入曲线，帧号、数值、斜率和权重输入仍通过「应用」或 Enter 确认。

切线栏左侧的「自由」「对齐」「自动」是持续的手柄模式。自由模式允许两侧独立编辑；对齐模式让两侧保持相同斜率；自动模式根据相邻关键帧重新计算斜率。手动拖动自动手柄或修改其斜率后，改为自由模式。

右侧的「水平」「拉直」「缓入」「缓出」是一次性预设。水平把两侧斜率设为零；拉直把前后两个区间设为线性；缓入让进入该关键帧的一侧水平弯曲、离开侧拉直；缓出相反。应用后回到自由手柄，预设按钮不保持选中，后续修改不会重复应用预设。

左侧的原版 0–127 面板支持拖动两个贝塞尔手柄。不能用原版归一化手柄表示的区间会禁用该面板，例如两端值相同的区间；仍可用数值曲线和切线输入编辑。切线斜率以「参数单位／帧」计，权重决定手柄沿时间轴的长度。

### 画布上的贝塞尔手柄

「数值」视图中，选中的关键帧在每个弯曲的一侧显示一根手柄线和圆形端点。拖动端点调整该侧的斜率与手柄长度，一次拖动为一步撤销；长度自动限制在不与相邻手柄交叠的范围内。对齐切线的关键帧拖动一侧时另一侧随之保持相同斜率，其他模式拖动后变为独立切线。直线的一侧不显示手柄。

| 操作 | 效果 |
| --- | --- |
| Alt 加单击线性关键帧 | 转为两侧贝塞尔：两侧手柄共用平滑斜率，与邻键共线时取水平；相邻关键帧朝向它的手柄保持在弦线上 |
| Alt 加单击手柄 | 该侧手柄回到弦线，曲率消失；另一侧也消失后关键帧回到线性 |
| Alt 加单击弯曲的关键帧 | 两侧直接转为线性 |

## 移动和缩放视野

横向和纵向范围条均支持中央拖动平移、两端拖动缩放。点击范围条的一段后，方向键操作该段，按住 Shift 放大步长。

视野范围随当前曲线限定：时间轴最小 1 帧，最大为关键帧跨度的三倍（至少 300 帧）；数值轴最小为数据幅度的千分之一，最大为其 50 倍（幅度按至少 1 计）。视野中心不会离开数据超过一个最大跨度，平移也不会漂到极端坐标。

| 操作 | 效果 |
| --- | --- |
| 中键拖动，或空格加左键拖动 | 双轴平移 |
| 滚轮 | 纵向平移 |
| Shift 加滚轮 | 横向平移 |
| Alt 加滚轮 | 时间轴缩放 |
| Ctrl 加滚轮 | 数值轴缩放 |
| Ctrl、Alt 加滚轮 | 双轴缩放 |
| Home / F | 适配全部 / 适配当前区间 |
| H / V | 平移工具 / 选择工具 |
| Tab、Shift 加 Tab | 切换控件焦点 |

这些快捷键在图形区域生效，不接管数值输入框的文字编辑。

## 烘焙和 VMD

选择通道，设置起止帧和步长后，点击「烘焙选中通道」。目前烘焙范围必须覆盖所选轨道的完整关键帧范围；局部替换会被拒绝。采样后的数值通道使用线性关键帧，离散通道保持阶梯。该操作采样参数曲线，不烘焙模型物理或网格。

浮窗的 VMD 按钮读取或导出当前来源。文件菜单中的「读取当前附件动作（VMD）」也可导入当前附件。附件区原先的「读取」按钮已移除：附件动作改随相机・照明 VMD 保存和读取，见[附加功能](../records/development/features.md#record-additional-features)中的「相机・照明 VMD 中的 `.x` 附件动作」。原附件文件按钮名称改为「载入」。

导出的 VMD 先写完标准骨骼、表情、相机、灯光、自阴影及显示/IK 段，再追加 `MMVCURV1` 曲线扩展。旧读取器仍可读取自身支持的标准段。附件变换写为 `Accessory` 骨骼轨道，其他参数写为表情代理；完整名称和曲线保存在扩展中。没有扩展的多骨骼 VMD 不会自动猜测附件目标，会报告无法选择唯一轨道。

模型表情曲线走另一段容器：标准表情段只带帧和权重，原版按线性关键帧读取，得到的是精确曲线的折线近似；精确曲线写在标准段之后、骨骼缩放尾部之前的 `MMSMCRV1` 块里。不认识该标记的读取器会跳过整块，块内声明的长度让损坏的数据也能被完整跨过，后面的骨骼缩放尾部不受影响。导入时，只有名称恰好匹配一个表情、并且该表情在记录的首帧确实收到导入关键帧，曲线才会被安装。

## 保存工程

需要按不同帧率整体换算动作时，使用[编辑 → 根据帧率修正](frame-rate.md)。它覆盖整个工程，处理同帧合并并输出逐帧报告，应用后自动打开「另存为」。

宿主主页和附件曲线写入 PMM 扩展。MMV 参数关键帧和曲线写入 `.vmm`。`.vem` 是手动静态效果预设，保存当前帧的参数值，不保存动画；`.uifx` 仍只记录作者的界面定义。

模型表情的精确曲线随工程写入 PMM v2 扩展，每个模型槽一条 `org.mikudancestudio.model.<槽>.morphCurve.v1` 记录；记录按整体校验后才装载，装载失败的记录被忽略并保留原始字节，不会被下一个模型继承。表情的标准关键帧仍在模型自己的轨道里，普通增删、拖动和烘焙照常写入这些轨道；原生关键帧出现、消失或改值时以它为准，被它触及区间的手工缓动会退掉，从编辑器重新应用曲线即可恢复。

模型骨骼缩放与物理烘焙继续使用原有菜单和记录，不在浮窗里。
