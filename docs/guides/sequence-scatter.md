# 选中帧序列散布

「编辑」菜单中的「选中帧序列散布」复制当前模型选中的表情关键帧，并在目标范围内按随机间隔和速度重复插入。原片段保留。当前只支持表情，不处理骨骼、相机或其他轨道。

## 使用步骤

使用前停止播放，并切换到模型编辑状态。片段至少需要两个不同帧上的表情关键帧，可以包含多个表情。只复制选中的关键帧，不补入未选中的关键帧。

1. 在时间轴上选中需要复制的表情关键帧。
2. 打开「编辑」菜单中的「选中帧序列散布」。
3. 填写目标帧范围、片段间隔和播放速度。
4. 点击「预览 / 重新随机」，查看预计插入次数、关键帧数量及跳过次数。
5. 需要另一组分布时，再次点击「预览 / 重新随机」。
6. 点击「散布」，插入当前预览的结果。

打开窗口时会生成一次预览。修改参数后，需要重新预览才能散布；没有可插入片段时，「散布」不可用。预览不修改工程，点击「取消」或关闭窗口也不插入关键帧。

## 参数含义

| 参数 | 含义与范围 |
| --- | --- |
| 目标帧范围 | 起止帧均为非负整数，包含两个端点，结束帧不得小于开始帧。首个候选片段从开始帧起放置。每个副本必须完整落在范围内。 |
| 片段间隔均值 | 上一个片段的结束帧到下一个片段的开始帧之间的帧数，至少为 1。间隔取整到整数帧。 |
| 片段间隔方差 | 单位为帧²，范围为 0 至 10¹²。例如方差 225 对应标准差 15 帧。 |
| 播放速度均值 | 倍率范围为 0.05 至 20。1 倍保持原时长，2 倍约为一半时长，0.5 倍约为两倍时长。关键帧位置取整到整数帧。 |
| 播放速度方差 | 单位为倍率²，范围为 0 至 100。例如方差 0.04 对应标准差 0.2 倍。 |

间隔和速度分别按正态分布采样，再截断到允许范围：越界样本直接取边界值，不重新抽样。均值和方差描述截断前的分布，截断后的实际统计值可能变化。方差为 0 时固定使用对应均值，间隔仍需取整。

默认间隔均值为 90 帧、方差为 225，速度均值为 1 倍、方差为 0.04。目标范围默认从原片段结束后的第 1 帧开始，到结束后的第 300 帧，且不超过工程帧上限。

## 跳过规则与上限

每次插入都以完整副本为单位，遵守以下规则：

- 候选副本超出目标范围时跳过，不裁掉尾部。
- 候选副本与原片段的时间范围重叠时跳过。
- 所选表情的已有关键帧落在候选副本范围内时，跳过整个副本，不覆盖已有关键帧。
- 速度变化和整数取整使原来不同帧的关键帧压缩到同一帧时，跳过整个副本。

单次预览最多尝试 10,000 个位置，最多新增 100,000 个关键帧。超过任一上限时生成失败，工程保持不变。缩短目标范围或增大间隔后可重新预览。

## 撤销与保存

一次「散布」记为一次撤销操作。「撤销」移除本次全部副本，「重做」恢复同一组副本及曲线，不重新随机。
