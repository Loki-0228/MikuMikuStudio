# 根据帧率修正

入口是「编辑 → 根据帧率修正…」。填写动作制作时的「原帧率」和工程采用的「现帧率」，预览后点击「应用」。页面支持中文、英文和日文。

应用成功后自动打开宿主的「另存为」。取消另存为会保留内存中的修正结果和报告；不会自动覆盖原工程。通过常规 PMM 保存流程保存修正结果，外部插件存档仍由插件负责。

## 修正范围

转换作用于当前载入的整个工程，不受当前模型或相机模式的选择限制：

- 所有模型的骨骼位置、旋转、缩放、表情、显示、IK 和外部亲记录。
- 相机、灯光、自阴影、重力与所有 `.x` 附件的原生关键帧及曲线。


原生通道不依赖 MMV。当前 main 不修正 MMV4MMS 参数、FX 启停轨道或已烘焙网格缓存时间；使用这些数据的工程需另行核对时间对应关系。播放、录制、导出或烘焙期间不能修正。

本功能处理载入后的数据，不会扫描磁盘批量改写 VMD、PMM、VMM 或效果预设文件。VMD 导出仍沿用各自入口和原版数据加扩展尾部的格式。

## 时间和补间

「单一维度」指输出是一个标量 `v(t)`，不是指只有时间轴，也不意味着采用线性补间。时间 `t` 是自变量；一维关键帧压缩拟合的是该标量随时间的变化。

按用户确认的方案，二维及更高维向量拆成多个标量分量，分别执行普通一维补间，在同一时间点组合为 `p(t)`。位置 XYZ 各自处理；不增加空间轨迹联合拟合。

相机沿用原版 MMD 的六条补间：位置 X、Y、Z、旋转、距离、视角。旋转三个欧拉分量共用一条曲线；骨骼旋转仍保持原有四元数插值，不能把四元数四个分量当作四条独立标量曲线。

参考仓库保留原版地址注释的[相机求值代码](../../src/app/timeline_advance.cpp)：两关键帧之间先把时间归一化，在后一个关键帧的贝塞尔控制点上求出缓动比例，再计算 `前值 + 比例 × (后值 − 前值)`。各位置轴的缓动不同，组合出来的三维轨迹即可弯曲，并不需要另建空间路径拟合器。[相机 VMD 写出](../../src/io/vmd_save.cpp)仍保存这六组控制点。[当前帧率修正](../../src/animation/native_frame_retime.cpp)沿用此通道划分。

以帧 0 为缩放中心：

```text
理想新帧 = 原帧 × 现帧率 / 原帧率
实际新帧 = 理想新帧取整
```

帧率可以是小数。正常缩放保留关键帧值和归一化补间形状，自定义切线随相邻区间长度调整。原生骨骼和相机的补间控制点在没有帧合并时保持原字节。

多个键落到同一帧时，保留一个时间槽。连续通道在对应的原时间上求值，并裁切最左侧的入曲线和最右侧的出曲线；开关等离散状态保留组末状态。包含原始帧 0 的合并组保留帧 0 的初始值。骨骼旋转按四元数插值，缩放矩阵保留一个共同的缓动曲线。

整数帧和原生 0–127 控制点不能表达任意裁切结果。压缩可能改变时序或省略短促动作，不能保证无损。报告中的数值误差来自采样比较，不是严格误差上界。

## 结果报告

应用后窗口显示完整报告，可滚动查看并点击「复制报告」。每条明细包含对象或效果实例、通道、原帧和新帧。

| 明细 | 含义 |
| --- | --- |
| 取整偏移 | 理想新帧不是整数，列出理想位置和实际位置。正常等比例移动且正好落在整数帧不会被计为偏移。 |
| 合并省略 | 该原键失去独立时间槽，列出合并目标和来源帧范围。省略的是独立时刻，合并结果仍可能包含它对值或曲线的影响。 |

同一个原键可以同时发生取整偏移和合并省略，报告分别记录这两个原因。预览只显示汇总；应用后的报告给出逐帧明细。

## 提交与失败

预览不修改工程。应用前再次核对对象、关键帧和效果配置是否变化；过期的预览必须重新生成。原生关键帧和曲线作为一次事务提交，拒绝时恢复原状态，不保存部分结果。

变更后的时间轴仍采用整数帧。此命令不改变渲染帧率设置、声音速度或外部视频素材速度。
