# 网格导出与烘焙

**烘焙 → 烘焙网格…** 默认只写入工程缓存；**烘焙 → 导出 ABC…** 默认只导出文件。两项也可同时勾选。停止播放、录制后操作。取消采样不会提交半段缓存；同时输出时，若文件成功而工程提交失败，会分别报告。

当前 main 支持原生几何缓存与相应导出，但未接通 MMV 分层烘焙。不能选择指定 MMV 层、自动移除效果或创建插件区间启停轨道；带分层截点的缓存也不能作为当前原生缓存回放。

## 选择来源与输出范围

列表包含所有已加载的模型和 `.x` 附件，不按 FX 名称或已知物理后端过滤。勾选要输出的对象，再为各对象填写材质和顶点编号；编号从 0 开始，支持 `0,2,5-10`，留空表示全部。模型还可选「仅已选骨骼的权重顶点」。各过滤条件取交集。没有可见几何的对象不会因此产生可导出的网格。

完整对象可缓存可变拓扑。局部顶点缓存按源顶点编号覆盖，只改所选顶点的位置和法线，其他顶点继续使用当帧 MMS 动画。局部模式保留源拓扑；没有源编号的生成顶点不能局部烘焙，应选择完整对象。纯 ABC 输出不支持局部顶点过滤，界面会要求启用工程烘焙。

帧号使用程序支持的非负整数范围，按 MMD 的 30 fps 时间轴解释；超出范围时拒绝操作。采样率为 1–120，默认 30；从第 0 帧预计算，在指定区间内输出。场景在副本中求值，结束后恢复编辑器状态。物理采用独立世界，不保证与所有实时物理后端逐位一致。

## 工程缓存

工程缓存记录原生网格，MME 继续执行着色；原生 Bullet 骨骼运动也可通过「关键帧烘焙」输出。MMV4MMS 返回完整场景纹理，当前宿主没有把插件任意层的几何接回此烘焙入口。

- 新缓存只在 `[起始帧, 结束帧+1)` 生效，范围外恢复当帧求值；缓存样本之间保持前一样本。
- 全对象缓存冻结所选范围内的几何；局部缓存只覆盖所选顶点。源模型和动画记录保留。
- MME 分配在创建代理、重开 PMM 和清除缓存时维护，不将纯着色效果作为原生几何烘焙结果。

PMM 记录相对路径映射，几何另存为旁边的 `<工程名>.<内容标识>.mdsmesh.abc`。移动工程时一起保留 PMM、EMM、缓存及源素材。原版 MMD 忽略网格缓存扩展。

没有区间标记的原生缓存仍按对应存档规则读取。带 MMV 分层截点的缓存会报告不可用，不应将其视为已支持的普通缓存。

## 清除缓存

「烘焙 → 清除网格烧录…」可选择当前模型或全部对象；网格窗口的清除按钮只清除列表勾选的对象。清除后恢复源动画；外部插件的配置仍由插件管理。清除不删除已保存的缓存文件；保存 PMM 后写入新状态。网格缓存不占骨骼撤销栈。

## ABC 文件

仅导出 ABC 时仍捕获实际 DX9/MME 顶点着色器后的网格，适合向其他软件交付最终几何；不改变工程分配。同时选择工程缓存时，两种输出共享 MME 前的原生几何。ABC 使用 Ogawa，右手系 Y 向上、Z 相对 MMD 反向，UV 的 V 翻转；单位沿用 MMD。原生捕获保留顶点法线，传统绘制捕获重算法线。每个对象、材质和绘制通道保存为 PolyMesh，可变拓扑和消失组使用独立样本。

传统捕获支持标准索引三角形、VS 1.1/2.0/3.0；不支持的着色器重放或绘制方式明确报错。纹理像素、后期、阴影图与描边不作为导出内容。ABC 不含骨骼、动画曲线或 FX；相机相关变形已固定在采样镜头下。
