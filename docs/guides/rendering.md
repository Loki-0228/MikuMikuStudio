# 画面设置

本页介绍完整包的画面选项。最小包保留原抗锯齿开关和原版阴影、材质顺序，具体差异见[最小构建档](../reference/minimal-build.md)。

## 选择抗锯齿

打开「显示 → 抗锯齿」，选择 MMD 原始（MSAA）、FXAA、TAA 或 SMAA 的具体档位。「SMAA」本身只展开菜单；将指针移入三级菜单后选择档位。选择其他算法时，SMAA 子菜单不显示选中圆点。

| 方案 | 工作方式 |
| --- | --- |
| MMD 原始（MSAA） | 使用原生多重采样路径。 |
| FXAA | 在当前帧处理画面边缘；原生描边只在描边自身覆盖的像素之间平滑，不向轮廓外侧加宽，已经带渐变覆盖的描边保持原位。描边偏细导致断续时，把「描边粗细」调大可以让线条更连续。 |
| TAA | 使用运动矢量对齐历史采样。 |
| SMAA 1x（标准） | 在当前帧检测边缘并混合。 |
| SMAA 1x（斜线与拐角增强） | 扩大搜索范围，增加斜线与拐角处理。 |
| SMAA T2x（标准） | 使用运动矢量结合两帧采样。 |
| SMAA T2x（斜线与拐角增强） | 两帧采样，并增加斜线与拐角处理。 |

TAA 与 T2x 的运动捕获会增加工作量，复杂 MME 场景仍可能受影响。SMAA 1x 不需要运动捕获。静止画面和只有第 0 帧的工程会补充必要采样，图片序列按输出帧组织采样，避免重复执行整套渲染。实现与验证范围见[抗锯齿记录](../records/rendering/anti-aliasing.md)。

抗锯齿开关、算法和 SMAA 档位随 PMM 扩展保存。

## 调整预览比例

降低预览比例可减少部分像素绘制工作，不改变导出尺寸。HUD、工具条和帧率文字按显示分辨率绘制。低比例画面使用最近邻放大，因此小预览不适合作为最终画质判断。

小预览降低画面分辨率。原生 SM3 最近处阴影保留当前滑条要求的采样密度；动态精度开启时，中远处按画面深度和屏幕需求分配采样。MME 自建阴影和其他资源按 FX 原有声明分配，不做特效专用缩放或采样参数改写。模型更新、物理、CPU 等待和部分 MME 绘制不随分辨率下降，排查方法见[性能与设备](performance.md)。

## 设置透明排序与阴影

透明排序提供关闭、低、标准、高和最高，当前源码默认关闭。低、标准和高调整三角形顺序；最高档在适用路径上增加逐像素分层。复杂交叉表面、第三方 FX 和 MSAA 路径的验证条件见[透明排序记录](../records/rendering/transparency.md)。

自阴影精度数值越小，要求的采样密度越高。人物、场景和配件共用最小包原版投影中心的精度标准，不按物体大小提高精度。原生 SM3 用一个统一方形盒覆盖当前摄像机画面中的可见物体，深度范围保留画外物体投进来的阴影。近景、中景和过渡层也由全部物体共享，深度区间从最终相机投影推出，不随相机目标点距离扩大。贴图最低尺寸和尺寸取整只增加外围覆盖，不提高实际精度。

「动态精度」默认关闭。关闭时按滑条设定固定采样密度，不生成或混合相机近、中、远细节层；关闭开关时释放这些动态细节图。当大场景使全局贴图达到尺寸上限、人物阴影因此变粗时，为能受益的模型补充固定阴影图，以恢复同一滑条的原生人物精度。补充图覆盖整个模型，随模型移动，不随相机距离改变精度；所有场景投影物仍可向它投影。达到滑条要求时不额外分配，资源失败时回退全局图。这会增加显存和投影绘制开销，详见[人物固定精度补充](../records/rendering/shadows.md#record-fixed-model-shadow-20261029)。开启后，近景按最终相机投影和当前渲染视口增加采样，额外增量保留原增采样方案的 80%。第三层细节覆盖放大的中近景，使大场景不必等到超近距离才获得较细的阴影。各层交接区间不随滑条或物体尺寸改变，最外细节层在 2.5 倍深度跨度内平滑淡出。完整画面覆盖层按滑条对应的原生密度申请采样；画面范围过大时，实际精度受贴图尺寸上限限制。更高的覆盖精度可能增加显存占用和渲染时间。

全局覆盖图使用浮点双线性插值，避免低精度网格放大后产生重复斜条纹。它保留原来四个相邻深度点和比较公式，不扩大滤波范围，也不依赖「滤波加强」开关。见[固定精度与条纹修复](../records/rendering/shadows.md#record-shadow-fixed-bands-20261028)。

中近景扩展同样在关闭「滤波加强」时生效。现有桥接贴图会按当前视锥平移，使同一尺寸的方形覆盖盒容纳更远的画面，延后最粗层接管。此步保持贴图尺寸和采样密度，不增加贴图显存或阴影绘制遍数；更多像素使用细节层仍可能增加帧耗时。固定模式不使用这项扩展。首次扩大中近景贴图的显存代价见[中近景接管记录](../records/rendering/shadows.md#record-shadow-takeover-20261025)，后续复用贴图的对照与实测见[覆盖盒利用率记录](../records/rendering/shadows.md#record-shadow-packed-box-20261025)。

动态精度开启且「滤波加强」关闭时，近、中、远层的交接会从现有细节图中重建中间网格，再逐步连接到相邻粗图。中间层数取决于两张图的实际采样密度差，不按物体大小区分。交接处增加深度采样计算，但不新增阴影贴图或投影绘制遍数。低精度下的原始锯齿仍可能可见，连续交界的验证条件见[分级过渡记录](../records/rendering/shadows.md#record-shadow-progressive-20261027)。

等密度图层保持固定顺序，移动视角不会因浮点误差交换优先级。「滤波加强」先逐点判断遮挡，再混合结果，避免背景深度侵蚀细小阴影。放大后可见的阶梯边缘会在原滤波内识别网格交界点，拟合局部轮廓并修正像素覆盖；细条双边、真实拐角和不可靠的轮廓保留原滤波。人物柔阴影的局部明暗端值保持不变。 加强滤波按相机相对深度计算表面斜率，避免低精度网格放大后在平面上产生条纹或点纹；关闭时不使用该补偿。

滤波宽度随实际采样间距变化，同密度贴图扩容不会加宽滤波。轮廓重建会增加边缘附近的采样与计算，但不提高贴图精度。显卡贴图尺寸和显存仍限制可达到的密度；预算不足时保留覆盖并记录实际值。参见[轮廓重建记录](../records/rendering/shadows.md#record-shadow-contour-filter-20261025)、[远近景采样记录](../records/rendering/shadows.md#record-shadow-far-filter-20261025)及[固定精度标尺](../records/rendering/shadows.md#record-uniform-shadow-precision-20261024)。第三方 FX 的最终光照仍由特效决定。

模式 1、模式 2 使用不同的遮挡深度比较。完整包按最小包原版的默认范围和投影盒中心校准两种模式；滑条继续调整采样精度，不改变这项校准。阴影颜色仍来自材质。两种模式在已经完全遮挡的地方可以相同，差别主要出现在遮挡过渡处。这保留了模式差异和视角稳定性，不是旧版随投影位置变化的逐像素复刻。参见[模式差异修复](../records/rendering/shadows.md#record-shadow-modes-20261024)。

## 处理 NVIDIA 双面绘制白线

`MMSNvidiaAAFix.dll` 作为独立附件按需下载，不捆绑进完整包或最小包。需要修复时将 DLL 放到完整版程序旁，再通过「帮助」菜单安装；放置 DLL 不会自动修改驱动设置。步骤见[Release Notes 中的安装说明](../records/releases.md#nvidia-修复安装可选)。

该驱动设置只用于 NVIDIA。AMD 与 Intel 使用正常渲染和抗锯齿回退路径，不安装 NVIDIA 设置。删除 DLL 只隐藏入口，不撤销已经安装的驱动设置；卸载应使用程序提供的入口。安装行为见[仓库说明](../../README.md#中文)。

### 安装范围与重新安装

这条设置保存在显卡驱动的配置里，只关联安装时那个目录中 `MikuMikuDance.exe` 的完整路径。它不随程序文件夹复制或移动，也不会在另一台电脑上自动出现。

- 用新程序覆盖同一目录的 `MikuMikuDance.exe` 时路径不变，已安装的设置继续生效，不需要重新安装。
- 解压到新目录、改名目录、换用另一份 `MikuMikuDance.exe`，或换了一台电脑，都需要在对应位置重新安装。重装显卡驱动或重置 NVIDIA 配置后也一样。
- 已经安装时，「帮助」菜单同时显示「重新安装 NVIDIA 双面绘制补丁…」和「卸载 NVIDIA 双面绘制补丁…」。重新安装会重新写入并校验驱动设置，不需要先卸载。
- 保留 `MMSNvidiaAAFix.dll` 才有安装、重新安装和卸载入口。主程序包不附带该 DLL，换用新的程序目录时需从发布页单独下载。

### 安装后仍出现白边或锯齿

先确认「显示 → 抗锯齿」使用「MMD 原始（MSAA）」。这个 NVIDIA 设置针对 MSAA 下双面材质出现的白边、接缝和绘制异常；FXAA、TAA、SMAA 的边缘质量由 MMS 自身实现决定，与这条驱动设置无关。按上述步骤安装后仍有问题时，记录抗锯齿档位、显卡驱动版本和截图，便于区分是驱动设置还是渲染器本身的问题。
