# 画面设置

本页介绍完整包的画面选项。最小包保留原抗锯齿开关和原版阴影、材质顺序，具体差异见[最小构建档](../reference/minimal-build.md)。

## 选择抗锯齿

打开「显示 → 抗锯齿」，选择 MMD 原始（MSAA）、FXAA、TAA 或 SMAA 的具体档位。「SMAA」本身只展开菜单；将指针移入三级菜单后选择档位。选择其他算法时，SMAA 子菜单不显示选中圆点。

| 方案 | 工作方式 |
| --- | --- |
| MMD 原始（MSAA） | 使用原生多重采样路径。 |
| FXAA | 在当前帧处理画面边缘；原生描边只在描边自身覆盖的像素之间平滑，不向轮廓外侧加宽，已经带渐变覆盖的描边保持原位。描边偏细导致断续时，把「描边粗细」调大可以让线条更连续。 |
| TAA | 使用运动矢量对齐历史采样。 |
| SMAA 1x（标准） | 在当前帧检测边缘并混合。 |
| SMAA 1x（斜线与拐角增强） | 扩大搜索范围，增加斜线与拐角处理。 |
| SMAA T2x（标准） | 使用运动矢量结合两帧采样。 |
| SMAA T2x（斜线与拐角增强） | 两帧采样，并增加斜线与拐角处理。 |

TAA 与 T2x 的运动捕获会增加工作量，复杂 MME 场景仍可能受影响。SMAA 1x 不需要运动捕获。静止画面和只有第 0 帧的工程会补充必要采样，图片序列按输出帧组织采样，避免重复执行整套渲染。实现与验证范围见[抗锯齿记录](../records/rendering/anti-aliasing.md)。

抗锯齿开关、算法和 SMAA 档位随 PMM 扩展保存。

## 调整预览比例

降低预览比例可减少部分像素绘制工作，不改变导出尺寸。HUD、工具条和帧率文字按显示分辨率绘制。低比例画面使用最近邻放大，因此小预览不适合作为最终画质判断。

小预览只主动降低默认渲染的阴影贴图分辨率，100% 预览和导出恢复原精度。MME 自建阴影和其他资源按 FX 原有声明分配，不做特效专用缩放或采样参数改写。模型更新、物理、CPU 等待和部分 MME 绘制不随分辨率下降，排查方法见[性能与设备](performance.md)。

## 设置透明排序与阴影

透明排序提供关闭、低、标准、高和最高，当前源码默认关闭。低、标准和高调整三角形顺序；最高档在适用路径上增加逐像素分层。复杂交叉表面、第三方 FX 和 MSAA 路径的验证条件见[透明排序记录](../records/rendering/transparency.md)。

自阴影的动态精度和固定精度共用范围设置。「滤波加强」默认关闭，开启后对共享阴影图做预滤波；失败时使用当帧原始阴影图。第三方 FX 的最终光照仍由特效决定。适用范围和显存开销见[阴影记录](../records/rendering/shadows.md)。

## 处理 NVIDIA 双面绘制白线

`MMSNvidiaAAFix.dll` 作为独立附件按需下载，不捆绑进完整包或最小包。需要修复时将 DLL 放到完整版程序旁，再通过「帮助」菜单安装；放置 DLL 不会自动修改驱动设置。步骤见[Release Notes 中的安装说明](../records/releases.md#nvidia-修复安装可选)。

该驱动设置只用于 NVIDIA。AMD 与 Intel 使用正常渲染和抗锯齿回退路径，不安装 NVIDIA 设置。删除 DLL 只隐藏入口，不撤销已经安装的驱动设置；卸载应使用程序提供的入口。安装行为见[仓库说明](../../README.md#中文)。
