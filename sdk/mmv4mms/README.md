# MMV4MMS 接口

本目录的 `include/mmv/` 保存 MMS 编译时使用的接口定义，主程序不读取相邻插件仓库、不链接插件导入库，也不打包插件。

| 文件 | 用途 |
| --- | --- |
| `mms.h` | MMS 渲染 ABI 1，输入只读场景，返回同设备的借用颜色纹理 |
| `mmv.h` | 场景、编辑器与运行时 ABI 3，包含可选输入需求查询 |
| `menu.h` | 可选菜单状态接口版本 1，含渲染禁用状态位 |
| `mmv_deformer.h` | 原生计算模块契约；具体算法由插件提供 |
| `mmv_layer_bake.h` | 层采样与烘焙契约；实际使用还需相应路径接通 |
| `mesh.hpp` | 宿主采集的私有 C++ 辅助类型，不跨 DLL 传递 |

完整包从 `MikuMikuDance.exe` 同目录加载 `MMV4MMS.dll` 并验证 `MMV4MMSGetPluginApi`。已加载 `MMEffect.dll` 时不启用，最小包不加载。菜单由插件通过 `MMSGetMenuHostApi` 注册，宿主不创建占位菜单。

`MmvMmsFrame` 的可选尾部传递附件面板原始值、原生阴影及采样信息、材质 pass 回调。新字段按结构大小和各自版本判断；不把较短的旧结构当新结构读取。输出须匹配当前帧号与尺寸，纹理借用期依照头文件，不在设备丢失后继续持有。

同步接口时核对版本、字段尺寸、必需回调及双方编译结果。头文件存在不代表所有可选能力已经安装或接入。具体调用与生命周期见[宿主说明](../../docs/records/extensions/host.md)。
